# 工程0c：商品名（ブランド名）を決める（2026-10-20）

決まり：商品を決めたら商品名を決める。例えば「針マット → ハリネム（ハリで眠る）」のように、キャッチーで分かりやすい名前にする。
「この商品で行く」の直後に、この工程で名前を1つ決める。決めた名前は、店・LINE・ポリシー・CS の全部で同じに使う。

## 0. いつ・だれが
| 項目 | 決まり |
|---|---|
| いつ | 工程0 の最後。「この商品で行く」と Discord の商品チャンネル（supplier.md 1b）の後、工程1 の前 |
| だれが案を出す | Claude。10個の案と、それぞれの確かめた結果を出す |
| だれが決める | **運営者。案から1つ選ぶか、自分の名前を出す。運営者の言った名前が最後** |
| 止めない | 名前が決まるまで、工程1 は始めてよい。ただし 店（4d）・LINE・ポリシーの前には必ず決める |

## 1. 3つの名前を分ける（針マットの前例）
| 名前 | 何に使うか | 例（針マット） |
|---|---|---|
| 呼び名 | 広告の声・字幕・見出し。商品の形がそのまま分かる言葉 | 針マット |
| ブランド名 | 店の名前・LINE のアカウント名・ポリシーのショップ名・CS の署名・ドメイン・Instagram | ハリネム（HARINEMU） |
| 商品名 | 商品ページの題・カート・注文メール。ブランド名＋何の物か | ハリネム 自重指圧マット |

この工程で決めるのはブランド名。商品名は「ブランド名＋一般の言葉」で自動に作る。呼び名は工程0で決めた物のまま。

## 2. 良い名前の決まり（下の表は作りの手本。架空の名前）
| 今の名前 | 作り | 拍（音の数） | 分かる事 |
|---|---|---|---|
| ハリネム | 物＋動作（針で眠る） | 4 | 使い方がそのまま名前。呼び名「針マット」と同じ「ハリ」で始まる |
| フミラク | 動作＋効き目（踏む・楽） | 4 | 立ち仕事のインソール。足で踏むと楽 |
| シズナギ（静凪） | 場面＋状態（静かに凪ぐ） | 4 | 耳栓。音が静かになる。カタカナが正、漢字はロゴの添え |
| ニャンサラ | 擬音＋状態（ニャン・さらさら） | 5 | 猫のトイレ砂。鳴き声で「猫の物」と分かる |
| ここちドライ | 気持ち＋状態（心地・乾く） | 6 | 吸水ショーツ。6拍は長い方の上限 |
| SASAE | 動作の名詞（支え） | 3 | カップ付きタンク。ローマ字でも読める |

決まり：
1. **一度聞いて、何の物か・どう使うかが浮かぶ**。造語だけの名前（意味が浮かばない名前）は使わない
2. **3〜5拍**。6拍までは可。7拍以上は使わない
3. **カタカナが正**。漢字・ひらがな・ローマ字はロゴの添え。ローマ字は読みと同じつづり（HARINERU）
4. **呼び名と同じ音で始まると強い**（針マット → ハリネム）。広告の声と店の名前が耳でつながる
5. **作りの型は4つ**：①動作＋物（ハリネム）②場面＋効き目（シズナギ）③擬音・擬態語（ニャンサラ）④ダジャレ（言葉を2つ重ねる）。10個の案は、4つの型から少なくとも1個ずつ出す
6. **同じ運営者の別のブランドと似せない**（アプリが渡す「この運営者の別のブランド」の一覧と、ハーネスの商品フォルダ・各 `00_入口.md` を見る）

## 3. 使ってはいけない名前
| ダメな物 | 理由 | 例 |
|---|---|---|
| 治る・効く・治す・癒す・痛・病名・部位の病気（腰痛・むくみ・不眠） | 薬機法。雑貨が名前で効き目をうたう事になる | コシナオル、ムクミトール |
| すぐ効く・必ず・完全 の意味を持つ言葉 | 景品表示法。実際より良く見せる | タチマチ（たちまち） |
| 医療の見た目（メディカル・ドクター・クリニック・〜療法） | 医療機器・医者の物に見える | ドクターマット |
| 商品の一般名だけ | 商標が取れない（商標法 3条1項3号。だれのでもない言葉） | 立ち仕事マット、指圧マット |
| 実物と違う事を言う名前 | 誤認。届いた物と名前が合わない | ウゴクユカ（床は動かない） |

## 4. 確かめる事（10個全部に。結果は表に書く）
| # | 確かめる事 | やり方 | 合格 |
|---|---|---|---|
| 1 | 商標（J-PlatPat） | https://www.j-platpat.inpit.go.jp/t0100 の「称呼（類似検索）」にカタカナを入れて検索（付録の道具）。結果の「区分」の列で、下の関係する区分だけを見る | 関係する区分に、同じ読み・1音違いの登録や出願が無い |
| 2 | 区分の当て方 | J-PlatPat の「商品・役務名検索」で商品の言葉（例：マット、指圧器、耳栓）を引き、区分を確かめる。迷ったら下の表 | — |
| 3 | ドメイン | `.com`・`.jp`・`.shop` の空き。`.com` は `https://rdap.verisign.com/com/v1/domain/<名前>.com`、`.shop` は `https://rdap.gmoregistry.net/rdap/domain/<名前>.shop`（404＝空き。429 は間を空けて取り直す）、`.jp` は `whois -h whois.jprs.jp <名前>.jp/e`（No match＝空き）。値段まで見る時は Shopify の MCP の `generate-domain-names` | `.shop` か `.jp` のどちらかが空いている |
| 4 | Instagram | `instagram.com/<名前>` の空き。共通の Chrome（surasura）で Instagram にログインしてある時だけ取れる（未ログインは 401 で取れない） | 空き。取れない時は「未確認」と書く |
| 5 | 日本の検索でぶつからないか | 楽天の検索（`https://search.rakuten.co.jp/search/mall/<名前>/`）の商品名に、カタカナ・ひらがな・漢字の形が入っている物を数える。Amazon・Google は共通の Chrome で見てもよい | 同じ分野（健康・寝具・インテリア など）の商品名に無い |
| 6 | 一度で書けるか・意味が浮かぶか | ひらがなの読みだけを、書いた本人でない AI（Agent）に見せ、「客になったつもりで、書き方・浮かぶ物・覚えやすさ（○△×）」を答えさせる。運営者が人に1回言って書いてもらえれば、なお良い | 書き方が合っていて、浮かぶ物が商品とずれない |

## 5. 出す形（10個の案。商品フォルダの `naming.md` に書く）
| # | 名前（カタカナ・ローマ字） | 型 | 拍 | 意味・選んだ理由（1行） | 商標（関係区分の近い物） | .com／.jp／.shop | Instagram | 楽天の同名 | 一度で書けるか（AI の答え） | 判定 |
|---|---|---|---|---|---|---|---|---|---|---|

- 判定は ◎（一番推す。1つだけ）／○（使える）／△（弱い所がある。理由を書く）／×（使えない。理由を書く）
- 表の下に「推す1つと理由（3行まで）」と「確かめられなかった事」を書く
- 運営者には表と推す1つだけを見せる。「どれにしますか。自分の案でもいいです」

## 6. 決まった後（同じ回で全部）
1. `00_入口.md` の「商品名・何をする商品か」の行に、呼び名・ブランド名・商品名を書く。その下に「## 名前の決め方」として、10個の表と、運営者が選んだ日と言葉を写す（針マットの `00_入口.md` と同じ形）
2. 決めた名前を、次の値の正本に入れる（1か所に入れ、ほかはそこを読む）
   | 使う所 | 入れる場所 |
   |---|---|
   | 店の名前・ポリシーのショップ名 | `harness/_運営者/<会社>/ストア/<ブランド>.json` の `shop_name`（ポリシー・CS 担当の [store-legal.md](store-legal.md)・`operator-intake.md`） |
   | LINE のアカウント名 | LINE の設定（[line.md](line.md)・`tools/line-survey/products/<id>/survey.json` の `brand`） |
   | CS の署名 | `ec-cs` の新ブランド設定（`ec-cs/references/新ブランド立ち上げ.md`） |
   | 広告の声の呼び名 | `05_原稿の決まり.md` の 0 の1（呼び名）。ブランド名は店の名前として足す |
3. フォルダ名（`newec_harness/<呼び名>/`）は呼び名のまま変えない（針マットの前例。変えるとリンクが切れる）。どうしても変える時は工程1を始める前に1回だけ
4. ドメインと Instagram は、運営者のアカウントで取る（AI は取らない。空きを確かめるまで）。取ったら `ストア情報.json` の `store_url` に書く
5. 名前を後で変えた時は、2 の表の全部を同じ日に変える（[store-parts.md](store-parts.md) の「同じ値の点検」を回す）

## 付録：J-PlatPat の道具（共通の Chrome で回す。作業フォルダに写して使う）
```js
// node jpp.mjs タチラク フミカエ …  → ../jpp.json（名前ごとに表の行）
import { connect } from '<surasura の場所>/scripts/connect.mjs'; // 共通の Chrome
import fs from 'node:fs';
const out = {}; const { browser, newTab } = await connect(); const page = await newTab();
try {
  for (const n of process.argv.slice(2)) {
    try {
      await page.goto('https://www.j-platpat.inpit.go.jp/t0100', { waitUntil: 'domcontentloaded', timeout: 60000 });
      await page.waitForSelector('#t01_srchCondtn_mk_txtKeywd2', { timeout: 60000 });
    } catch (e) { out[n] = { err: String(e).slice(0, 100) }; continue; }
    await page.waitForTimeout(1500);
    await page.fill('#t01_srchCondtn_mk_txtKeywd2', n);   // 称呼（類似検索）
    await page.click('#t01_srchBtn_btnSearch');
    await page.waitForTimeout(7000);
    out[n] = { rows: await page.evaluate(() => [...document.querySelectorAll('table tr')].map(r => r.innerText.replace(/\s+/g, ' ').trim()).filter(Boolean)) };
    fs.writeFileSync('../jpp.json', JSON.stringify(out, null, 1));
  }
} finally { await page.close(); browser.close(); }
```
- 行の形：`番号 登録番号 商標 称呼基準 称呼（読み,…） 区分 区分… 権利者 出願日 登録日 ステータス`。区分は読みの後に並ぶ2けたの数
- 0件の時は、ページの「検索ヒット件数」が出ているかを見る（出ていなければ取り直す）
- ロボット確認が出たら越えない。その名前は「未確認」と書く
- 2026-10-20 にこの Mac で動いた（立ち仕事マットの10個。`sample/立ち仕事マット/naming.md`）
