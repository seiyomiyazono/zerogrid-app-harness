# ストア検収チェックリスト
更新: 2026-09-05 / **Shopifyに載せ終わったら毎回、上から全部確認してから納品する**。1つでも×なら納品しない
確認は**プレビューURL上で実測**する（ローカルのファイル一致で合格にしない）

## A. ヘッダー / ナビ
- [ ] ヘッダーは**1つだけ**。`document.querySelectorAll('header').length === 1` で数える
- [ ] **クローン側の自作ヘッダーを消したか**（`#shopify-section-header` / `header.site-header` / `#NavDrawer` が `#kd-main` の中に残りがち。テーマのヘッダーと二重に出る）
- [ ] ロゴが自社ブランド。サイズが崩れていない（横長ロゴは幅を調整）
- [ ] **左上にハンバーガー(3本線)があり、メニュー項目はその中に集約**されている。ヘッダーに項目を直接並べない
      → Shrine系は `sections/header-group.json` の `menu_type_desktop` を **`drawer`** にする。`mega`/`dropdown` だとPCでインラインメニューが出る
- [ ] メニューは「ブランド名(=商品ページ)」と「お問い合わせ」の**2つだけ**
- [ ] ソーシャルメディアのアイコンが**0個**（ヘッダー・メニュー・フッターとも）
- [ ] カートボタンはテーマ標準のものが動く

## B. 商品ページ
- [ ] **同じUIが二重に出ていない**（例:「サイズの選び方はこちら」が2つ）。クローン元HTMLが同じブロックを2回持っていることがある
- [ ] **セット/枚数を切り替えると価格表示が変わる**（定価の取り消し線も一緒に変わる）。3状態すべて実際に押して確認
- [ ] 色・サイズ・セットを切り替えると**商品画像が切り替わる**。**既定バリアント（初期選択）でも切り替わるか**を必ず見る（元テーマのJSが既定値のときだけ初期画像に戻すことがある）
- [ ] **セット商品にも画像が入っている**（カートとチェックアウトのサムネが空にならない）
      → `product.media` が0件でないこと、`variants` に画像なしが0件であることをAPIで数える
- [ ] 画像読込失敗 0 / 壊れリンク 0 / **クローン由来のJSエラー 0**
      → 切り替え操作をしてから数える。読み込むだけでは出ないエラーがある
- [ ] **`moneyFormat` など `{{ }}` を含む文字列が Liquid に食われていないか**。`"¥{{amount_no_decimals}}"` は `{% raw %}` で囲わないと `"¥"` になり、元テーマの `formatMoney` が落ちる
- [ ] 構造化データ（`itemprop="price"` / `priceCurrency`）が本家の通貨のまま残っていないか
- [ ] 390pxと1440pxの両方で崩れなし。横スクロールなし（`scrollTo(600,0)` して `scrollX` が0のままか）

## C. カート / チェックアウト
- [ ] **カートページの配色がブランドカラー**（テーマ既定の色が残っていない。「カートは空です」の画面も）
- [ ] **テーマ既定色を全部つぶしたか**。1か所ではない:
      - `config/settings_data.json` の `colors_accent_1` / `colors_accent_2` / `colors_background_2` / `colors_text` / `colors_solid_button_labels` / `colors_outline_button_labels`
      - **`current.sections.cart-drawer` の各ブロックが個別に色を持っている**（`checkout_btn.custom_color` など。ここが黄色のまま残りやすい）
      - `templates/cart.json` の `custom_colors_*`
      - 判定は「テーマ既定色のRGBを持つ要素が0個」を実測で
- [ ] 「買い物を続ける」のリンク先が**自店の商品**になっている（`settings.continue_shopping_url` に前の店の商品が残る）
- [ ] カートに入る → カートページ → チェックアウト到達
- [ ] チェックアウトの**サムネ画像が出る**
- [ ] **チェックアウト左上がブランドのロゴ**（ストア名のテキストのままにしない）
      → **Checkout Branding API は Shopify Plus 限定**。Basic等では管理画面（設定→チェックアウト→カスタマイズ→ブランディング→ロゴ）でしか入らない。手順を運営者に渡す
- [ ] 金額が正しい（バリアント価格 × 数量）

## D. フッター
- [ ] コピーライトが自社ブランド名
- [ ] **装飾（波など）と配色がブランドカラー**。テーマ既定の色が残っていない
- [ ] **謎の余白・白帯が出ていない**
      → `#MainContent` の下端と、フッターグループ最初のセクションの上端の差を測る。0でなければ原因を特定する
      → よくある原因: ①クローンの `</main>` がテーマの `<main id="MainContent">` を先に閉じ、外に出たクローンの `<hr>` が上下marginで白帯になる ②中身が空の `apps` セクションが `include_margins: true` で余白だけ作る
- [ ] **クローンの `<main>` / `</main>` を `<div>` に置換したか**（テーマのmainを巻き添えで閉じさせない）
- [ ] ポリシー6本のリンクがあり、全部開けて中身が入っている

## E. ポリシー / 法務
- [ ] プライバシー・返金・利用規約・配送・連絡先・特商法の6本
- [ ] 本文は自社の既存店を雛形に、保証日数など店ごとの違いだけ書き換え
- [ ] 6本とも**前の店のブランド名が残っていない**（本文を全文検索して確認）
- [ ] **商品ページの約束と齟齬がない**（保証日数・送料・返品条件）。裏付けのない約束は書かない
- [ ] `/policies/*`（チェックアウトのフッターが指す本物）も更新した。APIで不可なら管理画面用HTMLを出して運営者に渡した
      → トークンに `write_legal_policies` が無いと `shopPolicyUpdate` は `ACCESS_DENIED`

## E2. 表示と正式規約・登録特典の整合
- [ ] `/pages/*` と `/policies/*` は別本文として両方読む。フッター用通常ページの更新だけで、チェックアウトの正式規約も更新済みと扱わない
- [ ] 発送元の国・国内/海外・準備期間・到着期間・起算日（注文日/発送通知日）・営業日/暦日・北海道/沖縄追加送料を一覧で突き合わせる。事業者住所を発送倉庫と推測しない
- [ ] 満足保証・初期不良・機能故障・都合返品・サイズ交換を区分し、期限・返送要否・返送料・控除率・必要証拠・1注文あたり回数・返金処理日数を商品ページと正式規約で合わせる
- [ ] 登録特典前の販売価格、適用後、割引額/率、Shopify比較価格を分けて記録。定額値引きを厳密な15%と表示しない。『N枚無料』は1枚価格×有料枚数と実セット価格で検算
- [ ] クーポンを別ストアへ移植したら、対象ストア/商品/バリエーション・コード・記憶キー・適用回数・併用設定も移植先に合わせる。UIコピーだけでは完了にしない
- [ ] メール登録失敗では特典を有効にしない。割引適用エラー後の再試行で商品を重複追加しない。利用済みクーポンでも『特典を使わず購入手続きへ』の明示導線で購入できる
- [ ] 各セットの割引後金額はShopifyの実カート/チェックアウトで検収し、JPY端数を推測しない。未知の実発送元・採用保証条件はユーザー確認待ちとして分ける

## F. 事故防止
- [ ] 公開テーマ(MAIN)に書いていない（書き込みスクリプトが `role == MAIN` で中断するようにしておく）
- [ ] 商品の公開状態は最新のユーザー指定どおり。ACTIVE維持・404復旧済みの商品を古いDRAFT手順で非表示に戻していない
- [ ] 検収は**プレビューURL上**で実施（ローカルの一致だけで合格にしない）
- [ ] **ローカルの `theme_final/` が古くないか**。テーマ側を後から直していると食い違う。編集前に必ずテーマから引き直して差分を見る
- [ ] 文字列の切り出しで `find()` が `-1` を返したまま使っていないか（`s[:i] + s[k:]` でファイルが二重になる事故が起きた）
- [ ] 分割スニペットの連結が元本文と一致し、境目の重複・欠落・余分な閉じタグがない。描画後も購入ボタン・保証・比較・写真・FAQが本文ルート(`#wd-main`等)の中にある
- [ ] 375/390/430pxで保証・送料・配送日数・比較費用の文字が切れず、左右に余白がある。横はみ出しを非表示にしただけの修正にしていない
- [ ] 写真は横スワイプ・矢印で最後まで切り替わり、枚数表示とボタンの端の状態が一致。700px前後でもスナップ位置と枚数がずれない
- [ ] FAQは質問ごとに開閉でき、閉じた回答が見えず、開いた長文が切れない。タップ範囲44px以上・キーボード操作を確認
