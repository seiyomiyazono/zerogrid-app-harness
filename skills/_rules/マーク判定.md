## 位置づけと更新

基本の運用判定は[判定.md](判定.md)。本書で基本の2日・3日判定、停止・増減額、予算を上書きしない。分析は「俺らの基準では → マークの基準では → 俺の意見（エージェントの提案）」の順。同じデータ・期間に対する違いを示し、未取得・母数不足なら判定不能と明記する。

通常の判定ルール変更指示は基本へ。「マーク判定に入れて」等の明示、またはマークの発言として取り入れる助言は本書へ。運営者による基本への採用指示があった場合のみ基本側へ反映する。本書の追加・訂正は指定日、変更点、適用条件、ソースを残す。本人の発言、計算例、エージェントの解釈、運営者指定を区別し、提案を本人発言にしない。

## サイト内の目安と分母

| 区間 | 集計の考え方 | 本人の目安 |
|---|---|---|
| 商品LP訪問→カート追加 | 追加した訪問 ÷ 商品LP訪問 | 10%以上。高価格帯は8〜9%も許容（M2 15:00〜） |
| 商品LP訪問→チェックアウト開始 | 開始した訪問 ÷ 商品LP訪問 | 独立目標は未確認 |
| カート追加→チェックアウト開始 | 追加後に開始した訪問 ÷ 追加した訪問 | 独立目標は未確認 |
| チェックアウト開始→購入完了 | 開始後に購入した訪問 ÷ 開始した訪問 | 独立目標は未確認 |
| **カート追加→購入完了** | 追加後に購入した訪問 ÷ 追加した訪問 | **30%以上**（M1 12:00〜、M2 15:00〜） |
| 訪問→購入完了（CVR） | 購入した訪問 ÷ 訪問全体 | 価格帯に応じ3〜5%（M1 12:00〜） |
| 記事→商品LP | LP到達した訪問 ÷ 記事訪問 | 固定目標は未確認 |

30%はカート追加から**購入完了までを通した率**。チェックアウト開始率ではない。表の集計欄はエージェントが比較用に整理した定義であり、本人が全ツールの分母・重複排除を厳密に統一したという意味ではない。

同じ期間・流入・集計単位でそろえ、人数・セッション数・イベント発火回数を混ぜない。1人の連打を複数人の成功にしない。記事訪問と商品LP訪問を混ぜず、直接購入・別訪問での購入が含まれる場合は厳密な連続ファネルと区別する。Meta広告帰属、Shopifyの購入、Clarityの訪問は対象・同意・計測範囲が異なるので、異なる集団の件数を割って同一ファネルと断定しない。分母0は「—」、未取得は未取得。

### 価格別CVR（M1 12:00〜）

| 本人の価格例 | CVR目安 |
|---|---|
| 20〜30ドル程度の低価格商品 | 5% |
| 中間価格帯（厳密な上下限は未確認） | 4% |
| 90〜100ドル以上の高価格商品という例 | 3% |

任意の超高額商品にも一律3%を要求しない。日本円への単純換算・商品価格とAOVの混同を避ける。M3 2:45〜では間接広告からの安い流入は高CTR・低CVRでも採算が成立し得ると説明。価格だけでなく流入経路・購入準備の程度を考慮する。M2の競合売上推定で使うCVR1.5〜3.5%は推計仮定であり、この運用目標と混ぜない。

**計算例（本人が別途定めた目標ではない）**：同一集団が順番に進む場合、ATC10%×追加後購入30%=全体CVR3%。ATC10%で全体4%なら追加後40%、全体5%なら50%が必要。チェックアウト前後に任意の60%等を割り当ててマーク目標としない。

## 採算・平均注文額・継続購入

- M2 15:00〜：AOVは主力価格の+20〜40%、理想+50%。M1 16:18〜の「最低2倍」より新しい説明を優先。基本判定.mdのAOV倍率は変更しない。
- M1 18:00〜：CACをAOVの50%未満とする目安。広告費だけを獲得費用に使い同一集計範囲なら概ねROAS2超相当。CACと広告CPAの費用範囲、新規顧客と注文の単位を確認する。損益分岐は原価・送料・手数料・返品等を踏まえ商品別に計算し、ROAS2を普遍的な黒字保証にしない。
- M1 18:00〜：LTV:AOVを3:1以上という再販力の目安。初回注文だけで実績LTVを確定しない。継続購入の希望値で初期赤字を自動許容しない。
- M3 31:26〜：LP改善はCVR単独でなく訪問者あたり収益・利益で比較する。安い注文が増えてCVRが上がっても、採算改善とは限らない。

## 段階別の読み方（本人発言を運用順に整理した解釈）

| 段階 | 確認するもの | 使い方 |
|---|---|---|
| 配信前 | 目標CPA・損益分岐・購入/計測の動作 | M6 16:17〜とM1 12:00〜。本人購入テスト。M6のテスト利益率20%は2025-11の助言で、初日全広告の停止条件ではない |
| 配信直後 | 配信・到達・CTR/CPC/CPM・動画冒頭 | 目安との差を兆候として読む。少数の訪問・購入で勝敗を断定しない |
| 訪問/カートが蓄積 | ATC・区間別人数・CVR | 10%／30%／価格別3〜5%と比較し、落ちる段階を特定する |
| 購入が蓄積 | CPA・AOV・訪問者あたり収益/利益 | 施策前後の採算比較。率が上がっただけで勝ちとしない |
| 増額 | 獲得費用・利益・期間全体の傾向 | 単日の上下に反応せず、増額後の採算を見る |

初日・2日目・3日目別のCVR/ATC目標、統一最低サンプル数は確認できていない。データ不足の具体的な件数を併記し、未確認の100クリック・50購入等を本人ルールとして追加しない。

期間は文脈を分ける。M4 11:45〜は短期変動を見る際に7日以上へ視野を広げる助言。M5 12:35〜は2つのLPを比較し300〜400ドル消化で負けた側を切った実例で、どの配分単位の消化額かは保存ノートでは厳密に確定できない。7日待機義務にも、広告単体300ドル停止ルールにも変換しない。M5 20:15〜の初日ボット流入によるCVR水増し分母は本人事例で、確認せず自店の低CVRをボットのせいにしない。

## 組み合わせ診断（仮説として使う）

| パターン | マークの説明に沿って調べること |
|---|---|
| CTR低・フック率低 | 冒頭で関心を作れているか（M1 8:50〜） |
| CPM高・CTR低・CPC高 | 広告の弱さ、市場競争、続く場合は表現やインフラ（M1 5:15〜/20:21〜） |
| CTR高・ATC低 | 興味本位のクリック、広告とLPの期待のズレ、LPの説得不足（M1 20:21〜、M2 15:00〜）。LPだけが原因と断定しない |
| ATC良・追加後購入低 | 決済不具合・手続き負担・条件への不安。カート→開始、開始→完了の実数で場所を分ける（M1 12:00〜、M2 15:00〜） |
| CVR良・AOV低・採算悪い | オファー・セット・関連する追加購入の提案（M1 20:21〜） |
| CVR改善・収益悪化 | AOV・利益の低下を含めて比較（M3 31:26〜） |

「CTR6%・ATC3%」等は本人の診断例で、確率を保証するものではない。各KPIを単独で停止命令にしない。提案した施策と実施済み変更を分けて報告する。
