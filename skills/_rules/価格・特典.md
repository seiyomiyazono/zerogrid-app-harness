# 価格・特典の共通ルール

商品ごとの金額・原価・割引率・保証はブランド内の01-商品情報.mdを唯一の正本にする。[ワンドライ](../1-ワンドライ/01-商品情報.md)。共通フォルダに別の価格表を複製しない。

- 比較価格、セール販売価格、メール登録後価格を区別する。検討中の案、ユーザーの承認、Shopifyへの反映と検収を混同しない。
- 価格末尾・割引額・適用単位・回数・併用条件・コードはブランド別の商品データで決める。全商品共通の金額をここに固定しない。過去の共通4,000円OFF指定より、商品別の最新本人確定を優先する。ただし確定だけで実販売設定を変えない。
- 粗利の目標は登録後80%近辺・最低77%。原価のみ控除の算式、換算為替、送料の仮定、未確認費用を併記し、純利益率とは呼ばない。
- セール表記・比較根拠・期限・在庫は確認済み事実とユーザー指定を区別する。
- 方針確定時は商品データの確定欄と状態を更新し、サイト反映の有無を明記する。反映が依頼された時に商品設定・クーポン・ストア表示・cart/checkout・広告文を照合し、証拠を残して実反映欄を更新する。保留中は現行の公開物・広告文を変更しない。

整理前の横断価格表は[履歴](../履歴/価格・特典-整理前-20260906.md)に保管。今後の値の更新先はブランド別の商品データ。
