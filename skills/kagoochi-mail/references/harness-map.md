## 入力

SKILL.md の手順3の表「今の出どころ」は、上から探してあった所で止める。ハーネスの中では、その表の①②を下の列に読み替える。公開している店のページがあれば、それが先。

| SKILL.md が要る物 | ハーネスのどこから |
|---|---|
| 値段・セット・保証の日数・送料（手順2a） | `<商品名>/00_入口.md`・`02_損益分岐.md`。特商法と返金ポリシーは `ec-ad-ops/references/store-legal.md` と店の公開ページ |
| 商品の事実（仕様・使い方） | `<商品名>/01_商品理解の基盤/A_商品の事実.md` |
| 店のレビュー（手順2b） | 公開している店のページ。まだ無ければ `<商品名>/08_店/` の店の HTML に出ている声 |
| 専門家（手順2d） | 店の公開ページと、`<商品名>/07_納品/記事/<名前>/` の記事に名前つきで出ている人 |
| 場面の写真・声の写真（手順3） | Shopify の Files → `<商品名>/08_店/` の絵 → 無ければ生成 |
| 疑い3つ（手順5。3通目の声を選ぶ基準） | 店の FAQ。無ければ記事の移植表の「残った疑い」 |

## 道具

| 場面 | 回し方 |
|---|---|
| ターミナル | `node skills/kagoochi-mail/scripts/build.mjs <作業場>/店の値.json`・`python3 skills/kagoochi-mail/scripts/check.py <作業場>` をそのまま回す。初めての Mac は、このスキルのフォルダで `npm install` と `pip3 install playwright pillow && python3 -m playwright install chromium` |
| 審査 | `claude` コマンドが使えれば `審査を回す.py <作業場>`。使えなければ `--頼みだけ` → 書いた本人でない係に頼みを渡す → `--答え <ファイル>` |
| Shopify に入れる | `references/shopify設置.md` の「入れる順」。有効にする所は、ターミナルでは本人にチャットで聞き、アプリでは承認カードで聞く（`skills/_アプリでの読み方.md`） |
