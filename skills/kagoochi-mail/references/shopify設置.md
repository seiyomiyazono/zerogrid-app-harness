# 4通を Shopify Messaging＋Shopify Flow に載せる手順

読む人: kagoochi-mail の手順10b・10cで、4通を店の Shopify に入れる Claude。
読む時: 審査が通り、K7 まで○になった後。上から順に（「9 有効にする」だけは本人の「いいよ」の後）。
読まなくていい条件: 4通を作るだけで、まだ載せない時。

管理画面は、ブラウザを操作する道具で開いて Claude が押す。道具は、画面を撮る・座標で押す・字を打つ、の3つができれば何でもよい（例: Claude のアプリの内蔵ブラウザ・Claude in Chrome・Playwright の3つのどれでも。特定の道具の名前に頼る手順は書かない）。人に頼むのは下の表の5つだけ。

| 人に頼む事 | いつ | 頼み方 |
|---|---|---|
| Shopify のログイン | ブラウザにログインの画面が出た時 | 「開いたブラウザで Shopify にログインしてください」と1行 |
| テスト送信の宛先 | 「8 テスト送信」の前 | 「テストのメールをどのアドレスに送りますか」と1行 |
| Flow（無料のアプリ）を入れてよいか | 「アプリを確かめる」で Flow が入っていなかった時 | 「Flow（無料）を入れます。いいですか」と1行 |
| ドメイン会社でレコードを足す | 店のドメインから出したいと本人が言った時だけ | 足すレコードを全文で見せる |
| 有効にしてよいか | 「8 テスト送信」の後 | 「8 テスト送信」の表の最後の行 |

| 印 | 意味 |
|---|---|
| 公式 | Shopify の説明書に書いてある事（出典は `references/道具の選び方.md` の「出典」） |
| 動画 | 他の店の管理画面で、その並びが映っていた事（Ecom Mastery の Shopify 標準の2本） |
| 確かめた | うちの店の画面で通した事（かっこの中に日付と店） |
| 未確認 | うちの店の画面でまだ通していない事。初めて組む店で通し、通ったら印を「確かめた（日付・店）」に変える。書いてある通りに動かなければ、そこで止めて画面の言葉を写し、この表を直してから続ける |

画面の言葉は、日本語の管理画面に出る言葉で書いた。英語の画面では、自動化＝Automations、ワークフローを編集＝Edit workflow、チェックアウト離脱を回復する＝Recover abandoned checkout。

Messaging・メールの編集画面・Flow の中身は、ページの文字を読む道具では読めない（別の場所から読み込まれる面のため）。画面を撮って見て、座標で押す。ブラウザの幅は1440・高さ900にする（狭いと「カスタムLiquid」が出ない）。画面を開いた直後は白いままの事があり、最大30秒待ってから撮り直す。

## 6 Flow で流れを組む

5 で作った自動メールを一覧から開き、「ワークフローを編集」を押すと Flow が開く。型に入っている並びは「放棄された → オンラインストアでの放棄か → 合計が0円より大きいか → 10時間待つ → その後買っていないか（「最後の離脱から24時間より長い」と AND）→ 在庫があるか → メールを送る（Send marketing email）」（確かめた 2026-11-17・ここちドライ）。型の条件は残し、その後ろに下の表の行を上から順に足す。変えた物は自動で保存される（右下「保存済み」）。閉じるのは右上の ×。隣の「ワークフローをオンにする」は押さない。

手順の足し方: 手順の下の灰色のつまみを押す → 出た「+」を押す → 「アクション」か「条件」→ アクションは検索の欄に `wait` か `marketing email` と打って選ぶ。上から順に作る。もう出来ている手順の間に条件を入れる時は、①間の線を1回押す（確かめの箱なしで線が消える）→ ②上の手順の「+」で条件を足す → ③条件の True のつまみを、下の手順の箱の上の端（入口）までドラッグして離す（箱の真ん中に落としても付かない）。線は、消す時のほかは押さない（押すと消えて、下の手順が「接続されていない」になる）。

| # | 足す物 | 入れる値 | 印 |
|---|---|---|---|
| 1 | 型の「待つ」を開く | 数を `1` にする（単位は hours のまま＝1時間）。数を打ったら Tab で確定する | 確かめた（同上） |
| 2 | 1通目（型の「メールを送る」） | そのまま | 確かめた（同上） |
| 3 | 待つ | `82800`（秒。23時間＝放棄から24時間） | 確かめた（同上） |
| 4 | 条件「まだ買っていない」 | 「変数を追加」→ 検索に `customerHasNoOrderSinceAbandonment` → 1件目 → 「等しい」のまま、True の丸を押す（初めはどちらも選ばれていない） | 確かめた（同上） |
| 5 | 行4の True の先に メールを送る（2通目） | 「7 メールにコードを入れる」で `e2` | 確かめた（同上） |
| 6 | 待つ | `86400`（秒。24時間＝放棄から48時間） | 確かめた（同上） |
| 7 | 条件「まだ買っていない」 | 行4と同じ | 確かめた（同上） |

「待つ」の単位の一覧（seconds・hours）は、道具によっては開いても選べない。選べない時は単位を変えず、型の「待つ」は時間で、足した「待つ」は秒で数を入れる。

4通目の専用コード（Admin API リクエストを送信 → 顧客のメタフィールド `kagoochi.code4`・`kagoochi.deadline4`・`kagoochi.deadline4_at` を書く）は未確認で、置かなくてよい。置かない時、4通目は3通目のコード（期限なし）の文で届くので、偽の締切にはならない。

## 7 メールにコードを入れる

6通（`e1` `e2` `e3` `e3b` `e4` `e4b`）を、Flow でその「メールを送る」の手順を足した時に1通ずつ入れる。型のデザインを Shopify の出来合いの段で組み直さない。見た目は全部 `liquid/<通>.liquid` の中にある。

宛先を「すべてのお客様」（お知らせを購読していない人も含む）に変えられるのは、型「チェックアウト離脱」で作ったメールだけ。「独自コード」のメールは宛先が購読者に固定で変えられない（確かめた 2026-11-17・ここちドライ）。だから6通とも、型「チェックアウト離脱」のメールに「カスタムLiquid」の段を1つ入れる形で入れる。この形は、メールの末尾に黒い「フッター」（店の住所と配信停止）が付く。

| # | やる事 | 印 |
|---|---|---|
| 1 | メールの編集画面を開く。1通目は「5 自動メールを作る」の行4の続き。2通目からは、Flow で足した「メールを送る」の手順を押す → 左の面の「テンプレートを選択」→ 型「チェックアウト離脱」→「選択する」 | 確かめた（2026-11-17・ここちドライ） |
| 2 | 左下「セクションを追加」→ 検索の欄に `liquid` → 「カスタムLiquid」→ 左のコードの欄を押して全部選び（cmd+a）、`liquid/<通>.liquid` の全文を打つ。クリップボードからの貼り付けは効かない。打つ前に画面を撮り直し、欄が選ばれているのを見てから打つ（ブラウザの幅が戻ると座標がずれて空振りする） | 確かめた（同上。約12,000字が1回で入り、字の化けは無かった） |
| 3 | 入ったかを確かめる。コードの欄の最後の行の番号が `wc -l` の行数＋1・上の帯に「すべての変更が保存されました」（出ない時は、終了の後に Flow の手順の「最終更新日時」が今の時刻になっているのを見る） | 確かめた（同上） |
| 4 | 出来合いの段を消す。見出しの段・「チェックアウト離脱」の段を1つずつ押し、段の右上の赤いごみ箱を押す。頭の「ヘッダー」（店名）は消せないので、押して右上の目の印で「ヘッダーは非表示」にする。末尾の黒い「フッター」は消せず隠せないので残す | 確かめた（同上） |
| 5 | 「件名」「プレビューテキスト」に `dist/subjects.json` の同じ通の件名と前置き文を打ち、「宛先」を押して「すべてのお客様」を選ぶ | 確かめた（同上。6通とも選べた） |
| 6 | 右上の PC とスマホの印でプレビューを切り替え、`shots/<通>_600.png`・`_390.png` と段の並び・文字の寄せ・ボタンの寄せ・横のはみ出しを見比べる。スマホのプレビューは画面の幅で変わる指定が効かず、字の大きさと横並びが PC のまま出るので、それは崩れに数えない（届いたテストのメールで見る） | 確かめた（同上） |
| 7 | 左上「終了」→「ページを離れる」。下書きで保存され、Flow に戻る（戻った後、30〜40秒白いままの事がある） | 確かめた（同上） |

入れた後でコードだけを入れ替える時は、Flow の手順 →「メールを編集」→ メールの中の「カスタムLiquid」の段を押す → コードの欄で全部選んで打ち直す（確かめた 同上）。型を替えたい時は、編集画面に「テンプレートを変更」は無いので、その「メールを送る」の手順をごみ箱で消して足し直す。足し直す時、「テンプレートを選択」の左の「下書き」から前の下書きを選べる（件名に付く「のコピー」を消す）。
