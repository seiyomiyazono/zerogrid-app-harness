# カゴ落ちメールの送る道具とドメイン（店ごとに選ぶ） <!-- 例 -->

読む人: カゴ落ちメールの仕組みを自分の店に入れる人と、それを手伝う Claude。
読む時: 送る道具を決める時、ドメインを準備する時。
読まなくていい条件: 道具とドメインの認証がもう済んでいる店。

仕組みに入れるのは「4通の型・文面・検査」だけ。Shopify の数字は `mcp__shopify__shopify_graphql`（例 `abandonedCheckoutsCount`）で取り、載せる手順と人に頼む事は `references/shopify設置.md`。送る道具とドメインは、使う店がそれぞれ自分の物を使う。

## 結論（2026-10-20 に公式の説明書で確かめた）

| 店の状態 | 選ぶ物 |
|---|---|
| 既定（Shopify の店は全部） | **Shopify Messaging（旧 Shopify Email）の「放棄されたチェックアウト」の自動メール** |
| デザインを見本どおり細かく写したい・API で全部組みたい・分岐を細かく増やしたい | Klaviyo |

先に言葉をそろえる。「レジでメールを入れて買わずに離れた人」は、Shopify では「放棄されたチェックアウト」と呼ぶ（`abandonedCheckouts`）。カートに入れただけでレジに進まなかった人は、メールアドレスを入れていないので、どの道具でも送れない（Klaviyo でも、前にメールを押した等で本人が分かっている人だけ）。だから使う自動メールは「放棄されたチェックアウト」の物。

## 比べた結果

| 項目 | Shopify Messaging | Klaviyo |
|---|---|---|
| 同意していない人に送れるか | 送れる。型「チェックアウト離脱」で作ったメールは、Flow で足した2通目からでも宛先を「全てのお客様」に変えられる（画面で確かめた）。「独自コード」のメールは購読者に固定 | 送れる。「一度も購読していない」人は止められていなければ届く（公式） |
| 費用 | 放棄チェックアウトの自動メールは**いつも無料で、月の通数にも数えない**（公式）。他のメールは月1万通まで無料、その後1,000通ごと1ドル | 無料は有効な連絡先250件・月500通まで（公式）。500件で月20ドル前後（他社の比較記事）。同意していない人も連絡先に数える |
| 4通と待ち時間 | Shopify Flow（無料アプリ）を入れると編集できる。待つ手順は1回90日まで（公式） | 流れの画面で自由に組める |
| 「前に買ったか」で分ける | Shopify Flow の条件で分ける（管理画面では未確認） | 分岐の部品がある |
| 新しいアカウント | 要らない。どの Shopify の店にも入っている | 店ごとに作り、Shopify とつなぐ |
| 仕組みが組めるか | メールと自動メールを作る公開の API が無い。Claude がブラウザを操作する道具で管理画面を押して組む | テンプレートと流れを作る API がある（流れの API はベータ版・作った後は直せない） |
| 見本のデザインを写す | 「カスタム Liquid」の段に HTML を入れて写せる（50KB まで。末尾に黒いフッターが付く）。「独自コード」（500KB まで）はフッターが付かないが、宛先が購読者に固定 | HTML をそのまま入れられる。見本も Klaviyo で作られた物 |
| 戻せるか | 新しい放棄チェックアウトの自動メールを一度入れると、古いメールには戻せない（公式） | 消せば止まる |

Shopify を既定にする理由は3つ。①放棄チェックアウトのメールは何通送っても無料、②同意していない人に送る設定が公式にある、③新しいアカウントが要らないので、誰の店でも同じ手順で入る。

## ドメイン（どちらの道具でも同じ）

| 手順 | 誰が | 中身 |
|---|---|---|
| 1 | 仕組み | 道具の画面から、足すレコード（CNAME・TXT の数行）を取り出して見せる。Shopify は 設定 → 通知 → 送信者のメール → ドメインを認証。Klaviyo は「送信ドメイン」（例 `send.店のドメイン`） |
| 2 | 店の持ち主 | ドメインを買った所（例: お名前.com・Squarespace）にログインし、そのレコードを足す |
| 3 | 仕組み | `dig` で外からレコードを確かめる。DKIM と DMARC が見つからなければ送り始めない |

携帯3社（docomo・au・softbank）のアドレスは認証の無いメールをはじきやすい。アルコットのカゴ落ち100件のうち約4分の1がこのアドレスで、arukoto.shop は DMARC はあるが Shopify の認証（DKIM）が外から見つからなかった（2026-10-20）。

## 管理画面で確かめた事（2026-10-20 アルコット）

| 事 | 結果 |
|---|---|
| 放棄チェックアウトの自動メール | 作られているが**無効（オフ）**。メール1通・離脱から10時間後・件名 Complete your order。過去30日の送信は0通 |
| 4通・待ち時間・「前に買ったか」の分岐 | 「ワークフローを編集」を押すと Shopify Flow が開く。Flow は**入っていない**ので、入れる（無料アプリ）までは1通・時間だけ |
| 宛先「全てのお客様」 | 公式の説明書では放棄チェックアウトだけ選べる。メール編集を開くと今の文面が下書きに戻るため、画面では開いていない |
| HTML | 入る。メールに「カスタム Liquid」の段を足すと HTML か Liquid を書ける。上限50KB、配信停止の変数（`unsubscribe_link` か `unsubscribe_url`）が必須。.html の読み込みもできる（公式） |
