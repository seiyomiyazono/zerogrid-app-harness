# harness-map — ec-retarget-static の入力と置き場を、ハーネスの商品フォルダに読み替える表

読む人: ハーネスの中でリタゲの静止画を作る Claude と、毎日の運用でリタゲの数字を読む Claude
読む時: SKILL.md の手順1の前に1回。リタゲの広告セットの数字を読んだ日
読まなくていい条件: 新規向けの静止画（ec-static-ads）を作る時

**一行で: SKILL.md が「商品フォルダ」「設計のフォルダ」「納品の場所」と書いている物を、ハーネスの `<商品名>/` のどこから取り、どこに置き、道具をどう回すかを決める。** いつ作り始め、どこで待つかは `ec-ad-ops/SKILL.md` の「工程の継ぎ目」の表。

## 索引（詰まった所 → どこを読む）

| 詰まった所 | 読む所 |
|---|---|
| 相手が新規で聞いた事・客の疑い・商品の事実・写真をどこから取るか | 入力 |
| 設計・出来た絵・結果の記録をどこに置くか | 置き場 |
| ターミナルとアプリで道具をどう回すか | 道具 |

## 置き場

| SKILL.md の書き方 | ハーネスの中 |
|---|---|
| 設計のフォルダ（設計・`生成の記録.md`・`配信の条件.md`・`口座の数字_<日付>.json`） | `<商品名>/06_原稿/リタゲ/設計/` |
| 生成したままの絵・指示文 | ターミナルは `<商品名>/06_原稿/リタゲ/_作り/`。アプリは、絵はアプリが置いた場所（`skills/_アプリでの画像の作り方.md`）のまま使い、指示文だけ `<商品名>/06_原稿/リタゲ/設計/` に置く |
| 納品の場所（`画像.png`・`ヘッドライン.txt`・`本文.txt`） | `<商品名>/07_納品/Static Ads/リタゲ/<広告の名前>/` |
| 結果と選んだ記録（`_結果.tsv`・`_選んだ記録.tsv`） | ターミナルはスキルの `references/見本/`。アプリは `<商品名>/06_原稿/リタゲ/`（下の「道具」の `--記録`） |

社内の今の商品（商品フォルダがハーネスの形でない物）は、設計を `（アプリには同梱していない資料） 広告/リタゲ静止画/設計/`、納品を `（アプリには同梱していない資料） 広告/リタゲ静止画/<広告の名前>/` に置く。

## 道具

| 場面 | ターミナル | アプリ（`skills/_アプリでの読み方.md`） |
|---|---|---|
| 検査・指示文・切る・選ぶ・戻す道具 | `python3 skills/ec-retarget-static/scripts/<道具>.py …` をそのまま実行する。初めての Mac は `pip3 install pillow numpy` | `run_skill_script` で実行する（script に `ec-retarget-static/scripts/<道具>.py`、product に商品フォルダの名前。フォルダの道は商品フォルダから書く: `06_原稿/リタゲ/設計`） |
| 記録の置き場（`samples.py pick`・`samples.py record`・`sync_results.py`） | `--記録` を付けない（スキルの `references/見本/` に書く） | `--記録 06_原稿/リタゲ` を付ける（アプリの道具が書けるのは商品フォルダの中だけのため。読むのは、スキルに入っている記録と両方） |
| 画像の生成（手順7） | アプリの画像作り（`image`）（`aspect` は `portrait`、`refs`（添付する絵） に参考の絵・実物の写真の順） | `skills/_アプリでの画像の作り方.md` の `image`（`aspect` は `2:3`、`steps` は1段、`refs` に `skills:ec-retarget-static/references/見本/<型のフォルダ>/<ファイル>` と商品フォルダの写真の順） |
| 口座の数字を取る（手順12） | Meta の広告のコネクタ（`ads_get_ad_entities`。`level` は `ad`）の返事を、そのまま保存する | 毎日の運用が読んだ広告ごとの数字を、`name`・`adset_name`・`campaign_name`・`amount_spent`・`omni_purchase`・`omni_purchase_values` の6つの欄の並びにして保存する。アプリに広告ごとの数字を読む道具が無い時は、この手順はターミナルで実行する |
| 相手の人数を確かめる（手順1） | Meta の広告マネージャのオーディエンスの推定の人数を読む | 自分では開かない。運営者に人数を聞く。リタゲの相手を口座にまだ作っていない時は、まとめた相手2つ（`references/枠組み.md`）で作る |
| 勝った絵を見本に足す（`samples.py add`） | 実行する | 実行しない（スキルのフォルダに書けない）。勝った絵の名前と数字を報告に書く |
| Meta に広告を作る・配信する | 運営者にチャットで聞く。作る時は停止で | 承認カードにする |
