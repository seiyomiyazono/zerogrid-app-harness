# 写真の指示文（ChatGPT に渡す型。どの店でも同じ）

読む人: 店を作る Claude（pdp-tsukuru の「絵を作る」手順）。
読む時: `店の設計.md` の 5（絵）を書いた後、アプリの画像作り（`image`） を呼ぶ前。毎回。
読まなくていい条件: なし（図・イラスト・札・アイコンも同じ型で作る）。

> うちでは アプリの画像作り（`image`） の代わりに Codex の image_gen に、同じ指示文と添付（`refs`（添付する絵） に書いた絵）を渡す（`references/harness-map.md` 2章）。

絵は言葉だけで頼まない。**参考の絵を一緒に渡し、「この作りのまま、写っている物と文字だけうちの物に替える」と頼む。** 参考の絵は `絵の一覧.tsv` の5列目。道具には絶対パスで渡すので、頭に `pdp-tsukuru/` を付けたパスにする。

## 関門（通った絵だけ `_gen/` に残す）

| 関門 | 通る条件 |
|---|---|
| 1 | 商品が写る絵には、商品の実物写真を `refs`（添付する絵） の1枚目（添付1）に付ける。使う写真は `商品写真/照合.md` で ○ の物だけ |
| 2 | 全部の絵に、参考の絵を `refs`（添付する絵） に付ける（商品が写る絵は添付2、写らない絵は添付1）。参考の絵は、頼む前に1枚ずつ開いて、何が・どこに・どんな作りで写っているかを `店の設計.md` の 5 の「参考の絵が起こす気持ち」に書いてある |
| 3 | 形・数・向き・姿勢が要る絵（人の姿勢・置き方・部品の数・並べる数）は、「形・数・向き・姿勢を描かせる時」の5つを指示文に入れる |
| 4 | 画像の中の日本語は、一字一句 `prompt` に書く。`{}` が1つでも残っていたら呼ばない |

### 共通の頭（商品が写る絵の prompt の先頭に、このまま入れる）

> 添付1は商品の実物の写真。{商品の形と色}。この形・色・部品の数を1つも変えない。{付ける面の決まり}画像の中の日本語は、参考の絵と同じ書体・同じ太さで（参考が明朝なら明朝、ゴシックならゴシック。prompt に書体の名前と「参考と同じ太さ・同じ大きさ・同じ字の間」を書く）、下に書いた字の通りに一字一句。字が崩れたら、その絵は使わない。

商品が写らない絵（札・ロゴ・アイコン、商品の無い人の顔・イラスト）は、1文目と2文目（添付と商品の形）を外す。

### 主役ごとの頭（共通の頭の次に入れる。主役は `画像の置き場.md` のその絵の行）

| 主役 | 入れる文 |
|---|---|
| 商品・手と商品・物 | 実写の写真に見える事（一眼レフで撮った商品撮影、自然光）。場所は日本の家（地が「透明」の絵は、場所を入れずに白一色の地）。人は入れないか、手・腕だけ。顔は写さない |
| 人の体と商品・人の体 | 実写の写真に見える事（自然光）。場所は日本の家（地が「透明」の絵は白一色の地）。日本人で{客の年代と性別}。顔は写さない。体の形は自然に |
| 人の顔・人の顔と商品・専門家 | 実写の写真に見える事（自然光）。場所は日本の家か町（地が「透明」の絵は白一色の地）。日本人で{客の年代と性別}の顔が写る。表情は自然に |
| 場面 | 実写の写真に見える事（自然光、日本の家か町） |
| 図・イラスト | 写真にしない。参考の絵と同じ線の太さ・同じ塗り方 |
| 札・ロゴ・アイコン | 参考の絵と同じ形・同じ質感・同じ線の色。平らな図形にしない。背景は `絵の一覧.tsv` の「地」の列で決める: 「不透明」は参考の絵と同じ地、「透明」は白一色の地（`絵を置く.py` が四隅からつながる地を透明に抜く）、「透明（白い線）」は白い線が見えるように濃い一色の地（空色 `#469cd3`）に白い線 |

`絵の一覧.tsv` の「地」が「透明」の絵は、主役が何でも（写真・専門家でも）白一色の地で作り、家や部屋の背景を入れない。（`絵を置く.py` が四隅からつながる地を抜く。背景があると「抜け残り」で落ちる）。商品の色の16進の値の3つの数が全部 `C8`（200）以上の時は、地を抜かせると商品の明るい面まで抜けるので、「背景は透明（透過 PNG）」と頼んで最初から透明の絵を作る。白い商品を白い箱に置く絵（セットの絵）は、商品の色を変えずに、縁の細い影と布の縫い目で形を見せる。

### 参考の絵の写し方（主役ごとの頭の次に入れる。全部の絵で使う）

> 添付2（商品が写らない絵は添付1）は参考の絵。構図・写す角度・物の大きさの割合・文字と吹き出しと札の置き場所と数・光と質感・余白を、この参考の絵のまま写す。替えるのは次だけ: {替える物}。文字は参考の絵と同じ場所に、次の字に替える: {替える文字}。参考の絵の商品・人・動物・ブランドの名前とロゴは1つも残さない。

色は、参考の絵がどちらの店の物でも次の3つにそろえる: 濃い字は紺 `#001B74`、強調は空色 `#5BA7D8`、注意は赤 `#E84545`。ここちドライの参考の絵（ピンクと赤）もこの3色に替える。

### 横送りの写真（`yoko-1`〜`yoko-8`。1枚に役目を1つだけ）

| 枚 | 参考 | 役目 | 文字 |
|---|---|---|---|
| 1 | ワンドライの1枚目 | 得の結果を1枚で。商品が画面の5割以上 | 見出し1行＋1行（ページの見出しとは別の文。`見出しの指示文.md`）、透ける吹き出し3つ（商品の事実を2〜8字）、右上に金の保証の札、右下に線のアイコン3つ |
| 2〜8 | ここちドライの2〜8枚目 | 参考の絵のその枚の役目のまま（得を部位で指す・前の物との比べ・仕組み・保証 のように、参考の絵を開いて読む） | 参考の絵と同じ数・同じ場所 |

同じ役目が2枚あったら片方を作り直す。文字入りは8枚中6枚以上。

### 吹き出しの質感（参考の絵に吹き出し・カプセルの札がある時、prompt に足す）

> 吹き出しは平らな白い丸にしない。透けるガラスの玉（またはすりガラス）のように、後ろの写真がうっすら透けて見える白い地。縁は白く光る細い線で、左上に小さな白いハイライト。黒い影は付けず、外側にやわらかい白い光。字は紺（真っ黒にしない。太さは参考の絵と同じ）、要の数字か言葉だけ空色で少し大きく。

### 形・数・向き・姿勢を描かせる時

絵を作る AI は、言葉だけだと形・数・向き・姿勢を取り違える（`見本/03_くぼみの読み違い.md`・`見本/04_横向きがうつぶせ.md`）。次の5つを指示文に入れる。

| # | 指示文に入れる物 | 書き方の形 |
|---|---|---|
| 1 | カメラの位置と向き | 「カメラは◯◯の側に立ち、◯◯から写す」 |
| 2 | その状態なら必ず見える物を2つ以上 | 「◯◯と◯◯が見える」 |
| 3 | 取り違えやすい別の状態を1つ、打ち消す | 「◯◯にしない」。1つだけ |
| 4 | 数は数字で言う | 「◯つ。それより多くも少なくも描かない」 |
| 5 | 商品の形は「0 商品の形」の言葉のまま | 部品の数・位置を言い換えない |

2 の「見える物」は、`画像の置き場.md` のその絵の行の「見えるべき物」に書く。

### 人と一緒に写る商品の大きさと付け方（主役に「商品」と、「人」か「手」が入る絵は全部）

絵を作る AI は、絵ごとに商品の大きさと付ける場所を変える（`見本/17_大きさと付け方が絵ごとに違う.md`）。どの絵でも同じ商品に見えるように、次の順で作る。合う・合わないの線はこの節が正本で、ほかの文書はここを指す。

| 順 | やる事 |
|---|---|
| 1 | prompt に `{体との大きさ}` と `{付け方}` を入れ、続けて「商品の大きさと付け方は、この2文のとおり。絵に合わせて大きくも小さくもしない」と書く |
| 2 | 人と商品が写る絵のうち、付け方がいちばんよく見える1枚（手と、肩か腰の両方が写る絵）を基準の1枚に決め、この1枚だけを先に作る。添付は 1＝商品の実物写真・2＝参考の絵・3＝`商品写真/付け方_<番号>.png` で、「付ける場所と向きは、添付3の実物の写真と同じ」と書く。付けている実物の写真が取れなかった商品は添付3を付けず、`{付け方}` の文だけで作る |
| 3 | 基準の1枚を開き、下の「測り方」で大きさの比を測り、付け方が「0 商品の形」の4つ（場所・当たる面・向き・通り方）と同じかを見る。比が 0 の値の ±25% の外か、4つのどれかが違えば、基準の1枚を作り直す。合ったら、作った本人でない Opus に、基準の1枚・`商品写真/付け方_<番号>.png`・「0 商品の形」を渡して同じ4つと比を見させ、「違う所 0件」と返ってから 4 へ進む（基準の1枚の誤りは、添付した全部の絵に写る） |
| 4 | 残りの絵には全部、基準の1枚を添付3として付け、「商品の大きさ・付ける場所・向きは添付3と同じ。構図と人は参考の絵のまま」と書く。「参考の絵が無い・足りない絵」の表で添付するとある絵（縦長・比べる段の1枚目）は添付4にする。「付け方2」の絵は、その中の1枚を2つ目の基準にして同じ順で作る。参考の絵の構図（真正面・真横・比べる段の真ん中）だと付け方が見えない絵は、人と商品の向きを基準の1枚と同じカメラの向きに替え、文字と札の置き場だけ参考のままにする。参考の絵の景色（建物・海・看板）は写さず、場所は `{使う場所}` にする |
| 5 | 1枚作るたびに測り、`画像の置き場.md` の「大きさの比」に `<縦か横>÷<部位> <測った値>（<0 の値>）` と書く（例 `縦÷手の長さ 0.80（0.85）`。基準の1枚は頭に `基準・`）。0 の値から ±25% の外は作り直す。指示文の言い方を変えても線の外が合わせて3回続いた絵（数えるのは照らし合わせの係が測った値）は、参考の構図をやめ、基準の1枚を下絵にして文字と札だけ足す。比べる部位が1つも写っていない絵だけ `対象外（<写っている物>だけで、比べる部位が無い）` と書く |

体の物差し（日本人の大人の目安。絵の比を出すためだけに使い、客の体の数字として文には書かない。正本は `scripts/体との比.py` の 物差し）:

| 部位 | 女性 | 男性 |
|---|---|---|
| 手の長さ（手首から中指の先） | 17cm | 19cm |
| 手の幅（親指を除く4本の付け根） | 7.5cm | 8.5cm |
| 肩の幅 | 38cm | 43cm |
| 頭の縦（あごから頭の上） | 22cm | 23cm |
| 腰の幅（正面から見た腰の左右） | 30cm | 32cm |

女性・男性は、絵に写る人（`{客の年代と性別}`）の方を使う。0 の値は自分で割らず、「0 商品の形」の「体との大きさ」の行（`体との比.py` の出した文）から、その辺とその部位の数を写す（`絵を置く.py` が、写した数が設計と同じかを見る）。

測り方: できた絵を Read で開き、商品の辺の両端と、同じ絵に写る体の部位の両端の位置を読んで、商品÷部位を出す。測る辺は、カメラを横に回しても縮まない縦の辺（商品が寝ている絵は、縮んでいない方の辺）。部位は、商品と同じくらいの奥行きにある物を、手の長さ → 手の幅（握っている絵）→ 腰の幅 → 肩の幅 → 頭の縦 の順で、最初に両端が縮まずに見える物にする。作った本人が測った数は、手順10b・11c の見比べと照らし合わせで、書いた本人でない Opus がもう一度測る（`照らし合わせの指示文.md`）。

人と一緒に写さない商品・体に付けない商品（置く・敷く・持つだけの物）も、「0 商品の形」の3行は書く。付け方の「場所」は置く所か持つ手、「当たる面」は下になる面か握る所を書く。

### 参考の絵が無い・足りない絵

| 絵 | 作り方 |
|---|---|
| セットの絵（`set-1`〜`set-3`） | 参考はワンドライのセットの絵（縦長）。「白い地に、添付1の商品を{セットの数}つ、参考の絵と同じ重ね方で並べた商品撮影。全部同じ形・同じ向き。人も手も字も入れない」 |
| 色の札（選ぶ所が色の時。色ごとの16進の値は「0 商品の形」に1つずつ書く） | 「添付1の商品の{色の名前}の面だけを正方形に切り取った、布や素材の寄りの写真。字は入れない」。`_gen/iro-<番号>.png` に書き、スクリプトの `OPT_IMG` に入れる |
| 人の声のまとめの絵（`koe-matome-1`・`-2`。2枚で1つに見える） | 2枚目を作る時に1枚目も添付し、「字の大きさ・間・顔の並べ方を添付とそろえる。同じ顔を2回使わない」と足す。名前・苗字・コメントの文・日といいねの組み合わせは参考の絵から1つも使わない。2枚の件の間・吹き出しの幅・字の色が並べて見たで2回続けて挙がったら、AI で作り直さず、作った絵から顔の丸だけを切り、参考の絵と同じ寸法で字と吹き出しを描く（見本16） |
| 使い方の絵（`tsukaikata-N` は PC 用の横長、`tsukaikata-sp-N` はスマホ用の縦長） | 同じ場面を、横長と縦長の2枚で作る。縦長を先に作り、横長を作る時に縦長を添付して同じ人・同じ場所にそろえる |
| 比べる段の2枚（`kurabe-mae`・`kurabe-uchi`） | 2枚目は1枚目を添付し、「添付の写真を下絵にし、物の位置を変えずに、描き足すのは次だけ」と頼む（別々に作ると角度と部屋が変わる）。ページでは真ん中に左右へ動かす棒と丸い取っ手が乗るので、人の体を絵の横の真ん中に置き（頭から脚まで）、比べる物（前の物・うちの商品）は真ん中から外した左か右に置く、と prompt に書く（真ん中に置くと取っ手が隠す。見本15） |
| 体の下に敷く・当てる商品を、人と一緒に写す絵（ベルトで巻く商品は次の行） | 商品が体に隠れないように、商品が体の外に上下か左右へはみ出して見える角度と大きさで頼む（「商品の端が、体の両側に見える」と prompt に書く） |
| ベルトを商品の穴に通して体に巻く商品（輪・バックルの形の物）を、人と一緒に写す絵（この行だけを当てる。上の「体の下に敷く・当てる商品」の行は当てない） | 「0 商品の形」で体に触れる部品（例: 粒の面）が体に当たる向きを、ベルトの通り方で1文にして prompt に書く（例「ベルトは体に沿って横に走り、輪の穴を左右に通り抜ける。穴の口はベルトの向きを向き、粒の面は体に押し当たる。穴をカメラに向けて輪を体に平らに付けた形にしない」）。最後の「〜にしない」を「形・数・向き・姿勢を描かせる時」の3の打ち消しに使い、別の打ち消しを足さない。同じ向きを `画像の置き場.md` のその絵の「見えるべき物」にも書く。カメラは体の斜め横（45度）から写す、と書く（真後ろ・真正面から写すと、輪が細い棒に見えて商品と分からない。見本14）。参考の絵が真正面の構図でも、人の体を45度回して穴が見える向きにする。言わないと、AI は穴を前に向けて体に平らに貼った形に描き、触れる部品が体から離れる（見本14） |
| 線や札で部品を指す絵（商品のまわりに線・丸い印・部品の名前が並ぶ絵） | 「線・丸い印・字と商品は全部、画像の端から15%内側に収める。地は端から端まで一色」と prompt に書く（参考の絵と縦横の比が違う形でできた時に、上の印や商品の端が切り落とされないように。見本18。地が一色の絵は `絵を置く.py` が切らずに地を足して比を合わせる） |
| 宣言の止め絵（`sengen-poster`） | 動画がある店でも無い店でも作る（動画の止め絵と、動画が無い時の絵の両方に使う）。動画がある店は、動画の1コマを `ffmpeg -i _gen/sengen.mp4 -frames:v 1 _gen/sengen-poster.png` で切り出す。無い店は、ここちドライの宣言の絵を参考に静止画で作る |

## 手順（この順に）

1. `絵の一覧.tsv` の上から1行ずつ、参考の絵を開いて見て、`店の設計.md` の 5 のその名前の行を埋める
2. 1枚ごとに prompt を「共通の頭 → 主役ごとの頭 → 参考の絵の写し方 →（要る時だけ）吹き出しの質感・形と数の5つ」の順に組み、穴を全部埋める
3. 参考の絵の縦÷横が 1・1.5・0.67 のどれからも 5% を超えて離れている絵（`絵の一覧.tsv` の「元の大きさ」で計算する）は、近い形で頼み、「主役と文字は全部、上下左右の端から15%内側に収める」を prompt に足す（写真は `絵を置く.py` が真ん中で切って比を合わせる。地が一色の写真は切らずに地を足す。札・ロゴ・アイコン・図・イラストは切らずに地を足して合わせるので、横長の札やロゴは、作った後に PIL で中身の外枠まで切ってから `_gen/` に置く。上下の空きを残すと中身が小さくなる）
4. アプリの画像作り（`image`） を、`refs`（添付する絵）＝[商品の実物写真（商品が写る絵だけ）, 参考の絵, 基準の1枚（人と商品が写る絵だけ。prompt では「添付3」）, そろえる元の絵（「参考の絵が無い・足りない絵」の表で「添付する」とある絵だけ。prompt では「添付4」。基準の1枚を付けない絵では「添付3」）]、`aspect`＝参考の絵の縦横（正方形は square、縦長は portrait、横長は landscape）、`out_path`＝`<店のフォルダ>/_gen/<名前>.png` で呼ぶ。同時に3枚まで
5. できた絵を、参考の絵と並べて開く（`scripts/並べ絵を作る.py` で1枚に12枚までまとめて開いてよい）。商品の形と色が「0 商品の形」と取り違えない（数えるのは、部品の数・色・コードやつなぐ口の有無と本数・付ける面や敷く向きが違う時と、覆う範囲が倍以上違う時。端の位置の少しの違いでは作り直さない）・人と商品が写る絵は大きさの比と付け方が「人と一緒に写る商品の大きさと付け方」の線の中・字が指示文の通り・「見えるべき物」が写っている・参考の絵の商品や犬やロゴが残っていない、の5つを確かめ、5つとも良い時だけ `画像の置き場.md` のその行の「合う」に ○、1つでも外れたら「×（外れた物）」と書く。× は 2 に戻って作り直す。同じ絵で2回続けて × なら、指示文の言い方を変える
6. 全部 ○ になったら `python3 scripts/絵を置く.py <店のフォルダ>` で `img/` に置き、置いた後の `img/` の絵をもう一度並べ絵で開いて、切れた字・白い四角・抜けすぎた所が無いかを見る
