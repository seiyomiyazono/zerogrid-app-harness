# スケールの判断表（Sam Piliero式 pack構成）

作成：2026-09-29。出典は承認済みソース Sam Piliero の動画25本（主張と動画ID・時刻は `knowledge/sam-piliero-meta-ads.md`）。時期で言うことが変わった点は、発信が新しい方を採用している。構造そのもの（新規獲得CBO＋pack、既存客キャンペーン、packの分け方＝誰に×つらさ）は EC共通ルールの `出稿.md` が正。この表は「今の数字を見て、次に何をするか」だけを扱う。

言葉：
- **目標**＝1つの数字。その商品の目標CPA（商品フォルダの `03_広告の数字` の値。ad-funnel ではブランドの plan に書く）。幅で持たない。
- **勝ち**＝新規獲得キャンペーンの消化の5%以上を使い、CPAが目標以下の広告。3日・7日・14日の窓すべてで見て、セール日は除く。
- **見込み**＝消化5%以上だが目標未達、または目標達成だが消化5%未満。
- **増分**＝広告マネージャの列「アトリビューション設定を比較→増分アトリビューション」。Metaが広告のおかげと見なした購入だけ。次に増やす1円の返りの目安。
- **最低消化**＝広告セットの「平均日額の最低」。新packだけ目標CPA×1、7日で外す。合計は全体予算の20%まで。
- **最大消化**＝広告セットの消化上限（%）。疲れてきたpackを止めずに弱める時だけ使う。

## ①新作が必要なタイミング

新作は「疲れてから作る」のではなく、常に回す。基本のリズムと、前倒しする合図を分ける。

| 今の状況 | 判断 | やること |
|---|---|---|
| いつも | 定期便 | 1〜2週に1pack（4〜8本）を出す。最低消化中のpackが常に1つある状態にする。入稿は曜日を固定（例：月曜）、分析と制作指示は木・金 |
| 新しい勝ちが出た（3・7・14日のどの窓でも消化5%以上・CPAが目標以下） | すぐ作り直し | その勝ちの作り直しを最低3本、次の定期便で出す。変えるのはフック・見出し・冒頭の場面・背景など中くらいの変更。色違いは不可 |
| 見込み（消化は大きいのにCPAが目標の10〜15%上） | 弱点を直す版 | クリック→カート率・カート→購入率・CPC・CPM・CTRをアカウント平均と比べる。CPC/CPMが高くCTRが低い→購入の呼びかけを前に。クリックは安いが買われない→冒頭5秒と30秒付近でオファーを明示。カート・購入手続きで落ちる→深追いしない |
| 勝ち広告の窓が悪化（30→14→7→3日→昨日の順にCPAが上がる）、または消化上位の広告でフリークエンシー・CPMが上がり、カート追加単価・購入手続き開始単価も上がる | 疲れの始まり | 定期便を前倒しし、その勝ちの作り直しpackを出す。疲れた広告は止めず、次の段（③）で最大消化を検討 |
| アカウント全体のCPAが7日・14日とも目標を超えた | 新作不足 | 新作の本数を増やす前に、勝ちの作り直しが出ているかを確認。出ていなければ最優先で作る。新しい案を追いかけない |
| 勝ちが1本もなく、新packが最低消化ちょうどしか使わない状態が2回続いた | 型が合っていない | 競合で長く出ている広告の型（同じ型が何本も並ぶもの）を写した新コンセプトを出す。アバター×つらさの組み直しも検討 |

補足：Samは疲れを「フリークエンシー何回」という数字では決めていない。判断は窓の悪化と先行指標（カート追加単価・購入手続き開始単価）。ad-funnel既定の「疲れ＝累計フリークエンシー2.5以上、またはCTR・フック率・クリック後購入率のうち2つが低下」は自社基準として併用する。

## ②新作をどこに入れるか

| 新作の種類 | 入れ先 | 名前 |
|---|---|---|
| 勝ち広告の作り直し | 同じ「誰に×つらさ」で番号だけ新しいpack | pack<番号>_<誰に>_<つらさ>（作り直し元を広告名に書く） |
| 新しいつらさ・新しいアバター | そのつらさ専用の新しいpack | pack<番号>_<誰に>_<新しいつらさ> |
| 見込みを直した版 | 元と同じ「誰に×つらさ」の新しいpack | 元のpackには足さない |
| 種類の違う広告が混ざった回 | 種類ごとに別pack（1pack＝1アバター×1つらさ） | |
| 実績のある勝ち広告（新作ではない） | 既存客キャンペーンにも複製して入れる。スケール用・興味関心の広告セットを作る時は勝ちだけを入れる | 元の広告は止めない |
| 値引き・セット・新商品の告知 | 既存客キャンペーン | 新規客向けの初回特典は入れない |

禁止：柔軟な広告（複数の版を1広告にまとめる形式）で出す。単体広告で出し、同じコンセプトの版を同じpackに並べる。既存のpackへ新作を足す（その広告セットの学習が組み直しになる）。均等予算のテスト用キャンペーン。着地を変えての出し直し（着地を試すなら別pack）。

## ③packが増えた時：止める・弱める・まとめる

基本は止めない・まとめない。packは積み上げるもので、負けpackは最低消化を外せば自然に消化が細る。

止める前の確認順（Zvson3Jiz2M、2026-08-25）：①目標達成中なら残す ②悪い1日だけではないか ③計測の変更・データ不具合ではないか ④セール直後ではないか ⑤ピクセルは正常か ⑥増分の列で見ても悪いか ⑦カート追加・購入手続き開始に良い兆しはないか ⑧バズっているなら残して最大消化 ⑨想定外の年齢・性別に出ていないか。ここまで全部当てはまらず、目標CPAの2倍で購入0、または3倍使ってCPAが目標より50%以上悪いなら止める。

| 今の状況 | 判断 | やること |
|---|---|---|
| 新packが7日経った | 必ず | 最低消化を外す（勝ちも負けも）。学習はリセットされない |
| 最低消化を外した後、消化がほぼ0 | 放置でよい | 止めなくてよい（費用はかからない）。数が多くて見づらい時だけOFF |
| アカウント全体が目標を達成している | 止めない | 関係なくなった広告（終わった販促など）以外は止めない |
| アカウント全体が未達で、広告が購入0のまま目標CPAの2倍を使った | 止める | その広告だけOFF。配信が付いている理由を先に見て、作り直しの材料にする |
| 広告セットの増分CPAが、キャンペーン平均の増分CPAより大きく悪い（増分ROASでおよそ半分以下） | 止める候補 | 7〜14日の合算で確認してからOFF |
| 目標ぎりぎりのpackが消化の大半を取っている（例：消化の70〜80%） | 弱める | 最大消化を今の占有率より10〜20ポイント下に設定（80%→60%）。止めない |
| 消化上位の広告が疲れてきた（①の疲れの始まり） | 弱める | その広告セットに最大消化。作り直しpackを並行で出す |
| 最低消化の合計が全体予算の20%を超えそう | 間引く | 古い順に最低消化を外す。20%以内に収まるまで新packを待たせる |
| 「似たpackをまとめたい」 | まとめない | まとめ直しは広告セットの学習をやり直させる。勝ちを別の場所に使いたい時は、複製して入れる（元は残す） |

## ④予算の増やし方（縦）と横の広げ方

### 縦：増額

判断は14日と7日の合算で、通常の数字と増分の数字の両方を見る。予算を変える日は他を触らない。

| 今の状況（7〜14日合算） | 判断 | やること |
|---|---|---|
| 30・14・7・3日・昨日のどれかでCPAが目標超え | 待つ | 増額しない。悪化が続くなら①の新作へ |
| 全窓で目標以下、増分CPAも目標以下、上回り幅が20%未満（CPAが目標の80〜100%） | 小さく増やす | 20〜30%増。大きな予算なので金額で考えてよい |
| 増分CPAが目標の約1.5倍良い（増分CPAが目標の約3分の2以下） | 大きく増やす | 50%増 |
| 増分CPAが目標の2倍以上良い（増分CPAが目標の半分以下） | 倍々 | 倍にし、目標に近づくまで繰り返す |
| 増額後2〜3日でCPAが悪化 | 触らない | 購入単価が上がっても、カート追加単価・購入手続き開始単価が横ばいなら戻る見込み。増額前の普段の振れ幅と比べる |
| 増額後7〜14日で、広告の数字とストア全体（Shopify総売上÷全広告費、利益）が目標以内 | 次の一段 | 同じ表で次の増額 |
| 7〜14日たっても目標超え | 減らす | 増額分を戻し、効率の改善（新作・弱めるpack）へ |

### 横：広げる

| 今の状況 | 判断 | やること |
|---|---|---|
| 縦で増額したい（いつも） | 内側の横展開 | 新規獲得キャンペーンの中に、新しいつらさ・アバターのpackを足す（控えのpack3・pack4を順に使う）。縦と同時に回すとROASが横ばいのまま消化が伸びる |
| 目標以上のpackが複数あり、ROASに差がある | 全部残す | 最高ROASのpackだけ残すのは誤り。目標以上なら積み重ねる |
| 勝ちが3本以上そろった | 任意で追加 | 勝ちだけを入れた興味関心の広告セット（商品と遠い興味）を新規獲得キャンペーン内に。目的はピクセルの届く範囲を広げること |
| 年齢・性別などで弱い層に消化が偏っている | 除外しない | 価値ルールで入札を10〜20%下げ、勝ち広告を入れた新しい広告セットで比べる |
| 曜日で成績差がはっきりしている | 寄せる | 良い曜日に予算を寄せる（価値ルール・予算スケジュール） |
| 別の国・別の倉庫・別の価格 | 別キャンペーン | 既存の別キャンペーンがあればそのまま |
| 月の消化が約10万ドル（約1,500万円）を超え、勝ちが安定 | 上限系を検討 | 目標コスト＝目標CPAぴったり。最大化（最高ボリューム）と同じキャンペーンで混ぜない。消化0の日が出る前提 |

## ⑤既存客キャンペーンの回し方

| 今の状況 | 判断 | やること |
|---|---|---|
| 立ち上げ | 小さく | 日5,000円、広告セットは購入180日（必要なら全期間から180日を除くもう1つ）。packで分けない |
| フリークエンシーが低く、CPAが新規より良い | 上げる | 少しずつ増額 |
| フリークエンシーが高い（Samの例では既存客14.8で使いすぎ）、または増分ROASが大きく落ちる | 下げる | 既存客にお金をかけすぎ。予算を下げる |
| 新規獲得キャンペーンの「オーディエンス区分」で既存客への消化が目立つ | 除外を確認 | 購入者180日の除外が効いているか確認 |
| 入れる広告 | | 新規側の勝ち広告、追加セット・まとめ買い・新商品・販促。初回特典は入れない |

オファーは値引きでなく、いつでも使える特典を3〜6個用意し、2〜4週ずつ回す（まとめ買い、購入特典、お試しセット等）。

## ⑥毎日・毎週見るもの、触ってはいけない時

| 頻度 | 見るもの |
|---|---|
| 毎日 | アカウント全体の消化・購入・CPA（目標CPAと比べる）。カート追加単価・購入手続き開始単価。購入0のまま目標CPAの2倍を使った広告。消化・CPA・CPMの急変（直近3・7・14日の平均から標準偏差2つ分）。ピクセルの購入件数とShopify注文数の差（10〜20%以内） |
| 週1（曜日固定） | 増分列でのアカウント・キャンペーン・広告の評価。勝ち・見込みの一覧（3・7・14日）。当たり率（勝ちの本数÷出した本数）。オーディエンス区分（新規／エンゲージ／既存の消化比率）。年齢・性別・配置・曜日の内訳。最低消化の合計（20%以内か）。翌週の制作指示 |
| 増額のたび | 7〜14日後に、広告の数字とストア全体（Shopify総売上÷全広告費、利益）を確認 |

触ってはいけない時：
- 構成を作った・変えた日から7日間（止めるのは明らかに悪い広告だけ）。
- 増額後2〜3日の悪化。
- 予算を変える日に、構成や広告を同時に変える。
- アカウントが目標を達成している時に、目標未満の広告を消化順に並べて止める。
- 「学習制限」表示だけを理由に止める。
- 勝ち広告の着地を変えて出し直す。
- キャンペーンの作り直し（デスループ）。

## Samの基準と自社基準が違う所

- 止める基準：Samは「アカウント未達の時だけ、購入0で目標CPA×2」。ad-funnelの切る基準（購入0で目標CPA×2、最後の購入から目標CPA×2で直近5件未満、良く見積もっても基本基準未満、入替えで後継が入った）はこれと両立する。ただしSamは「アカウントが目標達成中は止めない」を上に置く。
- 疲れ：Samは数字の閾値を出していない。自社の「累計フリークエンシー2.5以上など」を併用する。
- 新作の判定期間：Samは7〜14日。ad-funnelの旧テスト（2日で昇格判定）は旧運用。
