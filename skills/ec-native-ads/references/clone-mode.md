# 完コピモード — 勝ち広告の型を写して日本語で出す(2026-08-17新設)

**発動**: 運営者が「勝ち広告を写して」「完コピで」と指定したときだけ。既定は通常モード(診断リサーチ→オリジナル3案)。

**思想**: フィード広告もゼロから設計しない。**実際に金を使って回っている勝ち広告の骨を借りる**。

## 写すもの / 写さないもの

| 写す | 写さない |
|---|---|
| **本文の骨格**(何を何番目に言うか。フックの型・悩みの提示順・メカニズム説明の位置・商品の遅出し位置・保証の出し方・P.S.の使い方) | 本文そのもの。**日本語で書き下ろす** |
| **ヘッドラインの型**(どういう絞り方をしているか) | ヘッドラインの文言 |
| **画像の型**(構図・撮り方・小道具・生活感の出し方・文字の乗せ方の有無) | 画像そのもの |
| **CTAの位置と回数、段落の長さ、改行のリズム** | — |
| オファーの構造(保証日数・セット段・特典の並べ方) | 価格の実数(日本の帯に置き換える) |

**他社の広告文をそのまま翻訳して自社広告として出さない。**言語も商材も客層も違うので、そのまま訳しても機能しない。
写すのは「どう組み立てているか」で、中身はこの商品のために書く。

## 手順

1. **収集** — Hookdで本命競合の広告を全部取る。`min_ad_copy_length=800` で長文だけに絞り、`run_time` の長い順に並べる。
   `ads_per_brand_limit=0` にして1ブランドの全量を見る(既定の4本だと本命の型が拾えない)
2. **型の抽出** — 上位3〜5本を並べて、共通する骨格を箇条書きにする。ビート単位で「何を何番目に言っているか」を書き出す
3. **日本語で書き下ろす** — 抽出した骨格に沿って本文を書く。語彙は日本の当事者から採集したものを使う(`copy-structure.md` の語彙採集は**省略しない**)
4. **運営者実戦ルールを全部通す** — 一人称/売り手の口ぶり排除/付かない特典を書かない/P.S.偽物注意/P.P.S.祈り締め。SKILL.mdの鉄則がそのまま適用される
5. **画像** — 元広告の構図を再現する。欧米人が写っているものは、スクショを Codex の imagegen に渡して日本人版を作る
6. **検収** — 通常モードと同じ品質ゲートを通す。「型を写した」ことは品質を下げる理由にならない

## 本数

コピー軸では**本命競合が回している型の数だけ**作る(型が3つなら3本)。フックのメカニズムを変えて割るのは通常モードのルールで、
完コピモードでは**元の型の違いがそのまま本数の違いになる**。
