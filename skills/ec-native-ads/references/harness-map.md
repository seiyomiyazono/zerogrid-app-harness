## 2. 診断シートの欄 → どこから埋めるか
| 診断シートの欄 | ハーネスのどこ |
|---|---|
| 購入者（語り手のプロフィール） | B ③・F。05 の「使ってよい人物」 |
| 認知レベル | F・04 の pack の段階（無自覚＝Problem／悩み自覚・解決策探し＝Solution／商品を知っている＝Product） |
| 1 正確には誰か（どんな瞬間） | B ④の原文（使っている最中の体の絵）・H 3章 |
| 2 何を試して失敗したか | D1・D2・H 7章。**その pack のヴィラン（04 のアングル）を主にする** |
| 3 何に疲れ切っているか／深夜2時の痛み | B ④・⑥ |
| 4 原因を何だと信じているか | H 3章「責めている物」 |
| 5 原因ではないと思っているもの（アングル） | **H 1章の根本原因**（お客さんがまだ聞いた事のない原因） |
| 6 次を試すのが怖い理由 | B ⑥（壁）・D（お金を払ってだめだった原文） |
| 採集語彙 15〜20個 | B ④・⑤の原文から、番号つきで抜く |
| 問題への命名案／問題側UM | **H の根本原因の名前をそのまま使う**（別の名前を作らない） |
| 解決側UM | E の「他にないもの」・仕組みの名前、I の細部 |
| 競合が使っているUM | C（＋I の「競合の言い方」） |
| Authority 計画 | B の体の仕組みの出どころ（学会・論文）を「〜だそうです」の伝聞で。05 の人物の決まりに従う |

## 3. VSL・静止画とそろえる物（同じ商品で言う事を割らない）
- **根本原因は H の1つ。** 名前も同じ言葉。ネイティブ広告だけ別の原因を言わない
- **ヴィラン（試してだめだった対策）は、その pack の1つを主役にする。** 購入遍歴でほかの物に触れてよいのはネイティブ広告の型（1購入＝1段落）のためで、主役は変えない
- 仕組みの名前・商品の呼び名は 05 と E のとおり
- 着地は 04 のとおり（ネイティブ広告の着地は advertorial＋native 用が基本：ec-ad-ops の article.md）
