# メガプロンプトと修正プロンプト

出典: Konvert講座 Bonus(承認済み)。思想: **AIは食わせたものの質までしか出せない**。4入力のどれかをサボると出力がその分壊れる(リサーチ欠け→誰にも刺さらない一般論 / ストーリー欠け→主張の羅列 / 商品欠け→薄い雰囲気コピー / 実例欠け→リズムが広告定型)。

## 本体テンプレ(4入力を全部埋めてから実行)

```
あなたは長文ネイティブ広告のコピーライター。以下の素材だけを使い、
フィードで個人投稿に見える広告本文を書け。

[RESEARCH] ← copy-structure.mdの診断シートをそのまま貼る
(6診断質問・認知レベル・クアドラント・支配的感情・採集語彙15-20・問題への命名案)

[STORY ELEMENTS]
語り手タイプ: Mirror / Authority / Caregiver / Skeptic Convert / Insider / Accidental Expert
  (複合可。実測の強型=Authority×Skeptic Convert。選び方: 必要なのは信頼性か共感か/最大の反論を潰せるのは誰か)
テーマ(書かずに滲ませる): 恥→贖い / 悲嘆→回復 / 恐れ→希望 / 怒り→正義 / 無力感→主体性
起点事件(1シーン・五感・作り話にできない細部): 外的ショック/内的限界/ニアミス/気づき
低点: 静かな諦め(クライシス禁止)
変容: 漸進タイムライン(Day/Week)+予期しない発見+他者検証のセリフ+アイデンティティ変化
脇役: 1人1証明(配偶者=外部検証、知らずに使った家族=プラセボ否定)

[PRODUCT]
何か / メカニズム(精密な数字入り) / 差別化(なぜ既存手段では要件を満たせないか) / 証明 / オファーと保証

[EXAMPLES]
同じ語り手タイプ・同じ認知レベル・同じトーン・近い長さの当たり広告2-3本の全文
(Hookd search_adsで調達、無ければ knowledge/chris-walters-analysis.md から)

[指示]
- 長さ: 短尺300-600語 or 長尺900-1300語(指定)
- フック形式: hooks-closes.mdから指定(3案はメカニズム違いで)
- 骨格: copy-structure.mdの14ビート。商品名は55%地点まで出すな
- 採集語彙を自然に散らせ。マーケ語(「画期的」「革命的」)禁止
- クローズはリスク反転を含め、指定形式で
- EXAMPLESのリズムとトーンに合わせろ(内容は写すな)
```

## 修正プロンプト集(品質ゲートで症状別に使う。指示は必ず講座用語=座標を持つ語で)

- フックが弱い →「[形式名]の形式でより明確に書き直せ。もっと具体的で生々しく」
- 低点が刺さらない →「低点を拡張しろ。フラストレーションでなく**諦め(resignation)**を入れろ。五感の細部を」
- 変容が曖昧 →「Day/Weekの漸進で見せろ。**予期しない発見**を足せ」
- セリフが嘘くさい →「実際の話し言葉に。短く」
- クローズが売り込み臭い →「リスク反転と許可を足せ」
- 実例と似てない →「実例のリズムに寄せろ。短文多め・対比多め・具体性多め」
- 単調 →「同じ感情レジスタに3段落以上いる箇所を割れ。パターン割り込み(質問/一行セリフ/告白)を1つ入れろ」
- 長すぎ/短すぎ → 残す骨格(フック・低点・変容・クローズ)を指定して調整

## 品質ゲートのチェックリスト(全案に適用。★=運営者ルール2026-08-15)

1. ペーシング: 音読してつまずく所は? 低点・変容は遅いか、メカニズムは速いか
2. 対比: 状態/知識/努力/権威/アイデンティティ/期待のうち2つ以上入っているか
3. 感情順序: 負→正→行動か。同レジスタ3段落以内か
4. ループ: 開けた質問を全部、遅延させてから閉じたか
5. 割り込み: 3段落ごとに注意リセットがあるか(多すぎもNG)
6. 信頼の階段: 大きな主張の前に検証可能な小さな真実があるか
7. 商品の位置: 初出が55%以降か
8. クローズ: 理由スタック+トーン急変なし(フック回帰は書かない)
9. ★一人称: 全文が「自分が喋っている」ベースか。三人称の紹介文・「私たち」文体が混ざっていないか
10. ★P.S.(偽物注意×UMの一言、2文前後・伝聞形)とP.P.S.(思考予言→保証→「一旦試してみてください」→**「私はそれで◯◯なので、皆さんもそれで解決したら嬉しいです」の祈り締め必須**、3〜4文)が付いているか。P.P.S.が祈りで終わっていなければ不合格
10b. ★売り手口ぶりゼロ: 「だからこその」「〜を用意しています」「期間を長めにしました」等、オファーを自分が設計した口ぶりが1つも無いか(grep検査)。保証は「あったから買えた」「ついているし」の受け手目線のみ
11. ★ヘッドライン: 本文と別枠で存在し、その案が刺したいペインをそのまま名指ししているか(短く・遠回しにしない)
12. ★当事者ワード: 採集語彙の「当事者しか使わない語」が本文に1〜2回入っているか
13. ★解決側UM: 「この商品じゃないといけない理由」が競合の言えない形で1回以上語られているか
14. ★付かない特典ゼロ: 実際には付かない特典・付属品(冊子・おまけ・サポート)を、付くように書いていないか
17. ★人間らしさ: jp-writing-style.mdのチェックリストを通したか(文長のばらつき/改行連打禁止/文末バリエーション/話し言葉マーカー)
18. ★ユーモア: 自己開示系の軽口・自己ツッコミ・余談が1〜2箇所あるか(ゼロも3箇所以上も不合格)
19. ★自然な日本語: 音読して「人がこう喋るか?」に全文が通るか。「先に悩んでおきました」型の不成立表現ゼロ
20. ★明瞭性: 初出の名詞が全部特定できるか(「スポンジのやつ」「そういうの」禁止)。人間っぽさ=曖昧さではない
21. ★変容の語り方: 症状消失の主張でなく行動の変化で語れているか(+序盤の習慣が回収されているか)
22. ★打消し表示: 「※個人の感想です。効果には個人差があります。」が体験談の後にあるか
23. ★アナロジー: メカニズム説明に生活アナロジーが1個あるか
24. ★出会い: 語り手が体験者の時、商品との出会いが「発見」になっているか
24b. ★語り手=購入者一致: 診断シートの[購入者]と語り手の年齢・性別・立場が一致しているか。年齢マーカーが本文か締めに1つあるか
26. ★pull-forward: 時系列で進んでいるか。段落末の半分以上が「次を読まないと落ち着かない」形か。冒頭で開けた謎が中盤で回収されているか
