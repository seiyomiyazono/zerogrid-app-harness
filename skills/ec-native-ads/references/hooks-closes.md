# フックとクローズのリファレンス

出典: Konvert講座 Phase 4(承認済み)。使い方: **形式から選ばない**。読者の感情状態と認知レベル→効くメカニズム→合う形式、の順。

## フックの7メカニズム

恐れ/危険・壊れたシステム・信頼性(権威)・共感・好奇心・検証・緊急性。
フックの仕事は一つ: 読み続けざるを得ない好奇心か緊張を作る。1秒で判定される。

## フック20形式(抜粋)

| メカニズム | 形式 | 構造 |
|---|---|---|
| 恐れ | Hidden Danger | 信頼してる物+実は害+気づいてない |
| 恐れ | 正確な時刻+惨事 | 「4:42AM…4:58AM…16分」時刻の特定性が信憑性 |
| 恐れ | 正しい道の代償 | 推奨された事をした+悪化した |
| 壊れたシステム | 定番解決策の否定 | 定番+役立たず+本当の理由 |
| 壊れたシステム | システム迷走の旅 | 症状+医者は正常と言う+浪費した時間と金 |
| 壊れたシステム | 標準治療の拒否 | 皆に勧められた+拒否した+結果 |
| 権威 | 権威の限界点 | X年の資格+伝えねばならない |
| 権威 | 患者の物語+質問 | 患者の質問の引用から開幕 |
| 権威 | 意外な専門家 | 意外な職業が知ってる事(パイロットと座り方) |
| 権威 | 専門家超え | 私の症状が名医を終わらせた |
| 共感 | 生々しい恥の告白 | 恥ずかしい具体的細部を無濾過で |
| 共感 | 年齢+出現した問題 | X歳+新症状+パニック |
| 共感 | 関係への影響 | 問題が愛に及ぼした瞬間(セリフ) |
| 共感 | 見守る介護者 | あなたの家族がこの症状なら+うちもそうだった |
| 好奇心 | セリフで開幕 | 「実際のセリフ」+文脈 |
| 好奇心 | 直接の絞り込み | あなたが◯◯なら読んで |
| 好奇心 | 変容リード | 結果を先に+知っておきたかった事 |
| 検証 | 誰かが気づいた | 人が変化を尋ねた+答えに驚いた |
| 緊急性 | 季節の緊急性 | 望む結果は今始まる+パニック時期では遅い |

実測の常用ハイブリッド(Chris Walters): 「直接の絞り込み+壊れたシステム」(症状名指し→医者の3つの答え→全部間違い)と「Hidden Danger+認識リスト」。

**追加形式: 体感テスト型(JP実測スワイプ・運営者提供2026-08-15)** — 冒頭で読者にその場で身体を動かさせて症状を自覚させる。受動的な読者を1行目で能動化し、「変わった…」の自己発見が最強の認識フックになる。当事者しか反応しない=絞り込みも兼ねる。knowledge/swipe/jp-shinoda-mimibubble-ad.png参照。

## 認知レベル対応(3案の割り方の基準)

- **Problem Aware**(問題は感じてる・原因不明) → 恐れ/共感/壊れたシステム: Hidden Danger・恥の告白・年齢+問題・介護者
- **Solution Aware**(試して失望済み) → 壊れたシステム/権威/好奇心: 定番否定・標準拒否・権威の限界点・専門家超え。共感フックは新情報ゼロで無効
- **Product Aware**(商品は知ってる) → 検証/緊急/変容: 誰かが気づいた・変容リード・季節・警告サイン

デフォルト3案 = そのレベルの推奨から3メカニズムを選んで1本ずつ。

## クローズの5メカニズムと12形式(抜粋)

恐れ+出口 / 許可 / リスク反転 / 緊急・希少 / 社会的証明。開けたループを閉じ、上げた恐れに出口を与える。

| メカニズム | 形式 |
|---|---|
| 恐れ+出口 | Don't Wait警告 / 時間切れ進行 / 「私は戻れないがあなたは今日始められる」 |
| 許可 | あなたには値する / 虚栄ではない(機能の話だ) |
| リスク反転 | 保証+失うものなし / 試して確かめて |
| 緊急・希少 | 在庫警告 / 季節の窓 |
| 社会的証明 | 数字+信頼 / 共感できるためらい(「興味ある人にはリンク置いとく」) |
| 権威の再強化 | P.S.信頼スタック(「私は報酬を貰ってない。独立検査を通った物だけ」) |

**行動理由はスタックする**(恐れ+許可+リスク反転+希少)。1つだけは失敗パターン。

## P.S. / P.P.S.(必須の締め二段 — 運営者ルール2026-08-15/16改訂: どちらも短く)

クローズの後に必ず付ける。本文を読み飛ばした人が最後に読む場所でもある。長い説明はしない。

- **P.S. = 偽物注意×UMの一言(2文前後)**。テンプレ: 「外観だけ似せた模倣品がAmazonなどに出ているそうです。◯◯(UMの一言)がそろっているのが本物。公式ページからどうぞ。」— **伝聞形「〜そうです」で書く**。お手本ねぎらい: 「外観だけ似せた模倣品があるそうです。4つの機能が『同時に』そろうのが本物。公式ページからどうぞ。」
- **P.P.S. = 思考の予言→一旦→祈りで締める(3〜4文)**。テンプレ: 「『どうせ今回も…』と思ってますよね。私もそうでした。返金保証もついているので、一旦試してみてください。私はこれで◯◯なので、皆さんもそれで解決したら嬉しいです。」— 予言→自分も同じだったで武装解除→カスタマー目線の保証→「一旦」→**必ず「私はそれでいけたから、あなたも良くなったら嬉しい」の祈り(おすそ分け)で終わる**。祈りの◯◯は本文の行動変容のコールバック。**禁止**: 「だからこその返金保証です」「〜を用意しています」型の売り手口ぶり(=広告バレ)

## 失敗パターン(品質ゲートのチェック項目)

フック側: 商品から始める/曖昧/読者より劇的すぎ(「私はそこまでじゃない」)・軽すぎ(「私の悩みはそんなもんじゃない」)/回収できないクリックベイト/全員向け/認知レベル違い。
クローズ側: トーン急変(物語→急にセールス。最頻の死因)/フックと無関係/押し売り文言/弱すぎ/リスク反転忘れ/理由が1つだけ。

## アングルの最前線 — death angle(Justin Han、承認済み、発信2026-08。鮮度ルール上この節が現時点の階級上位)

死・喪失の実話風ストーリーで入るアングルが直近実測で最強: **ROAS 4.2**、かつエンゲージメント(コメント・シェア)が高いのでFBが「バイラル投稿」扱いして**CPMも下がる二重取り**。通説「ポジティブなベネフィット訴求」の真逆。構造的にはフック7メカニズムの「恐れ+検証」の複合で、14ビート骨格にそのまま載る(起点事件を喪失・ニアミスに置く)。
3案を割る時、Problem/Solution Aware向けの1本はdeath angle系を第一候補にする。
**JP置換必須**: 死の直球は日本のフィードでは通報・審査リスクが高い。恐怖の水位を「加齢・後悔・間に合わなかった」レベルに落とす(例: 「親の膝、まだ歩けるうちに」)。
