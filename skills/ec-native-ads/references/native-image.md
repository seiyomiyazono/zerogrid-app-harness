# ネイティブ画像 — スクロールを止める1枚

出典: Konvert講座 Phase 5(承認済み)+Hookd実測(Chris Walters系、未承認)+**運営者ルール2026-08-15(承認済み・最上位)**。

## 優先順位(2026-08-15改訂)

1. **第一基準 = スクロール停止力**。当事者が一瞬「うわっ」「キモっ」と手を止めるユニークさ・違和感を優先する。実例は knowledge/swipe/jp-shinoda-mimibubble-ad.png。上品な記録写真は流される
2. **第二基準 = 広告に見えないこと**(下限)。停止力を上げても「作られた広告」に見えたら失格。キモさは「本物の生々しさ」由来であること — CGっぽい誇張・ホラー演出は広告臭に戻る
3. 検収は**停止テスト**(1秒で「うわ、それ私だ」が起きるか)→**Redditテスト**(「またこれと戦ってる」で投稿できる質感か)の順で両方通す

## 核の質問(改訂)

「この問題の当事者が、スクロール中に一瞬で手を止めてしまう画は何か?」を先に問い、
その画を「記録(documentation)の質感」で作る。(見栄え・物語の分かりやすさは問わない)

## 5タイプ(講座3+実測2)

1. **睨んでいる対象物** — 毎日「まだ解決してない」と突きつけてくる物。薬のボトル、動かない体重計、失敗商品の墓場。慢性問題の当事者はその物に過敏なので見た瞬間に認識が起動
2. **誰も見ない証拠** — 問題が本当だと証明する私的な写真。症状の跡、3:12AMのスクショ、投稿しなかったビフォー。親密でわずかに不快=本物
3. **それと二人きりの瞬間** — 車の中・深夜のキッチン・待合室。問題が生む孤立をそのまま見せる
4. **臨床記録(実測追加)** — CTスキャン+緑丸注釈、首のレントゲン素通し。権威(Authority)語り手の広告で「医師が見せてくる画像」として機能。文字なし・注釈は丸1つまで。実測ではタイプ1の変種として「カビだらけの競合品ボトルを持つ手」(敵製品の劣化画像)も勝ちパターン — ただし実在他社ブランドを合成で汚すのは日本では信用毀損リスクが高く、JPでは無名の「市販スプレー」等に置換する
5. **症状部位のマクロ(キモ系・実測追加=運営者スワイプ)** — 問題の起きている身体部位を不快なほど近くで撮る。生理的な「うわっ」で確実にスクロールが止まり、部位そのものが「何の広告か」を1秒で伝える。スクロール停止力が最も高いタイプで、**迷ったらまずこれを検討**。Metaの「不快画像」ポリシー水位に注意(グロ・体液の直接表現は不可、質感のキモさまで)

選び方: **まずタイプ5で作れないか検討**(停止力最優先)→ コピーの「くそ、まさにそれ」文の内容で 物の話=1 / 症状・結果=2 / 孤独=3 / 権威フック=4。**1画像=1パンチ、欲張らない**。

## ルール

- **POV**: 観察者でなく当事者視点。自分の手や体を見下ろす構図、スマホ画質
- **綺麗にしない**。強い浴室照明・散らかり・不利な角度。プロダクション価値は「売る意図」の証拠
- テキスト・ラベルを載せない
- **Redditテスト**: 「またこれと戦ってる」というキャプションでRedditに投稿して違和感がないか。あれば作り直し
- 最終3問: ①当事者は実際にこの写真を撮るか ②コピーの特定の瞬間か(雰囲気でないか) ③1秒で何の問題か分かるか

## Codex の imagegen に渡す言葉

Codex 内蔵の imagegen で作る(「綺麗に撮る」系の道具は真逆なので使わない)。プロンプトに必ず入れる要素:

```
smartphone photo, first-person POV looking down at [対象], harsh bathroom/kitchen lighting,
cluttered counter in background, slightly tilted amateur framing, no text, no logos,
mundane and unglamorous, looks like a photo taken to show a doctor / post on Reddit
```

- タイプ4(臨床)は: `coronal CT scan of [部位], radiology film look, dark background, single green ellipse annotation, no text labels`
- 生成物に文字が湧いたら再生成(AI文字は一発でフェイクとバレる)
- 実在ブランドのロゴ・パッケージは生成しない(JP: 信用毀損/商標。ENでも訴訟リスク)
