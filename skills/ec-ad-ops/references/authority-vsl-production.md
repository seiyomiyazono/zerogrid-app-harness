# 権威VSL（ohisama型）の作り方 — 声・口パク・画・音・検品・納品の細かい決まり（2026-10-01）

> 今の権威実写の作り方は [video-formats/authority-live-video.md](video-formats/authority-live-video.md) が正。台本は `vsl-script` スキル。このファイルは、そこから指されている 声・口パク・字幕・音・検品・納品の細かい決まりの置き場（画像・色・動かす指示・動画化の形は [live-action-vsl.md](live-action-vsl.md) が上書きする）。

下の各項目は 運営者 の指摘から決まったもの（経緯は _旧/creative-rules.md、原稿の決まりは creative-foundation.md）。

## 0. 流れ（1本）

1. **台本**（成果物④のページで承認をもらう）→ 2. **素材**（新規の静止画→動画、口パク）→ 3. **組み立て**（ブロックごと）→ 4. **全体の音**（BGM・効果音）→ 5. **検品** → 6. **納品**（④のページに動画＋行ごとの完成画）→ 7. **素材庫へ登録**

ひな形（コピーして使う）：`templates/authority-vsl/data_example.py`・`full_example.py`
- `data.py` … 台本（行＝(段, 文, 画の説明, 素材指定)）
- `full.py` … 全尺の組み立て（ブロック定義・BGM・効果音・モーショングラフィックス）
- 道具：`scripts/vsl_block.py`・`vsl_auto.py`・`vsl_edit.py`・`mg.py`・`register_assets.py`・`syncscore.sh`

## 1. 台本の決まり

- **作る前と納品前に `references/script-checklist.md` を全部確認する**（これまでの指摘の一覧）

台本の形と中身は vsl-script の決まりが正。
- 書いた後に**矛盾チェック**：前後の主張、記事の人物設定・事実（例：開発の相手、年数）、商品の正本（価格・保証・言わないこと）
- 読み：名前・数字は仮名でTTSへ（vsl_auto.READ に足す）。字幕は元の表記

## 2. 声

- 声は**スタメン**（ハーネス/共通ルール/音声.md）から1人に絞る。**別人物の直接発話だけ**スタメンの別の声（例：怒鳴り声は [shouting][furious] で数テイク作り最も強いものを1.0倍で）
- **台本全体を eleven_v4 で1回で読み上げる**（2026-10-02 運営者承認「声もこっちの方がいい・アバターと声が合っていて最高」。full.py の master_take）。v4 は1回1万文字まで読めるので約2,700字の台本は継ぎ目なし＝声が途中で変わらない。区間ごとに別々に読ませるのは不可（同じ声でも声質・調子が変わる）
  - v4 の文字時刻は終わりの方で止まることがある → 時刻は forced alignment（vsl_auto.force_align）で取り直す
  - v4 は voice_settings.speed が効かない（v3 も同じ）。速さは後から変える
  - 旧 v3 は1回約9分30秒（速くする前の長さ）で途切れ、2回に分けた継ぎ目で声が変わった。v3 を使う時だけ、2つ目を1つ目の最後の4行から読ませて捨て、seed違い3案から MFCC・高さが近いものを選ぶ
- 速さ：間を0.18秒に詰め、承認済みのテンポ（約6.6字/秒）になる倍率をかける（v3＝1.2倍、v4＝0.9倍）。区間ごとに伸び縮みさせない
- 音量：声だけを loudnorm で −13 LUFS にそろえる（声のモデルで元の音量が変わる）。BGM・効果音を入れた全体は6章の約 −12 LUFS
- 読み上げが内容フィルタ（403 content_against_policy）で止まった時は、止まった段落の前後で2回に分けて読み、継ぎ目は上の v3 の手順（2つ目を1つ目の最後の4行から読ませて捨てる）で合わせる
- **読みの確認**：数字・同じ字で読みが分かれる語は仮名で渡す（例：8か月→はっかげつ、その夜→そのよる）。専門語は言い換える。作った声は whisper で該当行を聞き取り確認する

## 3. 口パク（話し手が映るカット）

- **基本は HeyGen Avatar IV（2026-10-02 運営者確定「オーロラ使ってと言うまでは常にHeyGen」）**。サブスク（Pro）のクレジットで、ブラウザ操作（surasura の統一ブラウザ）で作る。10秒で約3クレジット。SyncNet 確信度6.6・ずれ1コマ（合格）
  - 手順：顔の行の声を全部つなぎ（間に無音0.6秒）、**1本だけ**HeyGenで作る → 切り分けて各行へ（scripts/heygen_lipsync.py）。写真＋声（Voice Mirroring はオフ）、アバター IV、縦向き、1080p
  - HeyGen は縦9:16で出す。元の動画は 9:16（原稿の基盤 4-3g）で組み、フィード用の 4:5 は 9:16 から顔の位置で切り出す
- **オーロラは 運営者 が指定した時だけ**：イレブンラボAPIの「クリエイティファイ・オーロラ」（1秒約890クレジット＝高い）。映像を0.08秒遅らせる
- 話し手の行の直後は、最後の顔のまま止める（黒くしない）
- 口パクを作り直す前に、作り直す範囲と費用の見込みを先に伝える（声を変えると顔のカットは全部作り直しになる）
- 不採用：声を渡す方式の Seedance/Wan/MiniMax（ずれる）、声の伸び縮み（片言）、別声への変換（声が変わる）

## 4. 画

- 悩み・問題は白黒、解決・商品はカラー。※イメージは、その画面のセーフゾーンの内側の右下に、読める大きさで（原稿の基盤 4-3g）
- 新しい場面：ChatGPT（Codex）で実写の静止画（**プロンプトは必ず [realistic-image.md](realistic-image.md) の型で書く**：スマホで撮った1枚・撮った理由・肌の粗・そろえない光・くずした構図・生活感・打ち消し。2026-10-07 運営者 指定）→ **Wan 2.7 1080p で動画化**（9:16 で作る。5秒12.5クレジット）。静止画のまま置かない
- 1カット4.5秒以内（素材を足すか、同じ素材の寄り1回で切る）
- 字幕の出る時刻は、表記（漢字）と読み（仮名）の対応を difflib でとり、**読み上げの文字時刻をそのまま使う**（語を探して当てる方式は、同じ語が近くにあると別の所に当たり字幕がずれた。2026-10-02 修正済み：vsl_auto.Seg）
- 字幕：極太丸ゴ（重なりを除いたフォント）、句読点で区切り空白なし、文字は同時に1つ。強調句は中央の色文字がポップ。話す言葉は全部字幕にする（カードが同じ文を出している間はカードを字幕とみなす）
- **モーショングラフィックスは文字と図形を動かして作る**（mg.py）：名前テロップ、赤い×、ループ図（言った順に点く・回る）、比較表、①②③の条件、口コミ、サイズ表、価格表＋送料無料のハンコ、数え上げ、ボタン＋カーソル。カードの文字と同じことを言う間は字幕を出さない

## 5. 音

- **BGMは最大3曲**。導入〜問題〜しくみ〜対策は1曲目（参考動画と同じ曲／近い曲）、転換（開発の話など気持ちが変わる所）で2曲目、**前を向く一言（例：「それから2年」）から3曲目の希望の曲**（悲しい曲は悲しい場面の行だけ。曲の切替は行単位でブロックを分けて合わせる）、解決〜CTAで3曲目。**切替は3秒のクロスフェード**（急に切り替えない）。音量は声の約10dB下で一定
- 効果音：画の動作（拭く・踏む・嗅ぐ・鳴く・ドア・スプレー・ケージ）、カードが出る「シュッ」、**「1つ目・2つ目・3つ目」や表の行が出るたびにポン**、金額にチャリン、言い切りにドン（直前にBGMを少し抜く）。入れすぎない

## 6. 検品（出す前に必ず）

- 黒い画面：`blackdetect` でゼロ
- 1〜2秒おきのコマ一覧を目で見る（字幕の重なり・欠け、カードの文字のはみ出し、画質）
- 口パク：SyncNet（scripts/syncscore.sh）で確信度6以上・ずれ±1
- 文言：生成した話し手の声は whisper で台本と照合
- 全体の音量：約−12 LUFS

## 7. 納品と登録

- **納品先（2026-10-02 運営者指定）**：`<商品名>/07_納品/VSL/<pack の名前（15 の 2-3）>/<ID>_<題名>/` に完成動画 `<ID>.mp4` と `原稿.md`（広告の本文・行ごとの原稿と素材）。pack のフォルダは pack0〜F を全部作っておく。運用ボード（ops-board）の作成済みも同時に更新

- 成果物④のページ（build_scripts_page.py）：動画（16MB超は数分割）、台本の全行に完成画、残りの判断事項
- 新しく作った素材（静止画→動画、口パク）は `register_assets.py` で素材庫の役割別フォルダと台帳へ
