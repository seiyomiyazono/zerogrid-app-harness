# 静止画広告の型（10種類）と作り方 — 全商品共通（2026-10-07 運営者 合格・正本）

**静止画にも型の番号と名前を持ち、pack の中で型を変えてテストする。**

- **この資料の状態**：2026-10-07 運営者 が見本10枚を見て合格（「はい最高。これを static ads の10このフォーマットとしてハーネス組み込んで」「もう完璧」）。**自分で作る静止画は、この10種類が標準。** 前の型（見出しが主役のデザイン静止画：原稿の基盤 2章・script-checklist 33）は、運営者 がその型を指定した時に使う
- **出す物は、画像だけではない。** 画像＋広告の見出し＋本文（3案）を1組で出す（下の3章。見出し・本文の決まりは前からある物をそのまま使う）
- **作る前に、その商品のマークダウン（商品フォルダ）を必ず読む**（下の2.5章。読まずに型だけ当てない）
- 根拠の格：X の運用者・制作者が「伸びている」と出した実物。配信の数字は取れていない。うちの実績ではない

## 0. 最初の版がなぜだめだったか（同じ失敗をしない）
型の名前を言葉で調べただけで、**勝っている実物の絵を見ていなかった**。伸びている静止画は、説明の図ではなく、**悩みや仕組みを「ありえない絵」に置きかえて、1秒で意味が分かるようにしている**（痛みが縄になる・体が陶器で割れる・体の中で血が渋滞する）。型を足す時も、必ず実物の画像を落として見てから分ける。

## 2. テストでの使い方
- **1つの pack の中で、型を変えて出す**（入口・根本原因・ヴィランは同じ。変えるのは型）。広告の名前に型の id を入れる：`A-2｜静止画 st03 体内ツアー｜なし｜記事A`
- 同じ絵で見出しだけ変えた物は、別の広告に数えない（原稿の基盤 1-4。X でも「同じ広告として扱われる」という指摘）
- ダッシュボード：`plan.json` の `formats.static` に10種類（`{id, name, desc, thumb}`。見本の絵は `products/_formats/st01.jpg`〜`st10.jpg`）。**画面で静止画の型を選ぶ所は、まだ作っていない**（2026-10-07 時点。データだけ入れた）
- 型ごとの当たり外れは、実績の台帳（03_実績の台帳.md`）に id で書く。1商品の結果で型を消さない（基盤 15-3）
- どの型でも、言う事は商品フォルダから取る：根本原因の名前（H）・ヴィラン（05）・体の絵（B の原文）・仕組みの細部（I）・使い方と呼び名（05）

## 3. 作り方（2026-10-07 運営者 指定：画像は Codex を呼び出して生成）
1. **読む**：2.5章の表を全部
2. **型を選ぶ**：pack の入口に向く型を1章の表から。1 pack に2〜4型
3. **絵の案を1行で書く**：「（原因・ヴィラン・症状）を、（ありえない絵）に置きかえる」。1秒で意味が分かるかを先に確かめる
4. **プロンプト**：`templates/static-formats/prompts_harimat_20261007.json`（針マットの10本）を見本に。形は「頭の共通文（4:5・文字は指定どおり・ほかの文字なし）＋ CONCEPT（絵の案を細かく）＋ TEXT（画像に入れる日本語を全部、位置と色つきで）」。商品が写る型は、実物の写真を参照に渡す
5. **生成**：**Codex 内蔵の imagegen**。`codex exec --skip-git-repo-check -s workspace-write -C <作業フォルダ> "$(cat task.txt)" < /dev/null > gen.log 2>&1 &`（`< /dev/null` を必ず付ける。指示文の見本：`templates/static-formats/codex_task_example.txt`）。10枚なら3本に分けて同時に回すと約10分
6. **点検**：下の5章
7. 寸法は 4:5（1080×1350 に合わせて書き出す。Codex の出力は 1122×1402）
8. **見出しと本文を付ける**（画像1枚ごとに）。決まりは前からある物：[creative-foundation.md](creative-foundation.md) の6章（本文は短い・中くらい・長いの3案／最初の2文に状況か原因と商品の種類／見出しは27字以内／終わりに CTA）
   - **画像の文字と、見出し・本文の最初の2文で、同じ事を二度言わない**。画像が絵で原因を見せる型（st01〜st04・st08）は、本文で「それが何か」（根本原因の名前と、ヴィランが届かない理由）を言う。画像が広告に見えない型（st09・st10）は、見出しと本文で悩みを名指しする
9. **納品の形**（ec-static-ads の「納品」と同じ）：`<商品名>/07_納品/Static Ads/<pack の名前>/<広告の key>_<型の id>_<題名>/` に `画像.png`・`ヘッドライン.txt`・`本文.txt`（3案）。原稿は `<商品名>/06_原稿/` の pack のファイルに、型の id・読んだファイル・画像の中の文字・見出し・本文を書く（ひな形 templates/pack-scripts.md）。運営者 の承認の後、停止（PAUSED）で作る

## 4. 生成が止められた時（実測）
| 止められた絵 | 理由 | 通った言い方 |
|---|---|---|
| 生の肉のような怪物・触手が体に巻きつく | 暴力の判定 | 「赤く光る太い縄の結び目」。血・傷・肉を書かない、「surreal but not gory」と書く |
| 素肌の腰・背中のアップ | 性的の判定（2回） | 服の上から／後ろ姿でパジャマをめくって湿布が見える程度／物だけの写真に替える |

## 5. 点検（出す前に）
| # | 問い |
|---|---|
| 1 | 文字を全部、拡大して1字ずつ読む（かぎかっこの種類・句読点まで。st06 の見本は『』が「」になった） |
| 2 | 絵だけ見て、1秒で何の悩み・何の話か分かるか |
| 3 | 根本原因の名前・ヴィラン・呼び名が、商品の 05 と同じ言葉か |
| 4 | 商品が写る型は、実物の写真と色・形を並べて確かめる（生成した商品を実物として出さない） |
| 5 | 人物が日本人・その商品の買う人の年代か |
| 6 | 体の絵（断面・筋肉）を正しい図として出していないか（たとえの絵として出す。図として出すなら I の確認の後） |
