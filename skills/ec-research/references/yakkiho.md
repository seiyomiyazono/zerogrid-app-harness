# 薬機法・景表法 早見表（健康雑貨DTC向け）

日本市場で健康系を売る場合の判定。3段階: **OK / 言い換えで可(-10点) / 明白NG(ゲート除外)**

## 明白NG（ゲート除外）

- **未認証の医療機器該当品の輸入販売**: 家庭用電気マッサージ器、EMS（治療目的訴求）、磁気治療器（磁気ネックレス等）、低周波治療器 → 医療機器該当。無認証販売自体が違法
- **摂取物（サプリ・健康食品）で効能訴求が必要な物**: 効果を言えないと売れない商品構造なら除外
- **口腔内に入れる器具**（マウスピース等）で治療効果を訴求する物

## 言い換えで可（-10点で残す）

物自体は雑貨として売れるが、広告表現の制約が強いケース:

| NG表現 | 言い換えの例（この言い方に固定しない。行動の変化・体験談＋但し書きで言ってもよい） |
|---|---|
| 治る・治療・改善する | サポートする・ケアする |
| 痛みが消える | 快適な毎日をサポート |
| 医師監修だから効く | 専門家と共同開発（効果の保証はしない） |
| 姿勢が矯正される | 正しい姿勢を意識しやすくする |
| いびきが止まる | 快適な睡眠環境づくり |

- Meta審査: 過度なビフォーアフター、身体コンプレックスの煽りは審査落ちしやすい。USプレイブックの訴求をそのまま翻訳しない

## 景表法の注意

- 「No.1」「売上1位」表示は根拠資料が必要
- 体験談には「個人の感想です」等の但し書き
- 「在庫薄」「今だけ」の希少性演出は事実に基づくこと（プレイブックの希少性クロージングを日本でやる時の制約）

## 判定に迷ったら

「この商品は雑貨として、効果を保証せずに売れるか？」がYESならOK側、広告の説得力が効果訴求に依存するならNG側に倒す（商品選びのゲートの話。広告の書き方の縛りではない）。
