# ドロップシップ判定（商品側 / 競合側）— 深掘りの必須ブロック

前提: うちはドロップシップで参入する。だから**「自分が仕入れて売れるか」と「勝っている競合がドロップシップ勢か」の両方**を実測する。
**さらに前提として、競合は `same-product-rule.md` を満たす同一商品でなければ実証に数えない。**競合が自社製造ブランドばかりの市場は、実証されていても土俵が違う（原価と独自性で最初から負ける）。

## A0. 主力商品への広告集中度（v6・**最初に通すゲート**）

**ストアの商品数で判定しない。** 判定するのは「広告がどれだけ1商品に集中しているか」。

```
mcp__zg__gethookd_search_ads  query=<ブランド名>  ads_per_brand_limit=0  limit=30
  → 返ってきた landing_page のパスを集計
```

| 集中度 | 判定 |
|---|---|
| 上位1〜2商品に **7割以上** | **DS形** ＝ 単品オファー。商品数がいくつあっても関係ない |
| 3〜9商品に散る | ハイブリッド。主力が立つなら候補に残す |
| 10商品以上に散る | 本当のカタログ。除外 |

根拠（2026-08-20）: Vion は39商品だが広告3,271本が `Fade - Sleep Earplugs $39` に集中していた。
「39商品＝カタログ」で捨てた結果、その日の最高スコア商品を取りこぼした。Loopも60商品で主力はQuiet/Dream。

**サイズ選択は別枠で即除外。** `products.json` の `options` に実寸サイズ（US 8 / EU 42 等）が並ぶ商品は、
広告集中度が満点でも落とす。SKUが分割され在庫と返品で死ぬ。ベアフットシューズ(69点)・厚手クッションインソール(46点)と
**2回続けて同じ理由で落としている**。

## A. 商品側 — この商品をドロップシップできるか（ハードゲート）

| # | チェック | 合格条件 | 取り方 |
|---|---|---|---|
| 1 | 同等品の存在 | Alibaba/CJ/AliExpressに**同等品URL 2本以上** | 実URL・単価・MOQを記録。画像で形状一致を確認 |
| 2 | 原価とマージン | 3x COGS かつ 粗利$25〜30（送料込み） | 想定売価から逆算。バンドル前提なら「バンドルで到達」と明記 |
| 3 | 独自性の壁 | 特許成分・独自機構・ブランド専売でない | 競合LPの特許番号/独自成分表記を確認。あれば形態差し替えを検討 |
| 4 | 物流 | 軽量・非バッテリー・非摂取・非液体・壊れない・サイズ依存が弱い | 既存ゲートと同じ。1つでもNGなら除外 |
| 5 | 日本への着地 | CJ日本倉庫在庫あり or 国内発送代行が成立 | CJで在庫地を確認。海外発送のみなら「配送15日前提の売り方」を条件として明記 |

判定: **○可 / △条件付き（条件を明記）/ ×不可**。**×は他が満点でも即除外**（スコア計算に進まない）。

## B. 競合側 — 勝っている競合はドロップシップ型か

主要競合（深掘りに進んだクラスタのブランド）ごとに判定する。

**単独で決まるシグナル（これが出たらDS型確定・以下の照合は不要）**
- **advertorial / listicle / 医師ペルソナ記事を前段に回している**（自社ブランドはこの型を使わない。運営者指示 2026-08-18）

**DS型シグナル（3つ以上該当でDS判定）**
- Shopifyで動いている（zg の research_stores の shopify・shopifyHtml ／ HTMLに `cdn.shopify.com` `/cdn/shop/`）
- 単品オファー型LP（`/products/` 直行、カタログが薄い、上部にヒーロー+CTA）
- 商品画像がAliExpress/他ドメインにも存在（画像のファイル名・構図が同じ）
- 会社情報が薄い（住所なし/私書箱/連絡先はメールのみ/会社沿革なし）
- 発送10〜20日 or 「発送に時間を要する」注記
- レビューアプリ（Loox / Judge.me / Okendo）＋割引ポップアップ＋バンドル割
- 価格帯 $29〜79 で 2個/3個バンドルが主オファー

**反証シグナル（＝自社ブランド/製造。DSに数えない）**
- 特許番号・商標付き独自素材・自社工場や創業ストーリー
- 小売流通あり（Target/Walgreens/Amazonブランドストア）、FDA登録、メディア掲載実績
- 複数SKUの縦深カタログ、サブスク基盤、CS電話番号

判定は **DS型 / ハイブリッド / 自社ブランド** の3値で、社名ごとに1行で記録する。

**実証の必要条件: 主要競合に DS型が3社以上いること（`same-product-rule.md` が正）。**
- DS型0〜2社（残りが自社ブランド）→ 海外実証度を**最大10点にクランプ**し、レポートに「DS勢が勝てていない市場」と明記
- DS型が3社以上 → 通常どおり採点。うち1社でも365日超継続なら「DSで利益が出る構造」の確証として扱う

## C. 記録フォーマット（レポートと台帳の両方に載せる）

```
商品側: ○ / Alibaba $2.8(MOQ100) https://... ・CJ日本倉庫あり / 3x+粗利$27(2個バンドル時)
競合側: DS型2社(Earship 82本535日・Hears 421本) / 自社ブランド1社(Loop=反証) → 実証OK
```
