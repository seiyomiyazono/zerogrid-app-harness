# 指標と売上逆算（v5.1・2026-08-20 運営者指示）

「うまくいっている」を言葉で判定しない。**数字と閾値で判定し、取れなかったものは取れなかったと書く**。

## 0. バンガー基準（最優先・v5.3）

| 指標 | 閾値 | 意味 |
|---|---|---|
| **月間訪問数** | **100万超** | SimilarWebで実測。1社でも超えていればその商品は当たり |
| **広告本数**（active_ads） | **1,000本超** | 同じ1社が出していること。**本数は最重要指標** |
| 同一商品の競合 | **他に2社** | 1社だけだと単発の可能性。2社いれば市場として成立 |

**探索は「訪問100万超がいるか」から始める。**いなければその商品は捨てて次を探す。
候補が枯れてきたら 50万 → 30万 と下げてよいが、**下げた事実をレポートに明記する**。
Hookdの `active_ads_count=1000` で本数側を先に絞ってから、SimilarWebで訪問数を当てるのが最短。

## 1. 広告単体

| 指標 | 取り方 | 使い方 |
|---|---|---|
| **継続日数**（days_active） | Hookd / Meta広告ライブラリ | 主指標。4日未満は無視、14日で「継続」、30日で「勝ち」 |
| **同一型のバリアント本数** | 同一ブランド内の重複＋`used_count` | 勝ったコピーは必ず増殖する。1本を長く回すより、同じ型が3本以上あるほうが強い |
| **performance_score** | Hookd | 81+（optimized/winning）なら単独で「勝ち」扱い。**nullのことが多く、その時はこの指標は使えないと明記する** |
| **ad_spend_range_score** | Hookd | 取れれば最も直接的。$0-500 / $501-2,000 / …$20,000+ |
| **eu_total_reach** | Hookd | EU圏限定だがリーチの実数。相対比較に使える |
| **作り直しの頻度** | start_dateの更新 | 刷新しながら回している＝生きている。3ヶ月前の1本が残っているだけなら放置の疑い |

**「うまくいっている広告」の定義**: 継続30日以上 **かつ** 同一型のバリアント3本以上、**または** performance_score 81以上。
どちらも満たさず継続日数だけが長いものは、**「最長継続◯本」と呼ぶ**。「うまくいっている」とは書かない。

## 2. ファネル（zg の research_stores が自動収集）

- `products.json` → 商品数 / **ストア年齢**（最古published_at）/ 価格 / 最終更新
- `cart.js` → **通貨**（Shopify Markets で閲覧地の通貨が返るので必ず記録する。日本から見ると円建てで返る）
- トップHTML → レビューapp / 社会的証明の件数表記 / 星 / 保証日数 / BOGO
- Trustpilot → レビュー件数とスコア（外部サイトなので改ざんされにくい）

**ストア年齢は強い**。2ヶ月のストアが1,000本回していれば立ち上がり期＝参入余地あり。2年なら定着市場。

## 3. トラフィック

**無料版でも訪問数の実数は取れる。ただし置き場所が違う。**（2026-08-20 判明）

- ページ本文の「Total Visits Last 3 Months」欄は **`<1M` のような帯しか出さない**
- **実数はその下の「Compare 〇〇 to:」ウィジェットに出る**。ここから `([\d.]+[KMB])\s*\n<ドメイン名>` で拾う
- ⚠️ **グラフの軸ラベルを訪問数として読むな。** 2026-08-20、artuvate.co と callixe.com を両方「1M」と報告したが、
  実数は **195.9K と 454.4K** だった（Global Rank が #238,853 と #124,140 で同じ訪問数になるのは不整合、で気づくべきだった）
- ⚠️ **Rank の隣に出る数字は「前月順位」ではなく「変動幅」**（2026-08-20に誤読して報告を訂正した）。方向は矢印アイコンなので
  innerText からは取れない。**方向は観測タブの前回値との差分で判定する**
- 比較ウィジェットには**同カテゴリの類似サイトが4つ並ぶ**。これは無料の競合発見チャネルとして使える
  （artuvate.co → kanudausa.com / thesleepoasis.com / therapexa.com / hugterra.com、
  　loopearplugs.com → alpinehearingprotection.com / happyears / quieton / earasers）

**Global Rank → 月間訪問数** の対数補間（`track.mjs` の RANK_ANCHORS）は、実数が取れなかった時のフォールバックに使う。**③推定ラベル必須**。

## SimilarWebのブロック（2つある。混同しない）

1. **無料枠 3ドメイン/日** — `browser.newContext()` で新規incognitoコンテキストを作ればリセットされる（統一プロファイルのCookieには触らない）
2. **IP単位のレート制限** — 短時間に連続で叩くと CloudFront が **403** を返す。こうなると**新規コンテキストを作っても無意味**。
   2026-08-20は40社以上を連続で叩いた結果、途中から全部403になり、5社分の訪問数が「未取得」のままレポートに残った

**だから叩くのは決勝に残った3〜5社だけにする。** 探索の途中で片っ端から叩かない。広告本数はHookdで無料・無制限に取れる。

運用: 決勝の3〜5社を優先度順に並べ、1社ずつ新規コンテキストで叩く。403に入ったらその日は打ち切り、
取れなかった行は「未取得（SimilarWeb 403）」と理由付きで残す（空欄で誤魔化さない）。
代替として Cloudflare Radar を試したが、この規模のドメインはランク圏外で使えなかった。

## 4. 売上の逆算 — 3経路で出して突き合わせる

**① トラフィック経路** = 推定訪問数 × CVR 1.5〜3.5% × AOV
**② レビュー経路** = レビュー/顧客数の増分 ÷ レビュー率 2〜5% × AOV（**2回目の観測から**）
**③ 広告経路（参考値）** = 広告本数 × 月$20〜80 × ROAS 1.8〜2.5

**3つが同じ桁に来たら信用する。割れたら「割れた」と書く。**

③の注意: **バリアント複製型のブランドは本数が膨らむので過大評価する**。300本超は複製型を疑い、警告を出す。初版で1本$150-400を当てたら①の10倍が出て破綻したので、$20-80に下げた。`ad_spend_range_score` が取れる時はそちらを優先する。

## 5. スワイプ在庫の数え方（`scoring.md` の20点軸）

**型を数える。広告本数ではない。**同じブランドの同じ型のバリアントは何本あっても1本。
本数を稼ぐコツは、Hookdだけで終わらせず**Meta広告ライブラリをブランド名で検索し、media_type を image/video で切り替えて**コピーの冒頭を読むこと。
Hookd未収録のブランドが普通にいる（膝ストラップではTyStrap・Kneveo・ExtraKneeの3社が未収録だった）。

各枠 0本=0／1-2本=2／3-5本=4／6-10本=6／11本以上=7点。合計20でクランプ。

## 6. 定点観測の運用

zg の research_stores（observe:true、ads に {ドメイン: 本数}）で、research/観測.json に1ブランド1観測=1行で足す（社内の版の「観測」タブの代わり）。

**2週間空けて2回取って初めて意味が出る。**確定した商品と保留の商品は、掃引のたびに観測を1回追加する。これが無いと毎回ゼロからのリサーチになる。
