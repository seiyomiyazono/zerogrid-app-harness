# 台本の確かめ表（書く前と、書いた後に当てる1枚。元は `台本の芯.md` と `台本の決まり.md`）


## 芯の確かめ（先にこれを見る）
- [ ] 1枚の絵が1つに決まっている。出てくる物は3つまで。専門の部品の名前が無い
- [ ] 売りが1行。働きで言っている（見える印ではない）。今の対策を、相手がうなずく理屈で切っている
- [ ] 語り手に言いにくい立場がある。相手の暮らしの場面が2つ以上。ひっくり返しが1つ。人の声が1つ。最後の回収がある
- [ ] 商品の名前が出てから終わりまでが、全体の3〜5割
- [ ] 前の文を受けて始まる文が、3割ある
- [ ] 似た物への注意と、選ぶ基準が、商品の前にある（要る時）
- [ ] 経過・研究・確かめ・使い方の簡単さを、条件で入れるか決めた
- [ ] 締めが、着地（記事・店）に合っている
- [ ] 長さは、言われていなければ3分前後

## 書く前に決める（1行ずつ書く）
- [ ] 商品の売りを1行に絞った（今の手ぜんぶに共通する、しくみ上の穴を1つ見つけて、そこだけを埋めている事）。本数・時間・保証は証拠に回した
- [ ] そのアングルの資料（J-3・J-5・J-7）を今、開いて読んだ。形を考える前に、原因の鎖と、商品の働きの鎖を、部品と動きで書き出した
- [ ] 段階と、相手が「今、買っていない訳」を1つ決めた。鎖で言う物（原因／物差し／オファーの訳／ここで買う訳）を決めた
- [ ] 商品を知っている人向けなら：悩みと原因は説明しない。オファーの訳は本当にある事情から。商品の名前は最初の文
- [ ] 売りは1つ（いちばん大きい悩みに、いちばん強い売り）
- [ ] 悪役は1つ。体の中の、絵にできる動き。名前は動詞。最後まで同じ言葉
- [ ] 悪役は、症状のある所とは別の部品（1歩上流）。症状の言い換えになっていない。「なぜ？」ともう1回聞けない所まで下りた
- [ ] 原因の鎖を、部品と動きで3〜6歩、先に書いた
- [ ] にせの犯人（相手が今まで責めていた物）を1〜3個
- [ ] 正解は、悪役の裏返しの1つの動き
- [ ] 今の手を全部並べて、「悪役に届くか」の1つの物差しで、できる事と届かない所を書く
- [ ] 賭け金：悩みを放っておいた先と、相手がもう感じているほかの不調（資料にある物だけ）
- [ ] 合言葉（1つのたとえ・1つの絵）
- [ ] 区切りごとに、見る人が何と思うかを、相手の言葉で1行
- [ ] 文の長さの流儀（刻む／つなげる）と、話し手
- [ ] 2e の部品（研究・確かめ・経過・使い方）を入れるか、条件で決める

## フック（声の1文目＋最初の画面）
- [ ] 欲しい結果と、早さが入っている
- [ ] 狙う症状の名前が入っている。リードも本文も、その症状から離れていない
- [ ] 悩みの名前は1語。場面は絵に回した
- [ ] 答え（何を使うか・なぜか）は見せていない
- [ ] 1回聞いて、言っている事が文字どおり分かる。言い回しで謎を作っていない
- [ ] 1文目は、声で3秒（20字前後）
- [ ] 見る人の得から入っている（話し手の名乗り・商品の名前と理由・約束の無い寸劇ではない）
- [ ] 画面の見出しの字（10〜15字）を書いた
- [ ] 見た事の無い絵を書いた

## リード
- [ ] 仕事をしている：悩みの値打ちを変える／今の手への信頼を落とす／答えを待たせる
- [ ] 中身は、ほかの台本と違う（見せ物・身の上話・助言・正常を先に教える・道具と指さし・代わりに試した・実況・言い当てとせりふ、など）
- [ ] 答えを言っていない。商品の説明をしていない
- [ ] 今の手は、できる事を認めてから、届かない所を言っている
- [ ] にせの犯人を外すのは1回だけ
- [ ] 待たせる訳（見せる前に見てほしい物と、見ると分かる事）がある
- [ ] 目次（これから◯◯と◯◯を話します）になっていない

## 本文
- [ ] 体の中で起きる順の鎖（1文に1つの動き・主語は体の部品・向きや量がある）
- [ ] 文ごとに「この文で初めて出た事」が書ける。同じ歩を、言葉を変えて二度言っていない
- [ ] 今の手を、どの歩に届いてどの歩に届かないかで切った。商品を、どの歩を止めるかで言った
- [ ] 正常を先に言って、そこからの差で悪さを言っている
- [ ] 相手が知っている感じの正体を言った（あの◯◯が、これです）
- [ ] ほかの不調を同じ原因に束ねて、にせの犯人から付け替えた
- [ ] あなたのせいではない、と言った
- [ ] 答えは単純（悪役の裏返しの1文）。いちばん暗い所の直後に置いた
- [ ] 本物は遠い（正しいやり方は前からある。でも高い・毎日は無理）
- [ ] 選ぶ基準を、商品の前に渡した
- [ ] 特徴は、数字＋身近な物＋だから何ができるか
- [ ] 証拠の種類が3つ以上
- [ ] 経過は、材料のある日だけ。最初のいやな所を言った
- [ ] 商品の弱い所を、こちらから言っていない。疑いには保証で答えた
- [ ] 締め：「もし◯◯なら」を3つ → 取り戻したい物を3つ → 今（訳つき）→ 保証は具体に

## 伝え方（声に出して当てる）
- [ ] 説明はつなげて話している。断片の連打は山場だけ。文と文につなぎの言葉がある。前の文の終わりを次の文の頭で受けている。時間は一方向
- [ ] ぼかし言葉（力が抜ける・張り・ほぐれる・ゆるむ・休む側・楽になる）を数えた。1つずつ、物の動きが付いている
- [ ] 読点は息つぎの所だけ。書き言葉が無い
- [ ] 語尾が並んでいない
- [ ] 説明はつなげて、言い切りとだめ押しだけ短い
- [ ] 短い問いは1分に1回まで。並べていない
- [ ] 「AではなくB」は、ここぞの所だけ
- [ ] 次に来る物の種類を、先に一言で言っている（実は／ここからがこわい所で／じゃあ、どうするか）
- [ ] 物の名前で言っている（抽象の言葉が無い）
- [ ] 相手のした事は「たいていの人は」で言っている
- [ ] 「あなた」「あなたの」が、ほぼ1文に1回
- [ ] 「だから」「〜のせいで」を省いていない
- [ ] 悪役の言葉を1分に2〜3回、賭け金の言葉をそれより多く言っている
- [ ] 数字は、比べる相手と一緒

## 絵と字
- [ ] 台本が、声・字・絵の3列になっている。絵の空いた行が無い
- [ ] 絵が言っている事（場面・つらさ・だれが話すか・体の中の形・今の手）を、声で言い直していない
- [ ] 1文に1つの絵。1〜2秒で切りかわる長さ
- [ ] 体の中は、本物の体の上に重ねる。赤＝悪い所、緑・青＝良くなった所
- [ ] 相手に似た人が何人も出る
- [ ] 話の区切りで、話し手の場所か服が変わる
- [ ] 商品の名前を言う所：長い動画は半分〜7割の所。1分の動画は最初からでよい

## 何本か書いた時
- [ ] フックだけ、リードだけを並べて、同じ形・同じ中身・同じ言い回しが無い
- [ ] 悪役と売りは、同じアングルなら同じでよい。変えるのは形と中身

## 聞かせる時
- [ ] 入口は「どれで手が止まるか・続きを見たいか」だけを聞く
- [ ] 穴さがしで見るのは、文と文がぶつかっていないか、だけ。強い言い切りを削らない
