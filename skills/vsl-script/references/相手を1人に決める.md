# 相手を1人に決める（書く前に、かならず。2026-10-08 運営者）

同じ段階の中にも、いろんな人が居る。段階の全員に向けて書くと、だれも「私の事だ」と思わない。**台本は、1人に向けて書く。** 与えられた相手がいればその人、いなければ自分で1人に決める。決めたら、その人にだけ刺さるように書く（その人から外れる人に届かなくてよい）。

## 0. 相手の理解シート（台本より先に、かならず。出す時は、台本の前に見せる）
**何が起きていたか**：1件だけの原文を、相手の考えや場面にしていた。2-3「一番多い物を数えて選ぶ」・2-4「15件以上集める」を飛ばしても、台本が書けてしまっていた。
**決まり**：台本を書く前に、次のシートを作業のフォルダに `相手の理解シート.md` で作り、**出す時に台本の前に付ける**（運営者 が先に、相手の理解が合っているかを見られるように）。シートの行がうまらない時は、台本を書かない。
**2026-10-19 から**：商品のフォルダに `01_商品理解の基盤/K_ペルソナ/<アングル>_<呼び名>.md`（`ec-ad-ops/references/product-foundation.md` の K）があり、依頼票にペルソナの行があれば、**シートは K を写して作る**（A〜H は K-1〜K-8、C の件数は K-3）。台本の工程でするのは「深める」だけ：①K-9（広告分析）の「効いている入口」「まだ誰も言っていない入口」を読んで、1文目の候補に反映する ②新しく分かった事を、シートと K のページの「台本で深めた差分」に日付つきで足す（次の台本が同じ所から始められる）。**新しく原文を集める（2-4）のは、K の行が「仮」の時だけ。** K が無い商品・票にペルソナが無い時は、今までどおり（下の表を0から作る）。
| 行 | 書く事 | 書き方 |
|---|---|---|
| A だれか | その困り事が出る、一番多い場面（いつ・何をしている時に困り、いつは平気か）・年代・暮らし（家族・仕事・家にいる時間） | 1行。アングルのページ・F の行・購入の年代から |
| B 一日の流れ | 朝・昼・夕・夜に、何をしていて、どこで困り事が顔を出すか | 4行。その年代・暮らしの人が、ふつうにしている事だけ |
| C 何のせいだと思っているか | 上位3つと、**件数**。それぞれに、ア その人や物の側の見立て／イ あきらめの結論／ウ きっかけ、の印 | 2-3 のとおり数える。1〜2件の物は書かない。原文が足りない時は、2-4 のとおり集めてから数える。**鎖の表・資料の予定・ほかの台本の都合から決めない**（2026-10-19） |
| D 今している事 | 上位3つと、**件数** | 多くの人がしている事だけ（めずらしい行動は書かない） |
| E 口ぐせ・ふだんの言い方 | 困り事を何と言うか・あきらめる時の一言 | 原文の言葉。件数の多い順 |
| F こわい事・あきらめている事 | 1〜2つ | 原文か、運営者 の見立て |
| G 知らない事 | 原因の名前・仕組み・専門の呼び名 | 台本で、教える側になる所 |
| H こうなりたい | 暮らしの場面で2つ | 原文か、B の困る場面の逆 |
- **件数の決まり**：C・D・E は、**3件以上ある物だけ**。資料が足りなければ、2-4 のとおり15件以上集めてから数える（何のせいの言葉で検索しない）
- **決まりだけで、正しい相手を作る**。運営者 に聞かなくても、下の集め方で、相手の考えが当たるようにする。運営者 の直しが入ったら、その直しが出るような集め方を、この章に足す
- **集める場は、相手の年代・性別・暮らしに合わせる**（2026-10-14：相手と年代の合わない場の検索だけで決めて、外した）。場ごとのかたより：知恵袋＝10〜30代・学生・急な痛みの相談が多い／発言小町・ガールズちゃんねる＝30〜60代の女性・暮らしの愚痴が多い／Amazon・楽天のレビュー＝買った人・その年代の言葉／調査（年代別・男女別の数）＝何のせいにしているかの割合。**相手の年代・性別に合う場を2つ以上**使い、それぞれの件数を分けて書く。合わない場の原文は、言葉の材料にだけ使い、C・D の件数に入れない
- **原文の書き手が、相手と同じ人かを1件ずつ見る**（年代・性別・暮らしが書いてあれば、それ。書いていなければ、文の中身から。相手とちがう年代・暮らしの人の原文は、件数に入れない）
- **場面は、相手の多くに当たる場面から選ぶ**。1つの場面の原文が多くても、それが、ある条件の人だけの場面なら、相手の中心の場面にしない
- **シートの確かめ（3問。全部「はい」で、台本へ）**：①この相手が10人いたら、8人が、どの行にも「そうそう」と言うか ②C の1位が、3件以上の原文で数えた物か（**書き手の見立てで決めない**）③1件しか出どころの無い行が、1つも無いか ④C・D の件数が、相手と同じ年代・性別の原文だけで数えてあるか ⑤台本の場面・思いこみの言葉が、ある条件の人だけの話になっていないか
- 台本の中で、相手の考えと困り事の中心（思っている事・何のせいにしているか・困り事の場面）は、**このシートの行から取る。** 場面の細部は足してよい

## 1. 人物メモ（作業のフォルダに `相手.md`。7行）
材料は、理解メモと、商品の `B_市場と悩みの地図` のお客さんの原文。**想像で埋めない。** 原文に無い行は「無い」と書く。ただし 7（こうなりたい）に原文が無い時は、2（困り事の場面）と 6（こわがっている事）の裏返しで書いてよい。
```
1. 一言で：<いつ・何をしている時に>、<どう困っている>、<年代・暮らし>の人
2. 困り事の場面：いつ・何をしている時に・どこが（何が）・どうなるか（本人の言葉。原文の番号）
3. その時、本人が口にする言葉・思わずする事
4. 何のせいだと思っているか（原文の番号）
5. 毎日の暮らしの中で、困り事が顔を出す場面を、ほかに2つ
6. こわがっている事・あきらめかけている事
7. こうなりたい（原文の言葉）
```

## 1-2. 困っている人・原因を持つ物・困り事が見える場所が、別々の時（2026-10-11。体に使わない商品で試して、だれを相手にするか・場面をどう書くかが決まらなかった）
- **相手は、困っている人（見る人・買う人）。** 原因を持つ物・ほかの人・生き物を、相手にしない
- 2 の「どこが（何が）」には、**相手が毎日見ている、困り事の出る場所と、そこで起きる事**を書く。人物メモに1行足す：`11. 原因を持つ物（だれ・何）／困り事が見える場所`

## 2. 決め方
| 場面 | する事 |
|---|---|
| 相手を与えられた | 与えられた言葉を1行目に置き、2〜7を原文から埋める。与えられた相手を、広げない・すり替えない |
| 自分で決める | 「商品を読む」5章で入口を決めた後、その入口の原文の中から、**同じ1人が言っていそうな原文を3つ以上**集めて、1人にする。台帳・記録にある相手と、2（困り事の場面）が重ならない人にする（**入口は変えない。** 入口＝どの困り事・どの対策の人かは、`商品を読む.md` 5 が先に決め、記録と重なっても、そのまま。ここで重ならないようにするのは、その入口の中の**場面**。入口の原文に場面が1つしか無い時は、場面も同じでよく、`商品を読む.md` 5 の 1 のとおり中身を変える。2026-10-11） |

- **1人は、「よく居る1人」。めずらしい1人ではない。** 人物メモに入れる細部は、**その困り事の人が10人居たら、8人がうなずく物だけ**。原文が1件しか無い、その人だけの変わった話（「◯◯すると収まる」「◯◯の時だけ出る」など）は、入れない。見る人が「ん？ 私はそうじゃない」と思った所で、台本は終わる
- **困り事の強さは、原文で一番強い言葉に合わせる**。困り事が軽い人・すぐ収まる人を相手にしない
- **相手は、困り事の場面で決める。事情で決めない。** 事情＝その人の立場・仕事・前にした事。事情は 1・5 に入れる材料で、相手の中心は 2（いつ・何をしている時に・どうなるか）
- 段階ごとに、人物メモの中心が変わる（7行の形は同じ。下の行を足す・読みかえる）：
  | 段階 | 中心 | 足す行・読みかえ |
  |---|---|---|
  | ① | 気にしていない小さなサインと、流している理由 | 2 を「小さなサインが出る場面」に、4 を「なぜ『こんなものだ』と思っているか」に読みかえる |
  | ② | 2（困り事の場面）と 4（何のせいにしているか） | そのまま |
  | ③ | 今している対策 | 8 を足す：何を・どのくらい・どうやって試して、どうだったか。その時の気持ち |
  | ④ | 疑い・迷い | 8 を足す：何を疑っているか（本人の言葉）・何と比べているか・前に何で失敗したか |

## 2-2. 相手が「知っている言葉」と「知らない言葉」を分ける
依頼で渡される**切り口の名前**（病名・専門の呼び名・業界の言い方・商品の種類の名前）は、**作る側の言葉**。相手がその言葉を知っている・自分に当てはめている、とは限らない。
- 人物メモに2行足す：`9. 相手が自分で使う言葉（困り事を、ふだん何と言うか。原文から）`／`10. 相手が知らない・自分の事だと思っていない言葉（切り口の名前・専門の呼び名）`
- **10 の言葉を、相手の頭の中の言葉として書かない**（「◯◯〈専門の呼び名〉だから、もう△△だ、と思っている」は、その呼び名を知っている一部の人にしか当たらない）。書き出し・思いこみ・相手のせりふは、9 の言葉だけで書く
- 10 の言葉を台本で使うなら、**教える形で、1回まで**（「それには名前があります。◯◯です」）。使わなくても台本が通るなら、使わない
- **段階ごとの目安**：① は、困り事の名前そのものを知らない。② は、自分の感じている困り事の言葉（痛い・つらい・うまく行かない）は言えるが、専門の呼び名・原因の名前は知らない事が多い。③ は、試した対策の名前は知っている。④ は、商品の種類の名前を知っている

## 2-3. 思いこみは、「一番多い」物を選ぶ（数える）
否定する思いこみ・何のせいにしているかは、**原文で数えて、一番多い物**にする。めずらしい考え・くわしい人の考えを選ばない。
（2026-10-19 運営者 の指摘：専門の人でない限り、専門の見立てでは考えない。書き手は「一般人のつなぎ方が下手」）
- **一般の人のつなぎ方で候補を出す。** 一般の人は、場面のすぐそばにある物（きっかけ）・その人や物の弱い所（見立て）・あきらめの一言（結論）でつなぐ。候補は3つの箱（ア その人や物の側の見立て／イ あきらめの結論／ウ きっかけ）から出す。専門の言葉は、相手が自分から口にしている原文が3件以上ある時だけ
- **原文が3件に足りない時**：2-4 のとおり原文を集めてから数える。**書き手の見立てで C を埋めない。鎖の表の外からさがさない**
- 原文を「何のせいにしているか」で仕分けて、件数を書く（`相手.md` の4の下に表で）。**上位3つの中から選ぶ。** 1〜2件しか無い物は選ばない
- **数える順（2026-10-11。「上位3つ」と、下の「段階と合う行」が逆に読めた）**：①先に、段階と合う行だけにしぼる ②残った行の中の上位3つから、一番多い物を選ぶ。全体の上位3つに入っていても、段階のちがう行は選ばない。しぼった後に3件以上の行が無い時は、この節の最後の行（場面を変えるか、返事の頭に書く）
- その段階の人が、**ふだん口にする軽い言い方**が多い（仕方ない・そのうち良くなる・みんなそう・◯◯はそういう物・私のやり方が悪い・忙しいから、の類）。むずかしい理くつ（専門の名前が入る理由）が1位になっていたら、集め方がかたよっていないかを疑う（下の 2-4）
- 確かめ：その思いこみを、同じ困り事の人10人に言って、8人が「そう思ってた」と言うか
- **同じ件数で並んだ時**：今回の場面の原文だけで数え直して、多い方。それでも同じなら、ほかの台本（台帳）でまだ否定していない方
- **一番多いのが「何のせいにもしていない人（なぜ？と聞いているだけ）」の時**：その人たちが、次に口にしている心配・見立て（◯◯かも、◯◯かな）の中で、一番多い物を否定する物にする。それも無ければ、「そのうちおさまる」「たいした事ない」と流している事を否定する
- **相手が、困り事そのものを、ある名前で呼んでいる時**（その名前が、原因の見立てになっている時）：名前を頭から否定しない。「◯◯なだけ、ではありません」と、**「だけ」を否定する**形にして、その後に本当の原因を言う
- **段階と合う物の中で、一番多い物を選ぶ**。件数の表の各行に、**その思いこみの人が、どの段階か**を書く：何かのせいにしているだけ＝②／そのために何かを買った・替えた・通った・ためした＝③／商品の種類を知って迷っている＝④。**指定された段階と合う行の中で、一番多い物**を選ぶ。全体の1位が別の段階の行なら、それは選ばない
- **段階を、あいまいにして合わせない**（③の人の動作を弱く書いて、②に見せる、をしない）。対策の名前・対策の物が、書き出しや否定する物に入ったら、その台本は③
- 指定された段階の人が、その場面には少ないと分かった時（上位が、ほとんど別の段階の行）は、**場面を変えるか、その事を返事の頭に1行で書く**（「この場面は、③の人が多い。②で書くなら◯◯の人になる」）

## 2-4. 自分で原文を集める時（商品の資料に、その切り口の原文が無い時）
- **切り口の名前では、さがさない。** その名前でさがすと、その名前を知っている・くわしい人の文ばかり集まり、相手がかたよる（実際に起きた：専門の呼び名でさがした原文から人物を作ったら、「その呼び名を知っていて、原因まで知っている人」になり、ふつうの相手から外れた）
- **困り事の言葉（相手がふだん言う言い方）と、場面の言葉**でさがす（「（場所・物・その相手の呼び方）＋（起きる事・困り事の言葉）」「（している事）＋（困り事）」「（した事）＋『のに』『しても』」）。集めた原文に、どの言葉でさがしたかを書いておく
- 15件以上。切り口の名前でさがした文が混ざる時は、印を付けて、**思いこみと相手の言葉を決める時には数えない**（強い言葉・場面の材料には使ってよい）
- **「何のせいか」が入った言葉でも、さがさない**（「◯◯のせい」「◯◯が原因」「年だから」などを検索の言葉に入れると、その行だけ件数がふくらむ）。入れてしまった検索で出た文は、印を付けて、件数から外す
- **件数は、今回の場面の原文で数える**（同じ切り口でも、場面がちがえば、責めている物がちがう。全部の場面を合わせた順位で決めない）
- **困り事の一番強い言葉も、今回の場面の原文から決める。** 同じ商品のほかの切り口・ほかの場面で決めた言葉を、そのまま持ってこない。その場面の原文に無い強さの言葉は、使わない
- 集めた物は、作業フォルダの `切り口の小さい基盤.md` にまとめる：①相手がふだん使う言葉（多い順）②困り事の場面（多い順）③何のせいにしているか（件数つき）④している事・していない事 ⑤こわがっている事 ⑥相手が知らない言葉。**人物メモは、ここから作る**

## 3. 台本への当て方
- **書き出し**に、2 の場面か 3 の言葉が入る。その人が、1文目で、その時の感じを思い出す
- **本文**に、3・5 の細かい物を、3か所以上入れる（その人の暮らしに実際にある物・時刻・動作）。「多くの人は」「ほとんどの人は」で広げない。その人の話として書く
- **原因の1文**（`台本の決まり.md` 3-3）に、その人の困り事を入れる（「◯◯の時の、その（困り事の言葉）の原因は、〜です」）。ただし、**その場面の理くつ（なぜその時に起きるか）を、作りから長く説明しない。** 原因の説明そのものは、短く、だれにでも分かる形のままでよい。その人らしさは、書き出し・否定する物・暮らしの細部・最後の姿で出す
- **否定する物**は 4。**最後の姿**は 7 を、2 の場面の逆で
- 1本の中で、相手を変えない。別の場面の人の話を足さない

## 4. 検品（出す前）
1. **入れかえの検品**：書き出しと、否定する物の文を読む。**別の相手（同じ段階の、ちがう場面の人）の台本に、そのまま入れても通るか。** 通るなら、広すぎる。その人の場面・言葉を入れて書き直す（原因の説明は、ほかの相手と同じでよい）
2. 人物メモの 2・3・4・7 が、台本のどの文に入っているかを言えるか
3. 逆に、狭すぎないか：書き出しが「事情」だけで、困り事の言葉が無い、になっていないか
5. **言葉の検品**：台本の中の、相手の頭の中・相手のせりふ・書き出しに、人物メモの 10（相手が知らない言葉）が入っていないか。思いこみは、2-3 の表の上位3つの中の物か
4. **「ん？」の検品**：台本の中の、相手についての文（場面・動作・感じ方）を1つずつ読む。**同じ困り事の人の多くが「私はそうじゃない」と思う文**は、消す。困り事を軽く言っている文（「今はまだ〜すれば収まる」）も、消す（段階①の、今のサインを言う文は別）
