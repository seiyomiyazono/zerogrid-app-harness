# 台本の決まり（1枚。2026-11-19 作り直し・同日 運営者 の OK で本物へ）

> 先に [台本の芯.md](台本の芯.md) を読む。食い違う時は、芯に従う（2026-11-23）。

この1枚に、商品の中身・例文・見本を書かない。書いてあるのは、考える順と、その訳だけ。

# 1. いちばん上の決まり：言葉は、ふつうに言う

**構成は工夫する。言葉は工夫しない。**

台本の面白さは、何をどの順で見せるかで作る。言い回しで作らない。言い回しを飾ると、聞いた人は、意味を取るのに1回止まる。動画は止まってくれないので、そこで離れる。

**書き方**
- 相手が、友だちや家族に口で言う文で書く
- 理由は、理由だと分かる形で言う（「なぜなら、〜だからです」「だから、〜です」）。聞いた人に、つながりを考えさせない
- 物の名前・体の部分の名前は、だれでも知っている呼び方で言う
- 主語と述語を省かない。助詞やつなぎの言葉を削って、文を短く見せない

**しない事**
- 自分で作った言い回し（その商品・その台本の中でしか通じない言い方）
- 名詞だけで文を切る（「◯◯。△△します。」の形）
- 語順をひっくり返す・もったいぶって後ろに回す
- たとえ・言いかえで、起きている事をぼかす
- 短く見せるために、言葉を省く

**確かめ（1文ずつ）**
- この文を、小学5年生が1回聞いて、同じ事を自分の言葉で言い直せるか
- この文を、相手が自分の家族に言う時、同じ言い方をするか
- 「つまり、どういう事？」と聞き返される文は、聞き返された時の答えの方を、そのまま書く

この決まりは、ほかの全部の決まりより上。ほかの決まりを守ると言葉が不自然になる時は、言葉の方を取る。

# 2. 考え方：1本の線

台本は、部品を集めて並べる物ではない。**相手が自分で気づいている事実から、「だから、この商品が要る」まで、1本の線を引く物。** 線の上に無い話は、正しくても、面白くても、入れない。

# 3. 書く前に作る物（設計メモ）

台本は、このメモからしか書かない。メモの中の文も、1章の言葉で書く。埋まらない所は商品の資料に戻る。資料に無い所は、技術テストとして書き手が作って埋め、作った物を「決めた値」（出す物の「作った値」）に書く。

**3-1. 相手の型**
商品の資料（アングルのページ・人物の表）にある物は、そこから写す。資料に無い時だけ、原文を集める（`相手を1人に決める.md` 0章）。
アングルのページ（J）に「相手の型」（J-0）・「商品が要る1点」（J-0b）・「原稿用の3歩」（J-3b）・対策の4点（J-7）がある時は、3-1・3-3・3-4 はそこから作る。
相手を、年代や属性ではなく、困り事の出方で決める。いつ・何をしている時に困り、いつは平気か。何を試して、その後どうなったか。何を失っているか。同じ型の人が多い事を、声の数と調査の数字で確かめる。書き手が「いそうだ」と思った人を、相手にしない。

**3-2. 入口の事実**
相手が自分で気づいているのに、訳を説明できない事実を1つ（困る時と平気な時の差・試したのに戻った事、など）。

**3-3. 原因の1文**
困り事の原因を、ふつうの言葉で1文にする。**どこで・何が・どうなっているから、困り事が起きるのか。** 聞いた人が、そのまま人に話せる文にする。作った言い回しにしない。
- この1文を、台本の中で何度も使う。今している対策を外す時も、商品の働きを言う時も、この原因に届くかどうかで言う
- 今している対策には、対策ごとに別の理由を持ち出さない。全部「原因に届いていない」で言う

**3-4. 商品が要る訳**
原因の1文から、「だからこの商品が要る」までを、相手の言い返しに答える形で書く。相手は、次の事を思う。
- 放っておけば、そのうち治るのでは
- 今している事を続ければ、足りるのでは
- 原因そのものをやめれば、済むのでは
- 毎日できる別の手で、足りるのでは
- 困っていない時にも、原因は残っているのか
- この商品だと、なぜそれができるのか

答えの無い問いが1つでも残ると、相手はそこで離れる。

**3-5. 線**
入口の事実から商品まで、相手が信じる順に並べた段。1段は「相手の疑問」と「答え」の組。終わりから逆にたどって作る（「相手がこの商品を要ると思うには、その1つ手前で、何を信じていなければならないか」）。段は4〜6。

**3-6. 商品について言う事**
商品が要る訳から出た条件を1つずつ書き、商品のどこがそれを満たすかを、1対1で並べる。台本で言う商品の良さは、この表にある物だけ。条件と関係のない良さは、本当でも、動画では言わない。

**3-7. 言い分の確かめ**
線の答えと、商品の文を、1つずつ見る。
- 当てはめた物の全部に、本当に当てはまるか（いくつかの対策にまとめて理由を付ける時は、1つずつに当てはまるかを見る）
- 相手は、何と言い返すか。言い返しが成り立つなら、その言い分は使わない
- ほかの文と、逆の事を言っていないか

# 4. 最初の30秒（フック・リード・本文の入り）

ここで決めるのは、**仕事と、できたかどうかの確かめだけ。** 文の形・言い出し・終わり方は決めない。形を決めると、どの台本も同じ頭になる。

**4-1. フックの仕事（最初の3秒ほど）**
その悩みの人が、「自分の事だ」と分かって、手を止める。
- 確かめ：その悩みの人が、音と絵で3秒見て、自分の事だと分かるか。その悩みが無い人は、通りすぎるか
- 取り方は自由。困り事を言う・困る場面を見せる・困っている場所や物を指す・相手が言いそうな一言から入る・相手に何かを聞く・だれかが相手に話しかける、など。ここに無いやり方でもよい
- 相手を、試した手（使っている物・通っている所）の1つで絞らない。試した手は人によってばらける。その1つを使っている人しか残らなくなる（相手の型の声の大半が、同じ1つの手を挙げている時は別）

**4-2. リードの仕事（フックのすぐ後）**
見ている人に、最後まで見る理由ができる。
- 確かめ：ここで動画を止めたら、相手は「続きが気になる」「見ないと損をする」と思うか。それはなぜかを、1文で言えるか
- 理由の作り方は自由。する事を渡す・やめる事を渡す・思っている原因と違うと言う・確かめさせる・来た疑いに答える・ある人に起きた事を話し始める・放っておいた先を見せる・結果を先に見せる、など。ここに無い作り方でもよい
- 守る事は2つだけ
  - リードで言った事は、本文で必ず受ける。リードの次の文が、その受けの始まり
  - リードが相手に何かを求めたり、言い切ったりした時は、その理由が、相手に分かる所にある（すぐ後でも、本文の入りでもよい）

**4-3. 何本か書く時**
- 台本ごとに、フックの取り方とリードの作り方を、先に表に書き出す。同じ組み合わせが並んだら、変える
- 並べて声に出して、言い出しと文の終わり方が同じ台本が続いていたら、取り方から考え直す（言い回しだけを替えない）
- 取り方・作り方は、その台本の相手の型・入口の事実・運び方から決める。前の台本でうまくいった形を、次の台本に持ちこまない

**4-4. 独創は、どこで出すか**
取り方・作り方・見せる物・比べ方・語り手・入る場所・数え方で出す。言葉では出さない（1章）。

# 5. 線に無い話の扱い

書いている途中で「これも言いたい」と思った事は、線に照らす。どの段の答えでもない話は、入れない。相手が見終わった後に思いそうな疑問になる話は、記事への疑問に回す。今している対策・放っておいた先・変わった後の姿も、線の段になっている時と、最初と締めに要る時だけ入れる。

# 6. 運び方（普通・フォーマット）

（2026-11-22：「ユニーク」の運び方は使わない。運び方は「普通」か「フォーマット」のどちらか。語り手・始まり・時間の向きを変えたい時は、フォーマットのカードで決める）

線は、台本ごとに1本。変えるのは、線をどう運ぶかだけ。
- **普通**：線の順のまま、相手に向けて語る
- **寄せ方がある時**：寄せ方の1枚が、運び方を決める。線と、1章の言葉の決まりは、どの寄せ方でも同じ
- **フォーマット**（頼まれた時・運び方を変えたい時）：`フォーマット/一覧.md` で選び、`フォーマット/カード/` の1枚を使う。カードから使うのは運び方だけ。商品の資料に、カードの「要る材料」が無ければ、そのフォーマットは使わない
- 線を切る変え方はしない。問いを声に出す運び方では、問いのすぐ次の文が、その問いの答え
- 何本か書く時、台本どうしの違いは、相手の型・入口の事実・運び方から出す。書き手は前の台本を読まない（読むのは、何を使ったかの記録だけ）
- 運営者の指摘の中の例は、考え方として受け取る。指摘に出てきた数字・たとえ・対策・言い回しを、台本にそのまま使わない

# 7. 締め（着地が記事の時。この順は変えない）

1. 困り事が悪くなる時期が、これから本格的に来る事と、その訳
2. この時期に同じ困り事の人が多い事 → 商品が役に立っている事 → 在庫が少なくなっていた事 → 補充した事 → 在庫があるうちに、早めに検討してほしい事
3. 相手が見終わって思う疑問を並べる → 最後の1文は「下の記事にまとめました」で終える

時期・在庫の事実は、商品の `05_原稿の決まり` の値を使う。05 が止めている時は、書く前に運営者に確かめる。

# 8. 長さ

長さは、段の数ではなく、段の厚みで変える。短い台本は、各段を答えの1〜2文で言う。長い台本は、同じ段に、場面と説明を足す。長くしても、段を増やさない。

# 9. 書いた後の確かめ

1. **言葉**：1章の確かめを、1文ずつ。飾った言い回し・切り刻んだ文・省いた言葉を、ふつうの文に直す
2. **線**：本文の1文ずつに、どの段かを振る。振れない文は削る
3. **最初と締めが、線とぶつかっていないか**
4. **突っこみ役の1回**：別の読み手に、本文だけを渡す。①うたぐり深い相手の「でも…」に、本文が答えているか ②逆の事を言っている文の組 ③1回で意味が取れなかった文、を挙げてもらう。0になるまで直す
   - 別の読み手を立てられない時は、書き手が、設計メモを見ずに本文だけを頭から読んで、同じ3つを挙げる
5. 相手役の試写（人物になりきって感想を言う物）は、しない

# 10. 材料と、出す物

- 商品の事実・仕組みは、商品の資料から取る。資料の仕組みを、別の仕組みに替えない
- 商品の `05_原稿の決まり` とぶつかる文は、出す時に全部書き出す
- 出す物：設計メモ／本文（字数）／運び方／段の番号を振った表／突っこみ役の答えと直した所／05 との照合／作った値／記事への引き継ぎ
