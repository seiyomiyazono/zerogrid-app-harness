# 参照をなぞる（2026-11-27 外からの提案。参照の作り手が作ったような動画を、続けて出したい時の1枚）

参照の動画と同じ作り手が作ったように見える台本を、何本も書く時に使う。依頼票から1本ずつ書くふだんの台本は、今までどおり `台本の芯.md` から書く。

この1枚は、短い動画と画像の投稿で参照をなぞって量産した時に分かった進め方を、台本に当てはめた物である。広告の VSL と、英語の参照から日本語の台本を書く場合では、まだ確かめていない。最初の数本は、今の書き方の台本と並べて運営者に見てもらう。

## なぜ要るか

カードや寄せ方の1枚は参照を測ってまとめた説明なので、参照が面白い訳（具体的な一瞬・語り手の声・文の調子）は、まとめた時に落ちている。説明だけから書くと、骨組みは参照と同じなのに中身が平らな台本になる。

また、1本の参照だけを写して量産すると、全部がその1本と同じ流れになる。ある作り手の投稿を約100本並べた時、変えていたのは話の入口だけで、後半と見た目はほぼ同じだった。入口は約20種類あった。作り手が変えている所と変えていない所は、1本を見ても分からず、全部を並べて初めて分かる。

## 1. 参照を、作り手ごとに全部集める

- 1本ではなく、その作り手（ブランド・アカウント）の広告を、取れるだけ全部集める。GetHookd の search_ads で作り手の名前から探し、transcribe_ads で声を全部書き起こす
- 書き起こしは、まとめずに原文のまま置く。置き場所は商品のフォルダの `06_原稿/参照/<作り手>/書き起こし/<広告の番号>.md` で、スキルの中には置かない（いくつかの商品で使う参照の置き場所は、運営者が決める）。頭に、配信の日数・段（Winning など）・長さ・share_url を書く
- 絵は、get_ad_media で見られたコマだけを一緒に置く

## 2. 固定の所と、変えている所を数える

- 全部の書き起こしを並べて、どの本でも同じ所（固定）と、本ごとに変えている所（可変）を分ける。見る物は、入口（最初の何文か）・語り手・区切り方・商品の出し方・締め・長さ
- 可変の所は種類に分けて、種類ごとに本数と成績（配信の日数・段）を表にし、`06_原稿/参照/<作り手>/固定と可変.md` に置く
- 種類ごとに、その種類の広告の番号を2〜3本ずつ書いておく。書く時に開く原文は、この番号で探す
- 本数が少ない種類や、古い時期にしか無い種類は、成績が高く見えても、そう書き添える

## 3. 書く時は、原文を開いてなぞる

- `固定と可変.md` から可変の種類を1つ選び、その種類の原文を2〜3本開いて、読んでから書く。カードや表の説明だけからは書かない
- 固定の所は、参照のままにする（順番・長さの割合・語り手・締め方）。作り手が変えていない所を、こちらの工夫で変えない
- なぞるのは、文の長さと調子、行の終わり方、次の文へ引っぱる仕掛け、何を言わずに残すかである。行をそのまま訳して使わず、言いかえただけの行にもしない
- 1本の参照と、文の並びを1対1にしない。2〜3本の場面や段を組み直して使う
- 組み直したら、頭から声に出して通して読む。参照の文は前後の文とつながる前提で書かれているので、別の参照の文を隣に置くと、つながりが切れたままになる
- 商品の事実・原因の1文・売りの1行は、今までどおり商品の資料と `台本の芯.md` の1〜3章から取る。参照から取るのは、運びと調子だけ
- 台本の頭に、どの広告をなぞったかを番号で書く

## 4. 変えるのは、入口と見せ方だけ

- 何本も書く時、相手・悩み・売りは同じままでよい。同じ物を何度使ってもよい
- 本ごとの違いは、2章で分けた可変の種類（入口・語り手・見せ方）で付ける
- まだ使っていない相手・場面・言葉を探しに行かない。探すほど、商品でできる事から離れた台本になる

## 5. 面白いかどうかは、案の段階で運営者が選ぶ

- 台本を書く前に、入口の案を5つ出す。1案は題と流れを3〜5行で書き、なぞる広告の番号を付ける。案は、台本の承認と同じやり方で運営者に見せる
- 運営者が選んだ案だけを台本にする。運営者が案に書きこんだ言葉は、そのまま使う
- 面白さを、確かめ表の項目を足して作ろうとしない。確かめ表で見るのは、事実・読み・線が切れていないかである

## 6. 直しの残し方

- 運営者の直しの言葉は、まとめずに原文のまま、日付を付けて商品のフォルダ（`06_原稿/直しの記録.md`）に残す
- 直しを原則にする時は、名前・訳・確かめ方（問いは2つまで）を付ける。良かった案と悪かった案を、運営者の評価と一緒に表にして、同じファイルに置く。スキルに入れるのは、原則の名前と訳だけにする（SKILL.md の大もとの決まり）
- 配信の成績から足した決まりと、まだ確かめていない考えを分ける。確かめていない物には「仮説」と書き、成績で確かめるまで決まりにしない
- 決まりを足したら、逆を言っている古い文を消す。上に重ねない

## ほかの決まりとの関係

- この1枚を使う時、`台本の決まり.md` 6章の「台本どうしの違いは、相手の型・入口の事実・運び方から出す」は、上の4章（相手は同じでよい）に読み替える
- カードの中の秒・％・文の数は、今までどおり、測った事実であって守る決まりではない（`フォーマット/一覧.md` の読み方）。長さや位置は、開いた原文に合わせる
- `台本の決まり.md` 1章（言葉は、ふつうに言う）と、商品の `05_原稿の決まり` は、そのまま守る
