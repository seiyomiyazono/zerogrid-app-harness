# 文章の決まり（書いた後に、1文ずつ当てる。2026-11-22 に作り、2026-11-24 に本物へ入れた。`台本の芯.md` と食い違う時は、芯が先）

入れていない章：商品の例だけの章（前の0章・3章）、出どころのメモ（4章）、言えない言葉の言いかえ（9章。技術テストでは法令の言葉の制限を当てない、という運営者の指定とぶつかるので、運営者が決めるまで入れない）。

## 1. フックの決まり（最初の1〜3文）

**1〜3文目のどこかで、見る人にとっての得を予告する。予告だけして、中身は言わない。**

| 順 | 仕事 | 例の形（言い回しは台本ごとに変える） |
|---|---|---|
| ① 悩みの名指し | その悩みの人が「自分の事だ」と分かる。場面・時刻・数字で言う | 「布団に入っても2時間眠れない人」「午後3時を過ぎると首が板みたいになる人」 |
| ② 得の予告 | この先に、自分の悩みが良くなるかもしれない話があると分からせる。**中身は言わない** | 「うれしいニュースがあります」「その枕、もう買い替えなくていいかもしれません」「揉みに通わなくても、首を軽いままにしておける方法があります」 |
| ③ 意外な行動・意外な事実 | 得の予告と結びつかないように見える物を出して、「なんで？」を作る | 「寝る前に、チクチクした物の上に乗ってみてください」 |

チェック：
- [ ] 1〜3文目のどこかに、見る人の得（悩みが良くなる・お金や手間が減る・今の困りがなくなる）が聞こえるか
- [ ] その得の「中身」（仕組み・商品名・やり方の全部）を、ここで言いすぎていないか。言うのは「ある」という事まで
- [ ] 意外な行動・意外な事実だけで始めていないか（得の予告が無い「なんで？」は、通りすぎられる）
- [ ] 悩みは、ふわっとした言葉（「眠れない」）ではなく、場面か数字（「布団に入っても2時間」）で言っているか
- [ ] 得の予告は、本文で必ず回収するか（予告した得が本文で出てこないと、だまされたと感じる）
- [ ] 何本か書く時、得の予告の言い方が台本どうしで同じになっていないか（台本の決まり 4-3）
- [ ] 運び方（型）が「名乗り」「欠点」「時刻」から始まる時も、3文目までに得の予告を入れる（型の始まりは変えず、その間か直後に挟む）
- [ ] 7章の「3つが全部立つか」も当てる（この1章は最低の線。7章が強める側）

なぜこの決まりか（出どころ）：
- 好奇心は「知っている事と、知りたい事の間に空いた穴」に気づいた時に起きる。穴を見せて、まだ埋めないと、人は埋めたくなる（Loewenstein 1994「The Psychology of Curiosity」Psychological Bulletin 116(1)）
- ただし穴だけでは弱い。見出しでいちばん効くのは「自分の得」、その次が「新しい知らせ」、その次が「好奇心」。得と好奇心を組み合わせると強い（John Caples『Tested Advertising Methods』の見出しの考え方。二次の解説による）。「うれしいニュースがあります」は、得（うれしい）と新しい知らせ（ニュース）と空白（中身は言わない）を1文でそろえている
- ターゲットを主語にする・商品の説明ではなく得を伝える、が日本のコピーの定番の考え方（自分ごと化）

## 2. 1文ずつのチェックリスト（声に出したつもりで当てる）

### 2-1 長さと中身
- [ ] 1文に言う事は1つか（一文一義）。2つあるなら、文を切る
- [ ] 1文が長すぎないか。目安は、書いた文で50〜60字を超えたら疑う。耳で聞く台本は、もっと短い方がいい（25字前後で息つぎできるか）
- [ ] 「〜が、〜して、〜なので、〜」と、つなぎでずるずる続けていないか（接続助詞「が」と、文を切らずに続ける書き方を重ねない）
- [ ] 3つ以上並べる時、聞いて追えるか（「〜も、〜も、〜も」で並べるか、1つずつ文にする）

### 2-2 主語と述語
- [ ] 主語と述語が、かみ合っているか（ねじれていないか）。「〇〇の訳は、〜からです」「冴えるのは、〜せいではありません」の形はOK。「〇〇の訳は、〜します」はねじれ
- [ ] 1文の途中で主語が入れかわっていないか
- [ ] 物が主語で、人の動き（「する」）を言っていないか。「ミルクが温めるのは、お腹の中だけ」→「ミルクで温まるのは、お腹の中だけ」

### 2-3 語順と修飾
- [ ] 係る言葉と受ける言葉が、近くにあるか
- [ ] 修飾が2つ以上ある時、長い方を先に置いているか（本多勝一『日本語の作文技術』の修飾の順序）
- [ ] 基本の順（いつ・どこで・だれが・何を・どうした）から外れる時、外す訳があるか（強調したい物を頭に置く時だけ）
- [ ] 「の」「に」「も」などの同じ助詞が続いていないか（「昼の緊張の首の…」）

### 2-4 言葉の組み合わせ（連語）
- [ ] 副詞と述語の組み合わせが、ふつうか（例2）。迷ったら、その組み合わせを日常で聞いた事があるかで決める
  - はっきり → 言う／見える／分かる（×はっきり痛い）
  - 正直 → 「正直に言うと」「正直、〜」（前置き）
  - じんわり → 温かくなる／しみる（×じんわり押す）
  - ぴたっと → 止まる
- [ ] 動詞と名詞の組み合わせが、ふつうか。「訳を言います」→「理由を話します」、「力を抜く事はしません」→「力は抜けません」、「信号を送る」→「合図を送る」
- [ ] 書き言葉の固い言い方を、口の言い方に直したか
  - 〜する事はしない → 〜しない
  - 〜の訳 → 〜の理由／なんで〜か
  - 一度に → いっぺんに（話し言葉の時）
  - 休む時の状態 → 休むモード／体が休む側
  - 約6,210本 → 6,000本以上（聞いて分かる丸め方。中身の数は変えない）

### 2-5 話し言葉のリズム
- [ ] 文末が同じ形（「〜んです」「〜です」）で3回以上続いていないか
- [ ] 「〜んです」は、理由や気持ちを打ち明ける所だけに使っているか（全部に付けると押しつけがましい）
- [ ] 問いを声に出したら、すぐ次の文が答えか（台本の決まり 6章）
- [ ] 欠点・本音を言う前に、前置き（「正直に言うと」「店の人間が言うのも変ですが」）を入れているか。前置きは信用を作る
- [ ] 数字は、耳で1回聞いて分かる形か（「2リットルのペットボトル2本半」は良い）

### 2-6 最後の確かめ（台本の決まり 1章のまま）
- [ ] 小学5年生が1回聞いて、自分の言葉で言い直せるか
- [ ] 相手が家族に言う時、同じ言い方をするか
- [ ] 声に出して、口が止まる所・言いにくい所が無いか

## 5. 好奇心の空白を最後までつなぐ（2026-11-22 運営者の手直し：「答えを見せてるけど、疑問を残しながら先に繋げていく感じ、そこを強化して」）

### 5-0 考え方
好奇心は、「知っている事」と「知りたい事」の間の穴に気づいた時に起きる。穴は、答えを全部隠すと開かない（何が分からないのかが分からない）。全部見せると閉じて、冷める。**いちばん開くのは、答えが半分見えている時。** だから台本は、答えを少しずつ見せて、見せるたびに次の穴を開ける。フックで開けた1つの大きい問いを、最後まで開けたまま運び、その間に小さい問いを開けては閉じる。

### 5-1 空白を作る物・冷ます物

| | 何が起きるか | 最初に試した商品での形 |
|---|---|---|
| **作る** 答えの一部を見せる | 何が起きるか・どこか・いくつか、だけ言う。なぜ・どうやっては、まだ言わない。半分分かると、残りの半分が気になる | 「この痛い1分のあとで、背中に面白い事が起きます」（場所だけ言う） |
| **作る** 自分の悩みの答えである | 自分の得につながる問いほど、答えを知りたくなる | 「その枕、もう買い替えなくていいかもしれません」 |
| **作る** 問いがはっきりしている | 見る人が「〇〇は何？」と1文で言い直せる | 「戻る理由は2つあります」→「2つって何？」 |
| **作る** 知っている事とずれる | 頭の悩みなのに背中、枕の話なのに枕は関係ない、痛いのに力が抜ける | 「痛いのに力が抜けるなんて、変に聞こえますよね」 |
| **作る** 先に考えさせる | 答えの前に見る人に当てさせると、答えが残る。問いの次の文で、すぐ答える | 「原因は、どこにあると思いますか。頭ではありません」 |
| **冷ます** 閉じすぎ | 最初に、仕組み・商品名・結論を全部言う。もう見る理由がない | 「肌のセンサーが休むモードに切り替えて、背中の力が抜けるので眠れます」（フックで全部） |
| **冷ます** 大きすぎ | 何が分からないかが分からない。諦めるか、あおりに聞こえる | 「体に、すごい事が起きます」「驚きの方法があります」 |
| **冷ます** 自分に関係ない | 話し手の得・豆知識の穴は、埋めたいと思わない | 「その訳が分かったので話します」（分かったのは話し手） |
| **冷ます** 引っぱった割に中身が薄い | 待たせた先が小さいと、だまされたと感じる。山場で切るテレビの「この後すぐ」は、嫌われやすい | 「答えはこの後！」と言って、次に一般論 |
| **冷ます** 開けっぱなし | 開けた問いを閉じないと、残るのは答えでなく不満 | フックの「うれしいニュース」を、最後まで回収しない |
| **冷ます** 問いを並べすぎ | 同時にいくつも開くと、どれも弱くなり、追えなくなる | 1つの区切りで「なぜ」「いつ」「どこ」を全部開く |

### 5-2 区切りごとの型：①一部答える → ②新しく開く → ③渡す

区切り（空行で分けた段落）ごとに、この3つを置く。フックの区切りは①が無く、締めの区切りは③が「下の記事にまとめました」になる。

| 順 | 置く所 | 仕事 | 形の例（言い回しは台本ごとに変える） |
|---|---|---|---|
| ① 前の問いに一部答える | 区切りの頭 | 前の区切りで開けた問いを、ここで受ける。全部答えてもよいが、大きい問いは一部だけ。見る人が「得をした」と感じる中身を入れる（中身の無い受けは、あおり） | 「考え事が、ぴたっと止まります」「まず、机に向かっている間の首です」 |
| ② 新しい問いを開く | 答えのすぐ後 | 答えた事から、次の「でも」「じゃあ」が出るようにする。答えの中に、まだ言っていない所（なぜ・どうやって・いつ・何で）を残す | 「ただ、これはまだ入口です。痛みに慣れたら、考え事はまた戻ってきます」 |
| ③ 次の区切りへ渡す一言 | 区切りの最後の1〜2文 | 次で何が分かるかを、中身を言わずに指す。短く | 「戻ってこなくなるのは、5分を過ぎてからです」「この張りがどこから来たのかは、時計をもう一度戻すと分かります」 |

書き方の決まり：
- **声に出した問いは、すぐ次の文で答え始める**（台本の決まり 6章・この決まり 2-5 のまま）。だから、開けたまま次へ渡す問いは、**問いの形にしない。言い切りの文で開ける**（「〜が起きます」「理由は2つあります」「〜は、〜ではありません」）。問いの形を使うのは、すぐ答える小さい問いだけ（「じゃあ、揉む回数を増やせば追いつくのか。それも違います」）
- **一部の答え方**は、次のどれか：何が起きるかだけ言う／場所だけ言う（背中に）／数だけ言う（2つあります）／違う方だけ言う（頭ではありません・朝ではありません）／1つ目だけ言う（理由の1つ目が、これです）
- **問いの大きさは3つ。** 大＝フックの得の予告（終わり近くまで開けておいてよい）／中＝区切りをまたぐ問い（途中に一部の答えを置く）／小＝次の区切りまでに閉じる問い（目安：30秒＝約180字以内）
- **同時に開いているのは3つまで（大1つ＋中か小で2つ）。** 大きい問いは途中で一部ずつ答える（目安：全体の3分の1までに1回、3分の2までにもう1回）
- **一部答えると、問いは細くなる。** 「なんで眠れる？」→「なんで5分目？」→「なんで痛いのに力が抜ける？」。細くなった問いは、新しい問いとして数えず、同じ問いが前に進んだと数える。細くならずに同じ問いをくり返すのは、引っぱっているだけ
- **渡す一言は、台本ごと・区切りごとに言い方を変える。** 同じ言い回し（「でも、話はここからです」）を並べない（台本の決まり 4-3）
- **あおらない。** 「この後すぐ」「答えは〇秒後」「驚きの」「衝撃の」は使わない。引っぱるのは、30秒以内に中身が来る時だけ
- **締めの疑問は、わざと開けたまま記事へ渡す問い。** 本文で閉じた問いをもう一度並べない。本文で答えていない所（何日で・何分・どこに・大丈夫か）にする
- 構成と運び（型）は変えない。足すのは、区切りの頭と終わりの1〜2文だけ。線（台本の決まり 2章）に無い話を、つなぎのために足さない

### 5-3 開いた問いと閉じた場所の表（書く前に作り、書いた後に当てる）

台本の末尾に、この表をつける。秒は、1秒6字（改行を除く）で数えた目安。

| 番号 | 問い（見る人の頭の中の言葉で） | 大きさ | 開いた所（秒） | 一部答えた所（秒） | 閉じた所（秒） |
|---|---|---|---|---|---|
| 例 Q1 | チクチクの上に乗ると、なんで眠れるの？ | 大 | フック（0秒） | 「考え事が止まる」（38秒）・「痛いマットだと力が勝手に抜ける」（117秒） | 「考え事を本当に止めるのは、力が抜けること」（195秒） |
| 例 Q6 | マットの上でそのまま眠るの？ | 小 | 使った人の声の後（212秒） | ― | すぐ次の文（216秒） |
| 例 記 | 寝る直前に乗って、かえって冴えないの？ | 記事へ | 締め | ― | 記事で閉じる |

表の当て方：
- 「閉じた所」が空の問いが無いか（記事へ渡す問いは「記事へ」と書く）
- 大きい問いに「一部答えた所」が無いか（無ければ、間が長すぎて冷める）
- 小さい問いが、開いてから30秒以上閉じていないか
- 同じ秒に、開いている問いが4つ以上ないか
- フックで予告した得（「うれしいニュース」「買い替えなくていい」「通わなくても」）が、表のどこかで閉じているか

### 5-4 閉じすぎ・開けっぱなしの見分け方

- [ ] **閉じすぎ**：区切りの最後の文で止めて、見る人の「で？」「なんで？」が1つ言えるか。言えなければ閉じすぎ。③を足す
- [ ] **閉じすぎ**：フックで、仕組み・商品名・結論のうち2つ以上を言っていないか
- [ ] **大きすぎ**：開けた問いを、見る人の言葉で1文に言い直せるか。「背中に何が起きるの？」は言える。「すごい事って何？」は中身が無い
- [ ] **関係ない**：その問いの答えが、見る人の悩み（眠れない・首が張る・朝こわばる）につながるか
- [ ] **開けっぱなし**：表で「閉じた所」が空の問いが無いか。予告した得を本文で回収したか
- [ ] **あおり**：渡す一言の後、30秒以内に中身（①）が来るか
- [ ] **問いの形**：声に出した問いの次の文が、答えの始まりになっているか
- [ ] **並べすぎ**：同時に開いている問いが3つ（大1＋中・小で2）を超えていないか

### 5-5 直し方の例（悪い → 良い）｜最初に試した商品 R・S・T の v2 から v3 へ

| 悪い | どこが悪いか | 良い（v3） |
|---|---|---|
| （R フック）でも、この痛い1分のあとで、体に面白い事が起きます。 | 「体に」では問いがぼやける（大きすぎ） | でも、この痛い1分のあとで、背中に面白い事が起きます。（頭の悩みなのに「背中」。ずれが問いをはっきりさせる） |
| （R）…考え事が、ぴたっと止まります。背中のチクチクに、気持ちが全部持っていかれるからです。→（次の区切り）ここで、布団に入ると頭が冴える理由を話します。 | 「止まった」で閉じたまま、話が変わる。③が無い | …持っていかれるからです。ただ、これはまだ入口です。痛みに慣れてきたら、考え事はまた戻ってきます。戻ってこなくなるのは、5分を過ぎてからです。その前に、布団に入ると頭が冴える理由を話させてください。 |
| （R）ここで、布団に入ると頭が冴える理由を話します。原因は、頭ではありません。 | 答えを先に渡すだけ | 原因は、どこにあると思いますか。頭ではありません。背中と肩です。（先に当てさせて、すぐ答える） |
| （R）…止めようとするほど、かえって目が冴えてしまいます。→（次の区切り）寝ころんで1、2分たつと… | 今の手がだめ、で閉じる。マットへの橋が無い | …目が冴えてしまいます。つまり、考え事を止めたいなら、背中の力を抜けばいいんです。でも、自分ではなかなか抜けません。ところが、あの痛いマットに寝ころぶと、力が勝手に抜けていくんです。痛いのに力が抜けるなんて、変に聞こえますよね。（一部答えて、ずれで開ける） |
| （R）押しているのは、自分の体重だけです。…5分を過ぎると、体が休むモードに… | 理由が並ぶだけで、どこで答えが出たか分からない | …拾い続けます。痛いのに力が抜ける理由の1つ目が、これです。もう1つは、押している物です。…この2つがそろうと、5分を過ぎたあたりで…（1つ目だけ言う → 2つ目 → そろう） |
| （S）なんで戻るのか。お客さんたちは、重い物を持っているわけではありません。 | 問いの次の文が答えでない。理由がいくつあるかも見えない | 15年見てきて、戻る理由は2つあると分かりました。1つは、机に向かっている間の首にあります。もう1つは、私の手にあります。どちらも、店の中では手が届かない所です。（数と場所だけ見せて、答えの向き〈店の外〉だけ言う）→ まず、机に向かっている間の首です。 |
| （S）首から背中までいっぺんには、私の手では押せません。→（次の区切り）張りは毎日… | 「じゃあどうする」の橋が無い | …私の手では押せません。じゃあ、揉む回数を増やせば追いつくのか。それも違います。（すぐ答える小さい問い） |

## 6. 書く前に決める：売りを1つに決め切る（2026-11-22 夜 運営者の手直し：「売りたい要素を決め切らなあかん。今は全部『チクチクが考える暇を取ってくれる』。困っている人の大きさ的に“痛み”の方が強い。即効で効くんだ、も魅力」）

台本の決まり 3章の設計メモの**一番先**に、この2つを決める。決めるまで、線（3-5）を引かない。

### 6-1 一番大きい悩みを選ぶ
商品の資料（B 市場と悩みの地図・F 刺さる層・J の J-0）から、候補の悩みを3〜5つ出し、次の3つで比べる。点は 大＝3・中＝2・小＝1 で付けて、掛けた数の一番大きい物を選ぶ。

| 見る所 | 何で決めるか | 出どころの置き場所 |
|---|---|---|
| 人数 | 国の調査・声の件数。多い順 | B の数字・J-0 の件数 |
| 痛さ | 体が痛い・動けない＞重い・だるい＞眠れない・気持ちが落ちる。**体の痛みは、眠り・気持ちより強い事が多い** | J-1 の原文の言葉（「耐えられない」「限界」があるか） |
| 今すぐ何とかしたい度 | 今日・毎日困るか／たまにか。湿布・薬・店にお金を払っているか | J-7 の対策と、そのお金と手間 |

- 体の痛み（首・肩・腰の痛み・張り）と、眠り・気持ちの悩みが並んだら、まず痛みの方を疑って比べる。眠りや気持ちが勝つのは、相手がそれにお金を払っている声が多い時だけ
- 痛みの悩みは、**原因が分かりやすい**（「この筋が、ずっと働きっぱなし」と1文で言える）。原因が分かりやすい悩みは、商品が届くと思わせやすい

### 6-2 その悩みに対する、商品の一番強い売りを1つ選ぶ
商品の強み（I・E）の中から、選んだ悩みに一番届く物を1つだけ選ぶ。ほかの強みは、その1つを支える時だけ言う（並べない）。
- 比べる順：①その場で体で分かるか（乗った・使ったその場で感じる）②手間が少ないか（寝ころぶだけ・家で）③ほかの手に無いか（面で同時に・6,000本）
- **「その場で感じる」（即効）は、一番強い売りになりやすい。** 見る人が「今夜ためして、すぐ分かる」と思えるので、買う前の迷い（本当に変わる？）が小さくなる。ただし言い方は 9章（体で感じる事として言う）
- 眠り・気持ちの良さ（うとうと・考え事が止まる）は、痛みを売りにする台本では、最後に1文だけにする。主役にしない

### 6-3 台本の頭に1行書く
台本ファイルの頭（設計メモの上）に、この形で1行。
- 「決めた売り：<悩み>に、<商品の一番強い売り>。選んだ訳：<人数・痛さ・今すぐ度のどれが勝ったか>」

## 7. フック・リードを強める（2026-11-22 夜 運営者の手直し：「フック・リードにもっとこだわって。見たいと思えない。インパクトに欠ける」）

1章（得の予告）は最低の線。この章は、それを強める側。

### 7-1 最初の3秒で、3つが全部立つか
| 立てる物 | 見る人の頭の中 | 無いと何が起きるか |
|---|---|---|
| ① 自分の事だ | 「これ、私の肩や」 | 通りすぎる |
| ② え、何それ | 「どういうこと？」 | 分かった気になって通りすぎる |
| ③ 得がある | 「見たら、私が楽になるかも」 | 「へえ」で終わる |

- 3つは、1文に全部入れなくてよい。**①は1文目の頭（最初の3秒・20字以内）で立て、②③は2文目の終わりまで（目安：声で10秒・60字前後）にそろえる**。2文目が長くなる時は、②③の言葉を2文目の前の方に置く
- ①は、悩みの名前だけでなく、**場面か数字**で（「肩こり」→「揉んでもらっても3日で戻る肩こり」）
- ②は、見る人の思いこみとずれる物で作る（下の5つの型）
- ③は、**決めた売り（6章）を指す**。中身は言わない。「どれくらい早く・どれくらい楽に」が見えると強い（「5分」「寝ころぶだけ」）

### 7-2 強い型5つ（悪い → 良い）
勝っている広告のフック（`フォーマット/カード/` A〜O の「フックの分解」）から、よく出る形をまとめた。言い回しは台本ごとに変える（台本の決まり 4-3）。

| 型 | 何で②を作るか | 悪い | 良い | 何が変わったか |
|---|---|---|---|---|
| 数字 | 思っているより大きい・小さい数 | 肩こりがつらい人に、おすすめのマットがあります。 | 人の手で同時に押せるのは、多くて10か所です。このマットは、6,000か所をいっぺんに押します。 | 数の差が②。①③は直後に足す（「揉んでも戻る肩こりの人は…」） |
| 意外な原因 | 責めている物と違う所を指す | 肩こりの原因は、姿勢の悪さです。 | 揉んでも3日で戻る肩こりは、揉む所が違うのではありません。休めていない筋肉が、毎日同じなんです。 | 「揉む所」と思っていた所を外す。原因の向きだけ見せる |
| 常識の否定 | みんながやっている事を、やめていいと言う | ストレッチも大事ですが、もっと良い方法があります。 | 肩こりが止まらない人、肩を回すのは、今日でやめてください。 | 「やめる」が②。③は次の文で（「代わりに、寝ころぶだけで…」） |
| 具体的な場面 | 見る人の毎日の1コマを言い当てる | デスクワークで肩がこる人へ。 | 夕方4時、パソコンを閉じて伸びをしたら、肩がゴリッと鳴る人。 | 場面で①が強くなる。②③はすぐ後に |
| その場の変化 | 見ている間に、体が変わるのを見せる | このマットを使うと、肩が楽になります。 | 今から5分、このトゲの上に寝ころびます。5分後に首を回した時、私が何と言うか、見ていてください。 | ②と③が、目の前で起きる事になる。結果は言わず「何と言うか」を開ける |

- 型は2つ組んでよい（場面＋その場の変化、など）。3つ以上組むと、2文に入らない
- **悪い例に共通するのは、「説明」から入っている事。** 良い例は、見る人の頭の中の言葉（思いこみ・場面・数）から入る

### 7-3 リードで「この先を見れば◯◯が分かる」を約束する
フックの直後（声で5〜15秒の所）に、**この先で何が分かるか**を1文で言う。見る人が「それが分かるなら、最後まで見よう」と思える物にする。
- 形：「最後まで見ると、<見る人が知りたい事>が分かります」「<〜する>間に、<〜の理由>を話します」
- 約束する物は、見る人の得になる問い（なぜ戻るのか・なぜ5分で変わるのか）。話し手の得（「私が気づいた事」）は約束にならない
- 約束は2つまで。3つ言うと、どれも弱くなる
- **約束した物は、本文で必ず閉じる**（5-3 の表に、約束の行を作る）

チェック：
- [ ] ①自分の事だ が1文目の頭で立ち、2文目の終わりまでに ②え、何それ ③得がある、がそろっているか。1つずつ、どの言葉で立っているかを書き出せるか
- [ ] ③の得は、決めた売り（6章）を指しているか
- [ ] 説明・商品の種類の紹介から入っていないか
- [ ] リードに「この先を見れば◯◯が分かる」の約束が1文あるか。約束は2つまでか
- [ ] 約束を、本文のどこで閉じたか言えるか

## 8. 運びのわかりやすさ（2026-11-22 夜 運営者の手直し：「運び方がわかりにくい」）

### 8-1 区切りを減らす。1区切りに1つの事
- **区切り（空行で分けた段落）は、フックとリード・本文・締めを合わせて5〜6まで。** 7つ以上になったら、2つを1つにまとめるか、線に無い話を削る（台本の決まり 5章）
- 1区切りで言うのは1つの事だけ（原因なら原因だけ。原因と今の手を同じ区切りに入れない）
- 区切りの中の小さい問い（5-2）は、その1つの事を進めるための物だけ

### 8-2 区切りの頭で「今どこの話か」を1文で言う
- 区切りの頭の1文で、見る人が「今は◯◯の話」と分かるようにする。型の区切り（時計・数・場所）を、そのまま頭に言うのが一番分かりやすい（「今、1分たちました」「次は、10か所です」）
- 5-2 の「①前の問いに一部答える」と、この1文は兼ねてよい。兼ねる時も、何の話かが分かる言葉を入れる
- 見る人が途中から見ても（5秒だけ聞いても）、今どこか分かるか、で確かめる

### 8-3 型の区切りを、見る人の目印にする
- 型の進み方（時計・数・順）を、最初に1回だけ見せる（「5分を、1分ずつ話します」「押す所を、1か所から増やしていきます」）
- その目印を、区切りごとに同じ形でくり返す。目印の言い方は、台本の中ではそろえる（台本どうしでは変える）

チェック：
- [ ] 区切りは6つまでか
- [ ] 区切りごとに、言っている事を1語で言えるか（言えない区切りは、2つの事が混ざっている）
- [ ] 区切りの頭の1文で、今どこの話か分かるか
- [ ] 型の目印を、最初に1回見せて、区切りごとにくり返しているか
