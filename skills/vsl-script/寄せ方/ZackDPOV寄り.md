## 1. どんな台本か
- 語りが、見る人に「あなたは◯◯です」と言い、**困り事の場面にいる、だれか・何か（＝視点の主）の目**に入れる。最後まで、主語の「あなた」は、視点の主。
- 視点の主には「仕事」が1つある。**その仕事を、そのままやった結果が、相手（買う人）の困り事になっている。** 見る人は、中から見て「そういう訳だったのか」と気づく。
- 途中で、語りが1度だけ**外の目**に出て、訳（原因）を言う。商品は、視点の主の世界に「ある日、入ってくる物」として出て、同じ場面が変わる。

## 2. 基盤のまま守る事
**必ず入れる物**
1. だれの話か：最初の3文までに、**相手が毎日している事か、毎日言っている言葉**を、その人の言葉のまま入れる（3章の「書き出し」）
2. 視点の主の仕事 → それが困り事になる、ずれ（3-2）
3. 原因の1文（外の目で。記事へ送る時は「名前だけ」）
4. 商品は何か・商品が原因に何をするか（厚さは着地で変わる＝3-4）
5. 締め（記事へ送る時は `台本の決まり.md` 7章）
- そのほかに守る物：`商品を読む`（理解メモ）・`相手を1人に決める`（人物メモ）・`references/台本の決まり.md`・困り事は相手の言葉で・1文ごとに絵に描ける・だれの話かを先に指す・`出力の形` の「声に出して読まれる台本」。
- **守らなくてよい物**：線（`台本の決まり.md` 3章）の段の、厚さの配分・順番・原因の位置・目安の長さ（この1枚の 3章・4章の数にする）。1文目で「やばい」を言い切る事（こわさは、3-2 の ⑧ に置く）。たとえ（入れない。視点の主の目で、そのまま見せる）。
- **線（`台本の決まり.md` 3章）の段の通る点は、全部通す。** だれが言うか（中の目・外の目）は、3-3 の表。

## 3. 基盤から変える事
### 3-1. 視点の主（だれの POV にするか）の選び方 — どの商品でも、この手順
**基準：困り事の起きている所を、一番近くで見ていて、相手（買う人）の知らない訳を、体で知っている者。**

1. **困り事の場面を1行で書く**（人物メモと、アングルのページから）：いつ・どこで・だれが（何が）・何をして・だれが困るか。
2. **その場にいる者を、下の5種類で、全部書き出す**（いない種類は「無い」と書く）。
   | 種類 | 中身 | 向く時 |
   |---|---|---|
   | ア 相手本人 | 買う人。困っている当人 | 困り事が、相手の体・気持ちの中で起きていて、まわりに分かってもらえない時 |
   | イ 相手の家族・生き物 | 困り事を**起こしている側**の人・生き物（相手は、その世話をしている・一緒に暮らしている） | 相手が、その人・生き物の行いに困っている時。**相手が、その者を責めている・自分を責めている時に、一番効く** |
   | ウ 相手の体の部分 | 困り事の起きている所そのもの | 相手が、体の中で起きている事を知らない時 |
   | エ 今使っている物（敵の物） | 相手が、今の対策として使っている物・当たり前に使っている物 | その物が「よく働いている」事が、原因になっている時 |
   | オ 商品そのもの | 売る物 | 似た物と比べられている時（④）。作りの差を、中から見せたい時 |
3. **物差し5つで、○×を付ける。○が一番多い者にする。** 同じ数なら、①と②が○の者。
   | # | 物差し | ○の形 |
   |---|---|---|
   | ① | 近さ | 困り事が起きる、その時・その場所に、いる（触れている・中にいる・目の前で見ている） |
   | ② | 知っている事 | 相手が知らない訳を、その者は、**体の感じ・目の前の出来事**として知っている（「何も感じなかった」「言われたとおりにやった」の形で言える） |
   | ③ | 仕事 | その者の「仕事」を、1文・15字までで言える。相手も「そうだ」と思う仕事である |
   | ④ | 絵 | その者の目の高さから、相手の顔か、相手の大事な者の顔が、見える（映像の決まり 2章） |
   | ⑤ | 責めない | その者の目で語っても、相手（買う人）が悪者にならない。その者も悪者にならない |
4. **認知段階で、向きを確かめる**（4章の表）。合わなければ、次に○の多い者にする。
5. 台本の頭の行と、台帳に「視点の主：◯◯（種類 イ）」と書く。**同じ商品の前の台本と、違う種類にする**。

- 依頼票の「型ごとの指定」に視点の主が書いてあれば、それ。手順は飛ばす（④と⑤だけ確かめ、通らない時は、書かずに報告する）。
- **運びの形は2つ**（視点の主の種類で決まる）：
  | 形 | 視点の主 | 芯の1文 |
  |---|---|---|
  | **A 起こす側の目** | ア・イ・ウ | 「あなたは、自分の仕事を、そのままやった。それなのに、相手が困る」 |
  | **B 道具の目** | エ・オ | 「あなたは、仕事をしただけ。でも、◯◯なのは、あなたが◯◯すぎるせい」（エ）／「あなたは、◯◯のために作られた」（オ） |

### 3-3. 台本の切り替えの決まり（中の目と、外の目）
台本の文は、**中の目**（視点の主が、見る・感じる・する事）か、**外の目**（語りが、見る人に教える事）の、どちらか。まぜない。
| 言う事 | どちらの目で | 形 |
|---|---|---|
| 相手の場面・相手の言葉 | 中の目 | 視点の主から見た呼び名で（「あの人」「持ち主」「◯◯さん」の類。人物メモの人と同じ場面） |
| 困り事（相手の言葉） | 中の目 | 相手のせりふ、または、相手の顔・動作 |
| 今している対策 | 中の目 | 相手が、視点の主の前で、それをする |
| 原因の1文 | **外の目** | ⑦。1文で言い切る |
| 原因の仕組み（なぜ） | 外の目 | ⑦の中。記事へ送る時は、言わない |
| 放っておいた先 | 外の目 | ⑧。形B は「あなたを◯◯したまま」のように、視点の主を主語に入れてよい |
| 商品の姿・使った時の感じ | 中の目 | ⑨ |
| 商品の名前・作り・する事 | **外の目** | ⑩ |
| 締め | 外の目 | ⑪ |

- **外の目に出るのは、2回だけ**（⑦〜⑧と、⑩〜⑪）。出る時は、**出る印の1文**を置く（⑦「◯◯たちは、分かっていません。」／⑩ は、商品の名前の文そのもの）。⑦の後は、**戻る印の1文**で中の目に戻る。
- 外の目の文は、**続けて4文まで**（締めは別）。それより長く説明しない。
- **⑩から後ろでは、「あなた」を使わない。**（そこまでの「あなた」は視点の主。締めで「あなた」と言うと、見る人か視点の主か、分からなくなる。締めの文は、主語なしで書く）
- 台本の出力では、外の目の行の頭に `【外】` の印を付ける（5章）。

### 3-6. 人でない物・生き物を、視点の主にする時の決まり
1. **持たせるのは、目と、体の感じと、仕事。** 人の言葉で考えさせすぎない。「うれしい」「こまる」「分からない」「こわい」までは、よい。
2. **知っている事**：自分の体に起きる事（触れる・ぬれる・押される・重い・熱い の類）／目の前の出来事／相手の顔と声／自分の仕事。
   **知らない事**（中の目の文に書かない）：商品の名前・材料や作りの名前・数字・専門の言葉／相手が、なぜ怒る・困るのか／この先どうなるか／ほかの家の事。→ これらは、外の目（⑦⑧⑩）でだけ言う。
3. **仕事は、その物・生き物が、本当にしている事**（資料・広く知られている事）。作り話の力を持たせない。**敵の物（エ）の働きは、うそなく、良い所として言う**（1つ認める。けなさない。「悪いのは、物ではなく、合っていない事」の形にする）。
4. **しゃべらせない**（声に出すせりふは、相手と、人の視点の主だけ）。物の気持ちは、語りが「あなたは、◯◯します」と言う。
5. **一人称の指定がある時**：自分の呼び方は1つに決める（「わたし」が基本。「ぼく」「おれ」は、物の性格が資料・指定にある時だけ）。口ぶりは、です・ます。自分の事を「かわいそう」に言わない。**「買ってください」「使ってください」と、物に言わせない**（締めは、語りに替わる）。話し手の一覧に、`◯◯（人でない物。自分の呼び方・口ぶり・声の感じ）` と書く。
6. **体の部分（ウ）を視点の主にする時**：部分の名前は、相手が自分で言う呼び方で。体の中の出来事は、広く知られている事と、資料にある事だけ。
7. 視点の主を、相手の子・家族・生き物（イ）にする時：その者の年・力で、分かる事だけを言わせる。**その者を、ばかにしない・あわれまない。相手（買う人）を、悪者として終わらせない**（⑨の最後は、相手の顔）。

## 5. 映像の側が、台本に求める物
台本の出力（`templates/出力の形.md`）の、**本文の前**に、次を足す。
```
視点の主：<だれ・何>（種類 ア〜オ）｜形：A 起こす側の目／B 道具の目｜目の高さ：<床から、どのくらい。ひざ・こし・床の上 の類>｜いつも画面に写る自分の体：<おなか・手・足・ふち の類。色を1つ>
話し手：語り（声の感じ）／<相手の呼び名>（だれか・年ごろ・口ぶり）／<視点の主>（人の時だけ）
人物・物の一覧：役｜視点の主から見た呼び名｜見た目（年ごろ・色1つ・身に着ける物1つ）
場面の一覧：#｜中／外｜場所｜視点の主の目に、今、見える物（1つ）｜画面に写る自分の体｜相手の顔（やさしい・こわい・困った・無し）
```
