# F　疑う役との掛け合い（寸劇）

- 一言で：2人の芝居で運ぶ。1人は相手と同じ立場で疑い、もう1人が答える。疑う役の「でも◯◯でしょ」が、そのまま線の段になる。
- 勝っている証拠：同じ運びの広告 6本・6ブランド。最長の配信 414日（300日を超える物が4本、残り2本も200日超）。6本とも文字起こしの秒を測った。弱い所：段（Winning／Optimized）が分かっているのは1本だけ（212日の Winning）。used は6本とも1。映像は6本とも最初の静止画1枚しか見られなかった。6本のうち2本は、疑いが2つしか無い・前の4割が1人の語り、と形がずれている（下の「秒の割り振り」に分けて書いた）。
- 始まり（線のどの端から入るか）：線の中ほど（相手が今している対策・今の考え）の場面から入る。疑う役が、今の対策をしている所を見られるか、自分から「◯◯は要らない。△△で足りる」と言う。見てくれる人の所へ来て、困り事を言う入り方もある。
- 進み方（何の時計・何の区切りで進むか）：問いと答えの往復が区切り。時計は無い。4〜7往復（測った幅は2〜7）。順は「相手が思う順」：①今の対策をやめさせる（または、今の対策では足りない訳）②商品の名前か種類 →「流行り物でしょ」「ほかと何が違うの」③仕組みを1つ ④「高いあれと同じ？」「値段は？」⑤使いごこち・手間などの小さな疑い ⑥疑う役が折れる ⑦「どこで買うの」。
- 語り手（だれの目・だれの声か）：2人の声。目は、疑う役（＝相手）。答える役は、友だち・家族・見てくれる人・売る側の人。疑う役を「今使っている古い対策そのもの」にし、答える役を商品にした物もある（1本）。
- 各区切りで言う事：疑う役は、相手が実際に思う言い返しを、短い話し言葉で1つだけ。答える役は、1問に1つだけ答える。知らない言葉が出たら、疑う役が「何それ」と止め、答える役が言い直す。答えのすぐ後に、疑う役の短い受け（「へえ」「なるほど」）を置いてから、次の「でも」へ行く。
- 1区切りの中の文の並び：疑う役の言い返し（1文。「でも」「待って」で始まる）→ 答える役の打ち消しか受け止め（1語〜1文）→ 訳（1〜3文）→ 疑う役の短い受け（無い時もある）。答えが3文を超えるのは、仕組みを言う往復の1回だけ。
- つなぎの作り：疑う役の「でも」「待って」「じゃあ」。前の答えの中の言葉を、疑う役がひろって次の問いにする（答えに出た物の名前 →「それって◯◯と同じ？」）。場面は変えない。物を手渡す・その場で試す、で1回だけ絵を動かす。
- 商品が要る1点の置き場所：全体の30〜60%（3〜4往復目）。疑う役の「それで、どうして◯◯になるの」「ほかと何が違うの」への答えが、要る1点。ここだけ答えが長い。その後の往復は、買う前の小さな引っかかりを消す段。
- 締めの作り：疑う役が折れる1文（86〜93%）→「どこで買うの」→ 答える役が、おまけ・値段・リンクを1〜2文（90〜95%）。売り手の声は出ない。別の締め（1本・212秒）：74%で疑う役が折れる → 2人が素に戻り「寸劇でした。来るコメントに、こういう動画で答えている」と明かす → オファー → **なぜこの値引きができるのか**（売る側の都合の訳）→ 礼 → 決め台詞。
- 長さの目安：測った6本は 69〜212秒。5本は 69〜98秒（平均83秒）。1本だけ212秒（素に戻る締めを持つ物）。
- 要る材料（商品の資料に何が無いと使えないか）：相手が実際に言う言い返し（声にある物。4つ以上）と、1つずつの短い答え。相手が今している対策の名前。会話が起きて不自然でない間がらと場面。値引きの訳を言う締めを使う時は、その訳が本当である事。
- 合わない商品・相手：言い返しが1〜2つしか無い物（会話が続かず、残りがほめ合いになる。測った1本がそうだった）。答えに長い説明が要る仕組み（会話が講義になる）。人に話しにくい悩み（友だちどうしの場面がうそになる。見てくれる人との場面なら可）。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：線の段を、語り手が並べない。相手の言い返しを先に声に出し、その答えとして段が出る。段の順は「相手が思う順」になるので、問題と原因の説明は短く（多くは1往復）、買う前の引っかかりの段が長くなる（全体の後ろ半分）。

# フックの分解

- 1文目：場面の中の強い一言。4とおりあった。①答える役が、相手の今の行いを見とがめる問い ②疑う役が「◯◯は要らない。△△で足りる」と言い切る ③見てくれる人が「今日はどうしました」と聞く ④古い対策の役が「みんな私を頼るのに、まだ◯◯のまま」と自分の負けを言う。
- 2文目：1文目への、1語〜1文の返し。今の対策の名前を言う／その手が届かない場面を問い返す／困り事を、起きる時つきで言う／負けの訳を1文で言う。
- 3文目：「なぜ」か「でも」。ここで往復が回り始める。相手を名指す文・数・商品の良さは、3文目までに出ない（1本だけ、1文目に商品の名前が出る）。
- 何で「え、どういうこと？」を作っているか：広告の形をしていない事。人の会話の途中に入ったように聞こえ、「何をとがめられたのか」「どう言い返すのか」が気になる。隙間は、知らない事実ではなく、会話の行き先で開けている。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：ほとんど見せていない。近い物が3つだけ。①疑う役が「もっと強い手に手を出しそう」と言う（11%）②1文目で、人に見られたくない所を見られる ③2文目で、今の手が届かない場面を問い返す。「1文目の後すぐにデスが目に浮かぶ」（台本の決まり1章の5）は、このフォーマットをそのまま写すと満たせない。満たすには、疑う役の2つ目の台詞を「今の手でだめだった時に起きる事」にする。

# 書く時の手順

1. 設計メモの線の段を、1つずつ「相手が言う言い返し」に言いかえる。声・レビューに同じ言い返しがある段だけを残す。4つに足りなければ、このフォーマットを使わない。
2. 答える役を決める（友だち／見てくれる人／売る側／商品そのもの）。これで、商品の名前の置き場所が決まる（早い・中ほど・最後）。
3. 2人の間がらと場面を1つ決める。相手の型の「困る時」に、その2人が居合わせて不自然でない場面にする。
4. 往復を「相手が思う順」に並べ、商品が要る1点の答えを、30〜60%の所に置く。その往復だけ、答えを3〜5文にする。ほかは1〜2文。
5. 線にあるのに言い返しにならなかった段（多くは「放っておけば戻るのでは」と入口の事実）を、疑う役の台詞として足すか、記事に回すかを決める。
6. フックの3文を書く。1文目は場面の一言、2文目は返し、3文目は「なぜ」か「でも」。2つ目の疑う役の台詞に、デスが目に浮かぶ場面を入れる。
7. 締めを決める：疑う役が折れて「どこで」と聞く形か、素に戻って値引きの訳を言う形か。後ろの形は、訳が本当に言える時だけ。
8. 通して読み、問いのすぐ次の文が、その問いの答えになっているかを、往復ごとに確かめる。

# はまる落とし穴

- 疑う役の言い返しを、書き手が作ってしまう。相手が思っていない疑いに答えると、1往復目で「私の事ではない」と気づかれる。確かめ方：どの言い返しにも、声・レビューの出どころを1つずつ付ける。付かない物は消す。
- 問いと答えがずれる。問いに「◯◯の時は平気なのに」が入っているのに、答えが商品の良さになる。確かめ方：問いと、そのすぐ次の1文だけを抜き出して並べ、答えになっているかを見る。
- 疑う役が、訳も無く折れる。小さな疑いをいくつ消しても、商品が要る1点の答えが弱いと、折れる所がうそになる。確かめ方：折れる文の前の往復を小さな疑いから順に消していき、仕組みの答えだけ残しても、折れる文が成り立つかを見る。
- 答える役の答えどうしが、ぶつかる。往復ごとに別の良さを言うので、「すぐ変わる」と「続けて変わる」のように、逆の事を言いやすい。確かめ方：答えを全部「いつ・どこで・何が・どうなる」の表に並べる（台本の決まり2-6）。
- 後ろ半分が、商品の良さの数え上げになる。線に無い強みを、小さな疑いの答えとして入れてしまう。確かめ方：小さな疑いの往復ごとに、設計メモの「商品が要る1点から出た条件」のどれに当たるかを書く。当たらない往復は記事へ。
- 素に戻る締めを、訳が無いのにまねる。値引きの訳がうそだと、寸劇の全部が疑われる。確かめ方：値引きの訳を、売る側の数字で言えるかを、資料で確かめる。
