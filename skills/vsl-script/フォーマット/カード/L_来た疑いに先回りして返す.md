# フックの分解

- 1文目：「疑いが来た」と自分から言う。4とおりあった。①この前の投稿にコメントが来たので、説明する ②（商品の名前）に一番多い苦情と、それが違う訳 ③試す前に、私が最初に聞いたのは◯◯だった ④近所の人に「だまされたよ」と言った。どれも、隙間を「売る側が、悪い言葉を自分で出した」事で開ける。
- 2文目：疑いの中身を言うか、相手の今を言い当てる。「たぶん、◯◯だと思ったのだろう」／苦情を、来た言葉のまま読む／「困り事は、もう知っていた」／「◯◯で買った物で、店には無い」。
- 3文目：打ち返しの合図か、疑いをもう1段強める文。「でも、うちのは△△」／「本当の所は」／「効く仕組みも、もう知っていた」（→止めていたのは1つだけ、へ進む）／「本物の訳が無いと思った」。
- 何で「え、どういうこと？」を作っているか：悪いコメント・「うそだと思った」という言葉を、売る側が自分で読む事。かくさない所で止まる。相手が自分でも思っていた疑いなら、「それ、私も思った」で続きを見る。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：見せていない（5本とも）。相手はもう困り事を知っている、という前提で進む。にせ物の所で「悪くなる事がある」と言う物が1本あるだけ（47〜54%）。「1文目の後すぐにデス」（台本の決まり1章の5）を満たすには、1つ目の疑いを「変わらなかった」という苦情にし、その答えの1文目に、やめた時に戻る場面を入れる。

# 線の段との対応

| 線の物 | どの区切りに入っているか |
|---|---|
| ①相手の型 | フックの2〜3文目（「困り事も、効く仕組みも、もう知っていた。止めていたのは1つ」）。型は「商品を知っていて、1つの疑いで止まっている人」。いつ困るか・何を試したかは言わない |
| ②入口の事実 | 疑いそのものが入口。相手が自分で気づいていて、答えを持っていない物（「◯日使ったのに変わらない」「店に無いのは、なぜ」）。体・暮らしの事実ではない |
| ③商品が要る1点：放っておけば戻るのでは、への答え | このフォーマットは言わない |
| ③商品が要る1点：今の手で足りるのでは、への答え | このフォーマットは言わない（にせ物・安い物との違いを言う物はある。1本） |
| ③商品が要る1点：なぜこの商品だとできるのか、への答え | 1つ目か2つ目の答え（14〜33%）。疑いを1つにしぼる形では、答えの段の全部（24〜72%） |
| ④商品 | 名前は0〜24%。締め（68%〜）で、値引き・返金・数 |

- このフォーマットは、問題・原因・「放っておけば戻るのでは」「今の手で足りるのでは」を言わない。相手がもう知っている、という前提。この前提が成り立たない相手（原因を知らない人）には、使わない。成り立つ相手にも、この2つは記事への疑問に回す。
- 値段・お店への疑いだけを返す形（2本）は、商品が要る1点も言わない。うちで使う時は、疑いの1つを、必ず「効き方への疑い」にして、その答えに商品が要る1点を入れる。

# 変わり種：自分に不利な数字を自分から言う（1本・139秒・402日）

- 一言で：売る側が、よその大きな数字の出どころが小さい事を明かし、自分の客の本当の内わけ（感じない人もいる）を言う。お試しと返品を、その正直さの答えとして出す。返す疑いは1つ（「自分には効かないかも」）。
- 進み方（数字の向きが区切り）：だれを信じていいか分からない、会社をやっている自分でもそうだ（0〜7%）→ よその大きな数字と、その出どころ（7〜17%）→ 自分の客に聞いた内わけ。大きく変わる人・しっかり変わる人・少しの人・感じない人の4つの組（17〜36%）→ 感じない人に「使い方が悪い」と言うのはひどい（36〜50%）→ 体の中の変化と、感じ方は別（50〜65%）→ だから長いお試し（65〜78%）→「どの組に入るかは、試すまで分からない」（81〜86%）→ 売る側として最後まで面倒を見る（86〜100%）。
- 商品の名前は口で言わない。値段も言わない。仕組みも言わない。急がせない。
- フック：1文目＝売る側が「だれを信じていいか分からない」と言う（信じていた物を、売る側が自分でゆらす）。2文目＝自分もそうだと言う。3文目＝よその数字を出す。
- 要る材料：自分の客に聞いた本当の内わけの数字（無ければ使えない）。長いお試し・返品の決まり。よその広告が使っている数字と、その出どころ。
- 合わない：内わけの数字が無い商品。お試しや返品が無い商品。感じない人の割合が大きすぎる商品。まだ商品を知らない相手。
- 映像：実写。野外の自撮りで、話し手の顔が大きく映る。字幕は無い。最初の静止画1枚だけ見た。
- 落とし穴：内わけの数字を作る事。出どころ（いつ・何人に聞いたか）が言えない数字は、使わない。

# 書く時の手順

1. 声・レビュー・コメントから、買う前の疑いと、買った後の苦情を全部ひろい、数の多い順に並べる。上から3つ、または、とび抜けて多い1つを選ぶ。出どころを1つずつ控える。
2. 形を決める。3つを順に返す形か、1つにしぼって答えを3つ並べる形か。相手を止めている物が1つだとはっきりしているなら、しぼる。
3. 疑いの1つを「効き方への疑い」にし、その答えに、設計メモの商品が要る1点を入れる。置く所は、1つ目か2つ目（全体の3割まで）。
4. 答えを、決めた文の並び（疑い → 合図 → 事実か仕組み → だからどうする）で書く。答え1つは、平均13秒・長くても22秒まで。
5. 3つ目を何にするかを決める（小さな引っかかり／にせ物／冗談の苦情）。冗談の苦情は、変わった後の暮らしが声にある時だけ。
6. フックの3文を書く。1文目で「疑いが来た」と言い、商品の名前は2割までに出す。
7. 締めを書く（全体の約3割）。値引きへの橋 → オファー → 返金か数 → リンク。橋の訳は、本当に言える物だけ。しぼる形は、最後に頭の疑いをもう1回言う。
8. 問題・原因・放っておいた先を言っていない事を確かめ、記事への疑問に回す物を決める。

# はまる落とし穴

- 疑いを作ってしまう。来ていないコメントを「来た」と言うと、1文目がうそになる。確かめ方：読む疑いの1つずつに、声・レビューの出どころを付ける。付かない物は、読まない。
- 答えやすい疑いだけを選ぶ。相手が本当に止まっている疑いを外すと、見た人の疑いは残る。確かめ方：選んだ疑いが、数の多い順の上から入っているかを見る。上にあるのに外した物には、外した訳を書く。
- 答えどうしが、ぶつかる。「すぐ楽になる」と「◯日は続けて」を、別の答えで言う。確かめ方：答えを全部「いつ・どこで・何が・どうなる」の表に並べ、すぐの物と、後からの物を分けて言えているかを見る（台本の決まり2-6）。
- 相手が、まだ商品を知らない。フックで何の話か分からず、離れる。確かめ方：設計メモの相手の型が「商品を知っていて、迷っている」になっているか。なっていなければ、このフォーマットを使わない。
- 値段・お店への疑いだけで終わる。商品が要る1点を、どこでも言っていない。確かめ方：台本の中で、商品が要る1点の文に印を付ける。印が付かなければ、疑いを入れかえる。
- 値引きへの橋がうそ。「コメントをもらって、もっと安くした」が本当でないと、前の答えも疑われる。確かめ方：橋の訳が、資料にあるかを見る。無ければ、橋を使わず、返金と数だけで締める。
