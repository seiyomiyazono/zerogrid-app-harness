# K　しるしを数えて一つの原因に戻す

- 一言で：相手が毎日見ているのに、別々の事だと思っている小さなしるしを番号で数え、全部を1つの原因に戻してから、商品へ向きを変える。
- 勝っている証拠：同じ運びの広告 3本・3ブランド。最長の配信 1,602日（Optimized）。ほかは 271日・240日。運営者が送った見本は無い。3本は長さが 35秒・121秒・226秒と大きく違い、数えた後の進み方も3つとも別（すぐ商品へ／成分と週ごとの段へ／一人称の告白へ）。そろっているのは「頭で数を言う → 番号で数える → 1つの原因 → 商品の種類は 62〜68%」の骨組みだけ。
- 始まり（線のどの端から入るか）：線の入口（相手が気づいている事実）から入る。ただし1つではなく、3〜5つ並べる。1文目で、数と、原因の名前を先に言ってしまう（3本とも）。
- 進み方（何の時計・何の区切りで進むか）：しるしの番号が区切り。数え方は2通り。上から数える（1→3、1→5）と、逆に数える（3→1。最後のしるしが一番強くなる）。数え終わった所で、向きを変える1文を置き、後ろは商品へ進む。
- 語り手（だれの目・だれの声か）：詳しい第三者の声（顔は出ない）。1本は、知らせ（ニュース）ふうの見出しで入り、数え終わった所で、一人称の当事者の声に切りかわる。1本は終わりで「私が試した中で」と、語り手が自分を1回だけ出す。
- 各区切りで言う事：しるしごとに、相手の暮らしの場面を1つ → みんなが思っている訳 → 本当の訳（毎回、同じ原因の名前に戻る）。短い版（35秒）は、しるしを1行ずつ名前だけ言い、3つ言い終えてから「全部、◯◯という事」と、まとめて1回で戻す。
- 1区切りの中の文の並び：番号 → 場面（相手がしている事・見ている事）→「それは◯◯ではなく」（思いこみを切る）→「◯◯だから」（原因の名前）→（長い版だけ）原因からしるしまでの道すじを1〜2文。
- つなぎの作り：番号を声で言うだけ。どのしるしも、訳の中に同じ原因の名前が出るので、聞き手は3回同じ所に戻される。逆に数える版は、最後のしるしを「あの手を試したのに、何も起きなかった」にして、今の手を切る段を兼ね、そのまま「腹が立つのは、直すのに◯◯しか要らない事」と向きを変える。

- 締めの作り：3つとも別。①商品の名前 →「試した中で一番」→ ただのお試し（短い版）。②成分 → 働き → 週ごとの段（カード B の短い版）→「原因に体を任せるな」→ 商品の名前 → 押す所。③一人称の変化 → 伝えたい訳 →「この人の短い動画を見て」→ やり方の名前（商品は売らず、続きの動画へ渡す）。値段をはっきり言う広告は無い（1本が「1日あたり◯◯より安い」、1本が「ただのお試し」）。

- 要る材料（商品の資料に何が無いと使えないか）：相手が別々だと思っている目に見えるしるしが3つ以上（声にある物）。その全部を、同じ1つの原因で言い切れる事。逆に数える版なら、「試したのに効かなかった手」が、同じ原因で説明できる事。
- 合わない商品・相手：しるしが1つしか無い悩み。しるしと原因のつながりを言えない物・言ってはいけない決まりの物（体の見立てになる言い方）。相手がもう原因を知っている時（1文目で原因を言うので、新しさが無い）。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：普通は入口の事実が1つ。これは入口を3〜5つに広げ、原因の説明を「しるしの訳」として、しるしの数だけくり返す。原因の名前は、後ろで明かさず、1文目で言ってしまう。相手は「自分に当てはまるか」を1つずつ確かめながら見る。「物」を数えて消し、1つ残す運びとは別（こちらは「しるし」を数えて、1つに集める）。

# フックの分解

- 1文目：3本とも「数を言う」＋「原因の名前を言う」。2本は「◯◯が△△になっている、◯つのしるし」という見出しの形。1本は「新しい調べで分かった、専門の人が見つけ方を教わっていない◯つのしるし」と、知らせの形にして、信じていた物（専門の人）を否定する。
- 2文目：2本は、もう「しるし◯番」に入っている（フックは1文）。知らせの1本は「あなたの◯◯が、この◯つのどれかをしていたら、△△の中にいる」と、相手を名指して、こわい事を言う。
- 3文目：知らせの1本だけ。「直し方は、こう」と約束する（その後に2文「専門の人は大きなしるしを見るが、一番傷つけているのは静かな方」と否定を重ねて、しるしへ）。
- 何で「え、どういうこと？」を作っているか：数。相手は「自分はいくつ当てはまるか」を確かめるために、最後のしるしまで見る。逆に数える版は「1番は何か」が残る。原因の名前を先に言うので、「なぜ、それがその原因のしるしなのか」も隙間になる。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：2本は見せていない（しるしの場面が、毎日のいやな事として並ぶだけ）。告白へつなぐ1本は、声では、数え終わった直後（38〜46%）に最悪の場面を一人称で見せる。絵では、最初の1枚がもう「荒れた部屋」で、デスを絵で先に置いている。うちの決まり（1文目のすぐ後にデス）で書くなら、数の1文の次に1文足す。

# 書く時の手順

1. 設計メモの相手の型から、相手が自分で気づいている事を3〜5つ拾う（声にある物だけ。件数の多い順）。入口の事実は、その中の1つにする。
2. しるしの1つずつに「これは、線の原因で本当に起きるか」を当てる。相手の言い返し（「それは別の訳でもなるけど？」）が成り立つしるしは外す。3つ残らなければ、このフォーマットをやめる。
3. 並び順を決める。逆に数えるなら、最後（1番）を「試した手が効かなかった事」にして、今の手を切る段を兼ねる。上から数えるなら、一番多くの人に当てはまる物を1番にする。
4. 長さを決める：しるしを1行ずつ（約35秒・訳は後ろでまとめて1回）か、しるしごとに訳を付ける（1つ 11〜24秒）か。
5. フック：1文目で、数と原因の名前を言う。デスを入れるなら2文目。3文目までに、しるしの1つ目に入る。
6. 数え終わり（全体の 27〜57%）に、向きを変える1文を置く。そのすぐ後に、設計メモの問いでまだ答えていない物（放っておけば・今の手で・なぜこの商品）を、1文ずつ置く。
7. 商品の種類を 62〜68% に、名前を 80% より後ろに置く。締めは 91% から。着地が記事の時は、うちの締めの決まり（6章）に置きかえる。
8. しるしの訳に出る原因の言葉が、全部同じ言葉か、商品の所でも同じ言葉かを、通して読む。

# はまる落とし穴

- 1つでも当てはまらないしるしがある：原因と関係のうすいしるしを、数を合わせるために足す。→ しるしごとに、原因からしるしまでの道すじを1文で書く。書けない物は外す（数を減らす）。
- しるしごとに、訳が別の話になる：3つのしるしに3つの別の仕組みを言い、原因が1つに聞こえない。→ どの訳にも同じ原因の名前が入っているか、名前に印を付けて数える。
- 「試したのに効かなかった」の訳が、物によって当てはまらない：いくつかの手をまとめて「同じ原因のせいで効かなかった」と言う。→ 手の1つずつに、その訳が当てはまるかを見る。当てはまらない手は名前を出さない。
- 体の見立てに聞こえる：「これがあれば、あなたは◯◯だ」と言い切る。→ 言い切りの文を抜き出し、資料と決まりで言える形かを確かめる。
- 数えが長すぎて、商品が要る1点が抜ける：しるしの場面を厚くして、後ろが名前とオファーだけになる。→ 設計メモの問いに、どの文で答えたか印を付ける。印の無い問いがあれば、しるしの訳を1文けずって入れる。
- 向きを変えた後が、別の線になる：数えの原因と、商品の働きの言葉がつながらない。→ 商品の文の中に、しるしの訳で使った原因の言葉がそのまま出ているかを見る。
