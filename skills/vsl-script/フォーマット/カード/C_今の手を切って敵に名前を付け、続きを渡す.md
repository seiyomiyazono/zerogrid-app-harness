# C　今の手を切って敵に名前を付け、続きを渡す

- 一言で：相手が今している対策を頭で切り、「それは結果で、原因は別にある」と言い直し、売り物は出さずに、答えの続きを別の物（短い動画・無料の資料）へ渡す。
- 勝っている証拠：**弱い。** 同じ運びの広告 2本・2ブランド。最長の配信 408日（Optimized・used 2）。ただし、この408日の1本は芯だけが同じで、見本にある部品（3つに分けて切る所・名前の付いた敵・放っておいた先）を持たない。見本（運営者が送った1本）は配信34日で止まっている（used 1）。**見本とぴったり同じ運びは、ほかに1本も見つからなかった。** 裏どりの検索（言葉「root cause」・8行）でも、同じ物は0本。つまり「芯（切る→言い直す→商品を出さず渡す）」は長く回っている1本があるが、「見本の全部の部品を積んだ形」が勝つかは、まだ確かめられていない。
- 始まり（線のどの端から入るか）：線の入口（相手が気づいている事実）から入る。すぐ、線の「今の手で足りるのでは」に進む。原因の説明より先に、今の手を切る。
- 進み方（何の時計・何の区切りで進むか）：時計は無い。区切りは「問いの置きかえ」。芯は3つ：①今の手を切る ②「それは結果。原因は別（見落とされている）」と言い直す ③商品を出さず、続きを別の物へ渡す。足せる部品（見本だけにある）は、②と③の間に入る：問いを声に出して置きかえる／敵に名前を付ける／放っておいた先／今の手が敵に届かない訳／見つかった物を半分だけ言う。
- 語り手（だれの目・だれの声か）：2つの形があった。名指さない第三者の声が相手に語り、調べた人たちを「彼ら」として引く形（見本）。詳しい人が顔を出して「私たちは」と語る形（もう1本）。どちらも、相手を「あなた」と呼ぶ。
- 各区切りで言う事：
  - 芯①切る：今の手の名前と、「それでは終わらない」。
  - 芯②言い直す：みんなが狙っている物は結果だ、という1文。または「あなたが悪いのではない。見落とされている物がある」。
  - 芯③渡す：飛び先で分かる事／手間が無い事（または、だれのための物か）／今押す訳。
  - 足せる部品：3つに分けて切る（今の手を1つずつ名前で言い、1語で否定）／問いの置きかえ（「聞くべきは◯◯ではなく◯◯」）／名前の付いた敵（いつから・何をするか。以後ずっとその名前で呼ぶ）／放っておいた先（できなくなる事を、小さい物から大きい物へ）／今の手が敵に届かない訳／見つかった物（種類の名前を半分だけ。何をするかは言う）。
- 1区切りの中の文の並び：切る所＝今の手の名前 → 短い否定。言い直す所＝みんながしている事 → それは結果 → だから終わらない。敵の所＝だれが見つけたか → 敵が何をするか → 無い時はどうか → いつから始まるか → 名前。放っておいた先＝こわい1文の前ぶれ → 小さい「できない」を3〜4つ → 「やめる」を3つ → 行き着く先 → 敵の名前で閉じる。
- つなぎの作り：「でも、それは◯◯にすぎない」「聞くべき問いは、こっち」「こわいのは、ここから」「その間も、◯◯は続く」「ところが、すべてが変わった」。前の区切りの答えを否定するか、問いに置きかえて、次へ進む。
- 商品が要る1点の置き場所：芯②（言い直し）と、足せる部品の「今の手が敵に届かない訳」。「原因が残っている限り、今の手は続けても足りない」を、ここで言い切る。商品そのものは出さない。「なぜこの商品だとできるか」は、半分だけ言って飛び先に残す。
- 締めの作り：オファーも値段も言わない。飛び先で分かる事 → 手間が無い事（登録が要らない等）または、だれのための物か → 待つと進む事 → （敵の名前をもう1回） → 相手の暮らしの場面を3つ「もう◯◯しなくていい」または「軽く言っているのではない」という念押し → 押す。全体の最後の2割強を使う。
- 長さの目安：74秒（芯だけの形）〜202秒（部品を全部積んだ形）。
- 要る材料（商品の資料に何が無いと使えないか）：相手が今している対策の名前（3つに切るなら3つ以上）と、どれも同じ訳で届かないと言える事／原因に付けられる名前（敵を立てるなら）／放っておいた先の段々（声か調査にある物）／**続きを渡す先**（短い動画・記事・資料）。これが無いと芯③が作れない。
- 合わない商品・相手：原因がもう知られている物（言い直しが新しくない）。対策ごとに届かない訳が違う物（まとめて切ると言い返される）。飛び先が商品ページだけの時。こわがらせる事を言えない決まりの商品（放っておいた先は外し、芯だけで作る）。もう商品を比べている相手（商品が出ないので、答えにならない）。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：対策を切る段が一番前に来る。商品の段が無い（④を言わない）。答えの半分を飛び先に残して終わる。部品を積んだ形では、原因を「名前の付いた敵」にして、その後ずっとその名前で呼ぶ。

# フックの分解

- 1文目：相手を名指し（年代や、起きている事）、相手が気づいている事実に「訳がある」と言う（隙間を開ける）。もう1本は、同じ1文の中で「◯◯のせいと言われてきた」「今の手では片付かなかった」まで言う（信じていた物を否定する）。
- 2文目：望みを足す（「しかも、戻せる」）。または「あなたが壊れているのではない」と、相手のせいでない事を言う。
- 3文目：相手の問いを声に出す（「一番いい手は何か」）。すぐ続けて、今の手を名前で言い、短く否定する。もう1本は「見落とされている物がある」と隙間を開ける。
- 何で「え、どういうこと？」を作っているか：「訳がある」と言って訳を言わない事。続けて、相手が頼っている物が次々に否定される事。2つの隙間（訳は何か・では何が効くのか）が同時に開く。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：フックでは見せていない。見本は45〜63%にまとめて置き、「できない事」を小さい物から大きい物へ並べて、行き着く先を1つ言う。もう1本は、どこにも見せていない。

# 書く時の手順

1. 飛び先を先に決める。続きを渡す先（動画・記事・資料）が無ければ、このフォーマットを使わない。
2. 設計メモの「今の手で足りるのでは」への答えを取り出し、切る物を決める。3つに分けて切るなら、3つとも同じ訳で届かないかを、1つずつ確かめる（2-6）。1つでも違えば、まとめて1文で切る形にする。
3. 言い直しの1文を決める（みんなが狙っている物は結果で、原因は別）。相手の体験で確かめられる言い方にする。
4. 部品を積むかを決める。資料に、原因の名前・放っておいた先の段々があれば積む。無ければ、芯だけ（60〜80秒）で作る。作らない。
5. 敵を立てるなら、名前を1つに決め、初めて言う所（全体の4割あたり）より後は、ずっとその名前で呼ぶ。
6. 「見つかった物」で、どこまで言うかを決める。商品の名前は言わない。敵に何をするかは言う。残りは飛び先。
7. 締めを書く。飛び先で分かる事 → 手間が無い事 → 待つと進む事 → 暮らしの場面。値段とオファーは書かない。全体の2割強を当てる。
8. 秒を当てる。切るのは頭の1割まで。渡し始めは74〜80%。

# はまる落とし穴

- まとめて切った訳が、1つの対策に当てはまらない。確かめ：切る物を1つずつ書き、「これは原因に届かない」が本当かを、資料の言葉で1つずつ言えるか。
- 敵の名前が、こわがらせるだけの作り物になる。確かめ：その名前が資料（調査・作り手の説明）にあるか。無ければ、名前を付けず「見落とされている物」と言う芯の形に下げる。
- 放っておいた先を、声に無い所まで広げる。確かめ：並べた「できない事」の1つずつが、相手の声か調査にあるか。行き着く先は、その型の人に本当に起きているか。
- 渡した先が、続きになっていない。確かめ：飛び先の最初の画面が、動画の最後の言葉（敵の名前・見つかった物の呼び方）から始まっているか。商品ページに直に飛ばしていないか。
- 「見つかった物」で言いすぎて、飛び先を見る訳が無くなる。または言わなすぎて、うそっぽくなる。確かめ：「何をするか」は言い、「何であるか・どう使うか」は残しているか。
- 見本の形（部品を全部積む）を、勝ちの形だと思いこむ。確かめ：見本は34日で止まっている。長く回っているのは芯だけの1本。初めは芯だけの短い形と、部品を積んだ形の両方を出して比べる。
