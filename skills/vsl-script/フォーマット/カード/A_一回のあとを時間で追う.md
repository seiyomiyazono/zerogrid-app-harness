# A　一回のあとを時間で追う

- 一言で：商品を1回使った瞬間から、分・時間・日と時計を進めて、ふだん見えない内側で起きる事を順に見せる。後ろで「では毎日続けたら」と折り返し、日数の短い段で外に見える変化を足す。
- 勝っている証拠：同じ運びの広告 2本・2ブランド。最長の配信 449日。1本は運営者が送った見本（配信15日・Winning・used 5。日が浅い）。もう1本（449日・Winning）は、前半が時間で内側を追い、後半は日数で外を追う「A と B の合いの子」で、1回ぶんだけを分・時間で追い切る形は見本の1本だけ。裏どりの検索（8行）でも、まじり気のない A は 0本だった。この運びが長く勝った証拠は、まだ弱い。
- 始まり（線のどの端から入るか）：線の終わり側（商品を使う所）から入る。1文目で、相手の型を一言で名指し、商品の種類を言い、「使うと何が起きるか」を問う。問題や原因の説明は前に置かず、時間の段の中に溶かす。
- 進み方（何の時計・何の区切りで進むか）：時計が区切り。見本は「分→時間→半日→1日→2日→3日」の6段で1回ぶんを追い、折り返しの2文をはさんで、日数の段を4つ。もう1本は「最初の1日→数日→1週間」の3段が内側、「2週間→3週間→◯日」の3段が外。どちらも、時計は後ろへ行くほど目が粗くなる。
- 語り手（だれの目・だれの声か）：名指さない第三者の声。1文目だけ「ある人」を三人称で置き、区切りに入ったらすぐ「あなたの◯◯の中」に切りかえる（見本）。もう1本は、売り手側の人が顔を出して「あなたの◯◯（世話をしている相手）」に語り、原因を抑える所だけ「私たち」と言う。目は、ふだん見えない内側。
- 各区切りで言う事：内側の段＝その時刻に、商品のどの部分が、どこに届くか／そこで何が変わるか／相手が毎日見ているしるしのどれが、そのせいだったか。外の段＝日数と、目に見える変化を1つ。最後の外の段だけ「今までの手のおかげではなく、◯◯が楽になったから」と、訳を言い直す（見本）。
- 1区切りの中の文の並び：時刻 → 商品のどの部分が、どこに届くか → そこで何が変わるか → （段によって）今までの物との違い、または、相手が毎日見ているしるし。内側の段は2〜4文。外の段は「日数 → 変化」の1文。
- つなぎの作り：文の頭に時刻の言葉を置くだけ。前の段で動いた物が、次の段の主語か場所になる（届く → 入る → 出ていく → 直り始める → 外に出なくなる）。だから、時刻を消しても順がつながる。内側から外への切りかえは、見本は「これが1回ぶん。毎日なら？」の2文、もう1本は合図なしで「外に見える変化」に移る。
- 商品が要る1点の置き場所：最初の内側の段（全体の10〜13%）で「この作りだから届く。今までの形の物は届かなかった」を、時刻の訳として言う。もう1本は2つ目の段（35%付近）で「ほかの普通の物にはできない」。見本は、外の段の最後（73%）と締めの作りの説明（87〜90%）で、同じ事をあと2回言う。
- 締めの作り：使い方を1文（商品の名前がここで初めて出る）→ 作りの確かさ（出どころ・濃さ・届く作り・調べ）→ オファーと返金 → 数が少ない事。もう1本は、名前と形 → 返金の約束（くり返す）→ 押す所。値段は言わない。
- 長さの目安：84〜144秒（測った2本）。内側の段が6つなら約145秒、3つなら約85秒。
- 要る材料（商品の資料に何が無いと使えないか）：使ってから変化までの時間の順（何が・いつ・どこに届くか）。段ごとに、相手が自分で確かめられるしるし。今までの物が届かない訳を「作りの違い」で言える事。日数ごとの外の変化（後ろの段）。
- 合わない商品・相手：使ってすぐ変化が目に見える物（追う時間が無い）。時間の順を資料で言えない物（段を作り話で埋める事になる）。内側で何も動かない物・好みで選ぶ物。仕組みに関心の無い、もう買う気の相手。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：普通は問題から始めて商品で終わる。これは商品を使う所から始め、原因と「届かない訳」を、時間の段の訳として後から出す。商品の種類は 0% で言い、商品の名前は 77% まで言わない。相手は「原因の説明」を聞いている気がしないまま、線をたどる。

# フックの分解

- 1文目：相手の型を三人称で名指し、商品の種類を言い、「使うと何が起きるか」と問う（見本は「もし◯◯な人が、うっかり◯◯を1つ使ったら」の仮の問い。もう1本は「◯◯な△△が、◯◯を◯日使うとこうなる」）。隙間を開ける文。
- 2文目：見本＝答えの形で「内側のどこが、これから何時間それを感じ続けるか」を言う（時計の長さを先に見せる。結果は言わない）。もう1本＝「信じられないほど効く」と、悩みの名前つきで約束する。
- 3文目：見本＝もう最初の区切り（フックは2文で終わり）。もう1本＝「順に見ていこう」と、区切りに入る合図。
- 何で「え、どういうこと？」を作っているか：結果ではなく「途中」を問いにしている。相手は、使った後の内側を見た事が無いので、時刻ごとの続きを見たくなる。見本は「うっかり」と「感じ続ける」で、良い事か悪い事かを伏せている。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：フックでは見せていない（2本とも）。見本は、内側の段の中で「何年も、ここが◯◯され続けてきた」と、内側の傷みとして少しずつ見せ、1日・2日の段で相手が毎日見ているしるしに結ぶ。もう1本は、1段目で「かくれた原因」と言うだけ。うちの決まり（1文目のすぐ後にデス）で書くなら、2文目に足す事になる。

# 書く時の手順

1. 設計メモの「なぜこの商品だとできるのか」の答えを、時間の順に割る（何が・いつ・どこに届き・何が変わるか）。資料に時刻が無い段は作らない。内側の段が3つに届かなければ、このフォーマットをやめる。
2. 段ごとに、相手が自分で確かめられるしるしを1つ当てる。当たらない段は、変わる事だけを言う。入口の事実は、どれか1つの段のしるしとして置く（前に出さない）。
3. 「今の手で足りるのでは」への答えを、最初か2つ目の段の「訳」として1文で置く（全体の10〜35%）。
4. 1回ぶんだけで押すか（内側6段・約145秒）、内側3段＋外3段にするか（約85秒）を決める。外の段は、日数ごとの変化が資料にある時だけ足す。
5. フックを決める：1文目＝相手の型の名指し＋商品の種類＋問い。2文目＝内側のどこが、どれだけの時間それを感じるか。デスを入れるなら、ここ。
6. 折り返し（内側から外へ）を、全体の半分〜60%に置く。合図の文を入れるなら2文まで。
7. 商品の名前は、外の段が終わってから（全体の75%より後ろ）。締めは「使い方 → 作りの確かさ → オファー」の順。着地が記事の時は、うちの締めの決まり（6章）に置きかえる。
8. 時刻を全部消して読み、前の段で動いた物が次の段につながっているかを見る。

# はまる落とし穴

- 時刻の作り話：資料に無い時刻で段を埋めてしまう。→ 段ごとに、資料のどの行から取ったかを横に書く。書けない段は消す。
- 内側と外で、言う事がぶつかる：内側の段で「◯日目に◯◯が直り始める」と言い、外の段で別の日数に同じ変化を置く。→ いつ・どこで・何が、を1枚の表に並べて見る。
- しるしと訳のつながりが、相手に言い返される：「それは、◯◯のせいでもなるけど？」と言える段。→ 段ごとに言い返しを1つ書き、成り立つ段は、しるしを言わず変化だけにする。
- 入口の事実が後ろに埋まる：相手が自分の話だと思う所が、全体の30%より後ろになる。→ フックの1文目の名指しが、設計メモの型と同じ言葉かを確かめる。弱ければ、2文目に相手の場面を足す。
- 「放っておけば戻る」が抜ける：内側の段は「使ったら」の話だけで、使わない時の事を言わない。→ 設計メモの問いを、どの段の何文目で答えたかに印を付ける。印が無ければ1文足すか、記事に回す。
- 商品の種類を 0% で言うので、もう知っている相手は1文目で離れる：→ 相手の段階が「その種類をもう試した」なら、1文目に「今までの物との違い」を入れるか、別のフォーマットにする。
