# B　何日かを段で追う

- 一言で：「これを◯日使うと、こうなる」と先に言い、数日・1週間・2週間・◯日の段で、変化とその訳を組にして追う。追う相手は「相手とそっくりな1人」（三人称）か、「あなた」（二人称）の2つの形がある。
- 勝っている証拠：同じ運びの広告 5本・5ブランド。最長の配信 531日。運営者が送った見本（102日・used 2）は「ある1人」を三人称で追う形で、この形は1本だけ。裏どりで見つかった3本（531日・449日・432日。どれも Winning）は「あなた」に語る形。もう1本（245日）は、商品の成分が一人称で「あなた」に語る。日数の段そのものは、5つの別の悩みで長く回っている。「ある1人」の形だけの長い証拠は、まだ無い。
- 始まり（線のどの端から入るか）：線の終わり側（使った後）から入る。フックの中で、商品の種類と日数を言う（5本とも、種類は全体の 0〜11% で出る）。問題や原因は前で説明せず、段の「訳」に割って入れる。1本だけ、段の前に「原因 → 今までの手が外れている訳」を全体の3分の1ぶん置く形がある。
- 進み方（何の時計・何の区切りで進むか）：日数が区切り。基本は4段（数日／1回目 → 1週間／10日 → 2週間／3週間 → ◯日）。6段に割った広告が1本。段の境目は、4段の4本でほぼ同じ所に来る（2段目 40%・3段目 58%・4段目 76%）。
- 語り手（だれの目・だれの声か）：2つの形。
  - 「ある1人」の形（見本）：そばで見ている第三者の声。主役は三人称の1人で、相手本人ではなく「相手が世話をしている人」。1文目で、その人を1つのしぐさで言い当てる。話は「もし◯日過ごしたら、こうなるだろう」という仮の話。
  - 「あなた」の形（4本）：声が「あなた」または「あなたの◯◯（世話をしている相手）」に、じかに約束する。声の主は、名指さない語り（2本）・売り手側の人（1本）・商品の成分そのもの（1本）。
  - 違い：「ある1人」は、しぐさの言い当てで「うちの事だ」と思わせ、最後の段を場面で厚く描ける（13秒）。結果を「この人の話」として言える。「あなた」は、段が短く速い（全体 42〜85秒）。最後の段は結果を1文で言い切り、そのまま返金の約束につなぐ。約束が直接になるぶん、言い分の確かめが厳しくなる。
- 各区切りで言う事：1段目＝最初に変わる事＋その訳（商品の作りが、原因のどこに届くか）。「今までの手はここを狙っていなかった」をここで言う広告が多い。2段目＝続く変化＋2つ目の訳（効きが続く訳・別の作り）。3段目＝毎日の目に見える事＋原因が力を失った事。4段目＝別人のような姿・人前で平気な場面（「ある1人」）、または結果の1文（「あなた」）。成分が語る1本だけ、1段目で「まだ感じない。待って」、2段目で「本当かどうか、まだ分からない。本当だ」と、疑いを先に言う。
- 1区切りの中の文の並び：「ある1人」＝日数 → 見える変化 → それは◯◯だから（商品の作り）→ 本人が気づく小さな事。「あなた」＝日数 → 変化（暮らしの場面か、気持ち）→ 内側の訳。訳の無い段は、変化を場面で2〜3つ重ねる。
- つなぎの作り：文の頭の日数だけ。前の段の訳で出した原因の言葉を、後ろの段でもう一度使い、「弱まる → 力を失う → 消える」と進める。段の合図の文（「順に見よう」）は1本だけ。
- 商品が要る1点の置き場所：1段目の訳の中（全体の11〜41%）。「今まで試した物は、どれもここを狙っていなかった」を、商品の作りの説明と同じ文で言う。2段目で、効きが続く訳を作りで足す。前置きのある1本は、段の前（22〜36%）で言い切ってから段に入る。
- 締めの作り：お試し・返金の約束が、最後の段のすぐ後（平均 88%）。その後に、大きさ・値段 →「◯◯を選んで」と選ぶ動作で終わる（見本）。「あなた」の形は、返金 → 押す所か、問いかけの1文で終わる。値段を言うのは5本のうち2本だけ（見本は 93%、成分が語る1本は 81% に「1日あたり」で）。
- 長さの目安：42〜85秒（測った5本。平均68秒）。「ある1人」の見本は75秒。「あなた」で訳を薄くした物が42〜53秒。
- 要る材料（商品の資料に何が無いと使えないか）：日数ごとの変化の順（声・レビュー・調査にある物）。段ごとの訳になる商品の作りが2つ以上。試した対策の名前。「ある1人」の形なら、相手の型を1つのしぐさ・場面で言える事（声にある物）。
- 合わない商品・相手：1回で結果が出る物・変化が日で進まない物。日数ごとの変化が資料に無い物（段を作る事になる）。作りの特徴が1つしか無い物（段ごとの訳が続かない）。結果の約束を言えない決まりの商品（「あなた」の形は特に）。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：問題と原因を前で説明しない。使った後の変化を先に見せ、原因と「今までの手が届かない訳」は、段ごとの「なぜなら」に割って入れる。商品の種類は頭で言ってしまう。カード A は分・時間で内側を追い、これは日・週で暮らしを追う。

# フックの分解

- 1文目：
  - 「ある1人」（見本）：「◯◯な子（人）に、こういう事が起きるだろう」。相手の型を1つのしぐさで言い当てる（場面に入れる＋相手を名指す）。
  - 「あなた」：3つの出方。①「◯◯を◯日使うと、こうなる」と、いきなり隙間を開ける（2本）。②「もし◯◯が、あなたの△△をだめにしているなら」と悩みで名指し、同じ文で商品と日数を言う（1本）。③「◯◯は、ただ△△なのではない。内側で◯◯を壊している」と、信じていた物を否定する（1本）。
- 2文目：見本＝日数と、今まで使っていた物との取りかえを言う（1文目と合わせて1つの長い文）。①＝驚きの約束、または、元の仕組みの説明に入る。②＝もう1段目。③＝「◯◯を毎朝◯日使うと、こうなる」。
- 3文目：5本のうち4本は、もう1段目に入っている。1本だけ「順に見よう」の合図。
- 何で「え、どういうこと？」を作っているか：「◯日でどうなるか」という、終わりの見える問い。日数があるので、相手は最後の段まで見る訳を持つ。見本は、しぐさの言い当てが先に来るので、「うちの事だ」→「で、どうなる？」の順になる。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：5本のうち4本は、フックで見せていない。1本だけ、1文目で「内側で壊れている」と言う。見本は、デスを言わず、1文目のしぐさ（今の悪い姿）と、最後の段の「人前で平気な場面」の差で見せている。うちの決まり（1文目のすぐ後にデス）で書くなら、2文目か、1段目の頭に足す事になる。

# 線の段との対応

| 線の物 | どの区切りに入っているか |
|---|---|
| ①相手の型 | 「ある1人」＝フックの1文目（しぐさ）と、3・4段目の毎日の場面。「あなた」＝フックの名指しと、段ごとの暮らしの場面（仕事の途中・朝・食事の後、など） |
| ②入口の事実 | 「ある1人」＝1文目のしぐさが入口。「あなた」＝1段目の訳の中（「それが、あなたが◯◯で困る訳」）か、段の中の場面 |
| ③商品が要る1点：放っておけば戻るのでは、への答え | 言わない（5本とも）。成分が語る1本だけ、前置きで「年とともに減る」と言って、うっすら答える |
| ③商品が要る1点：今の手で足りるのでは、への答え | 1段目の訳の中（見本は 20〜29%）。成分が語る1本は前置き（23〜36%）。6段の1本は2段目。「あなた」の2本は言わない（「本当の原因はここ」と言うだけ） |
| ③商品が要る1点：なぜこの商品だとできるのか、への答え | 1段目と2段目の訳（見本＝形の訳と中身の訳の2つ）。「あなた」の形は、段ごとに内側の訳を1文ずつ |
| ④商品 | 種類はフックの中（0〜11%）。作りは段の訳の中。名前は言わないか、締め |

このフォーマットは「放っておけば戻るのでは」への答えを言わない。台本では、1段目の訳に「今までずっと◯◯だった訳」を1文足して答えるか、記事に回す。「あなた」の形で「今の手で足りるのでは」を言わない時は、1段目に必ず1文入れる。

# 書く時の手順

1. 形を決める：「ある1人」か「あなた」か。相手の型を1つのしぐさ・場面で言い当てられ、結果をじかに約束しにくい時は「ある1人」。相手が、買う人と使う人で別の時も「ある1人」。短く速く出すなら「あなた」。
2. 資料から、日数ごとの変化を拾い、4つの段に割る。資料に無い日数は作らない。段が3つに届かなければ、このフォーマットをやめる。
3. 設計メモの「商品が要る1点」を、1段目の訳に置く（「今までの手は、ここを狙っていなかった」＋商品の作りが届く所）。2段目に、効きが続く訳（2つ目の作り）を置く。
4. 入口の事実を、1文目のしぐさ（「ある1人」）か、1段目の訳の終わり（「あなた」）に置く。
5. 3段目・4段目は、相手の型の「困る場面」を裏返した場面にする（設計メモの型にある場面だけ）。
6. フック：商品の種類と日数を、最初の2文の中に入れる。デスを入れるなら2文目。
7. 段の境目を、40%・58%・76% の見当に置き、最後の段のすぐ後（85〜90%）に、締めを置く。着地が記事の時は、うちの締めの決まり（6章）に置きかえる。
8. 段の訳で使った原因の言葉が、後ろの段でも同じ言葉かを見る。

# はまる落とし穴

- 日数の作り話：資料に無い日数・変化で段を埋める。→ 段ごとに、声・レビュー・調査のどの行から取ったかを横に書く。
- 「ある1人」が、設計メモの型とずれる：絵になるしぐさを選んだ結果、声に無い人物になる。→ 1文目のしぐさが、声の件数のある型かを確かめる。
- 訳が、当てはめた段の全部に当てはまらない：1つの訳（作り）を、別の変化の訳にも使い回す。→ 段ごとに「この変化は、この作りで本当に起きるか」を1つずつ見る。
- 最後の段の約束が言いすぎ：「別人のように」「◯年ぶりに」が、資料の幅を超える。→ 「あなた」の形では特に、相手の言い返し（「そこまでは変わらないのでは」）を書いて確かめる。「ある1人」の仮の話にしても、結果の言い分は同じ重さで確かめる。
- 「放っておけば戻る」「今の手で足りる」が抜ける：段が変化の話だけになる。→ 設計メモの問いに、どの段の何文目で答えたか印を付ける。
- 2つの形がまざる：「ある1人」で始めて、途中から「あなた」に変わる。→ 主語を通して読み、変わる所があれば、どちらかにそろえる。
