# H　手紙を読み上げる

- 一言で：贈る人が、贈られる人に書いた手紙を、声に出して読む。説明は1つも無い。渡す場面と、読む声だけで運ぶ。
- 勝っている証拠：同じ運びの広告 4本・2ブランド。最長の配信 588日。4本のうち3本は同じ1ブランドで、読む手紙の文も、半分ほど同じ（同じ手紙を、前の寸劇と絵だけ替えて出している）。だから「2つの売り先で長く続いている」が正しい言い方で、広く勝っている証拠としては弱い。見本の運営者の広告は無い。4本とも、贈り物として買われる商品。
- 始まり（線のどの端から入るか）：線の外から入る。2通りある。（ア）渡す直前の小さな言い合いから入る（2本）。（イ）手紙の1語目＝あて名・祝いの言葉から、いきなり入る（2本）。どちらも、画面には「相手が◯◯な人なら、これで泣く」の形の札が、最初から出ている（3本で見た）。
- 進み方（何の時計・何の区切りで進むか）：手紙の文が区切り。時間の時計は無い。①あて名 ②ふだん言えていない、という打ち明け・または、気づいている事 ③相手が、家族にとって何か ④かなえたい願いを1つ ⑤約束・結びの1行 ⑥署名（無い物もある）。その後に、受け取った人の一言（2本だけ）。
- 語り手（だれの目・だれの声か）：贈る人の一人称（手紙の文）。読む声は、贈る人のこともあり、受け取った人が声に出して読むこともある。目は、贈られる人。買うのは、贈る側。
- 各区切りで言う事：商品の事は、1つも言わない（4本とも、声に商品の名前は0回）。言うのは、贈られる人が、だれにも言われた事の無い言葉だけ。①だれに ②言えていなかった事を認める ③その人がいるから家が回っている、という見方 ④「自分の目で、あなたを見せたい」という願い ⑤これからも変わらない、という約束。
- 1区切りの中の文の並び：認める（言えていなかった）→ 見ている物を具体に1つ → 相手を言い表す1文 → 願いを1つ → 願いがかなうと相手に何が分かるか → 約束。1つの区切りは、1〜2文で、どれも「あなた」に向いている。
- つなぎの作り：つなぎの言葉は無い。手紙の文の順だけで進む。寸劇から手紙へは「これは、あなたにだ」「開けて」の一言で渡す。手紙から結びへは、読み終わりの間（何も言わない数秒）で渡す。
- 商品が要る1点の置き場所：言葉では置かない。「言えずにいた事を、これが代わりに言う」が、ただ1つの訳で、渡す場面そのものが証明になる。値段・作り・ほかの物との違いは、全部、飛び先に回す。
- 締めの作り：手紙の最後の1行（約束か署名）で終わるか、受け取った人の短い一言で終わる。声のオファーも、行き先の案内も無い（4本とも）。行き先は、画面の札と下のボタンだけ。
- 長さの目安：33〜86秒。手紙そのものは、どれも33〜38秒ほどで、ほぼ同じ。長い物は、前の寸劇（16〜18秒）と、読み終わった後の間・受け取った人の一言（10〜11秒）が足されているだけ。
- 要る材料（商品の資料に何が無いと使えないか）：贈り物として買われている事（声・レビューで確かめる）。贈る人と贈られる人の間がら。贈る人が、言えずにいる言葉（声にある物）。言葉を商品に付けられる事（札・箱・包み）。
- 合わない商品・相手：自分のために買う、困り事を直す商品（線の段を1つも運べない）。仕組みを分かってもらわないと買われない物。贈る相手が、はっきりしない物。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：問題・原因・対策・商品の段が、1つも無い。相手の型は「言えずにいる人」。入口の事実は「相手の苦労に気づいているのに、言っていない」。線は1段だけで、残りは場面が運ぶ。商品が要る訳を、言葉で1度も言わない。

# フックの分解

（ア）寸劇から入る形
- 1文目：受け取る人の、いらだった問いかけ。広告に見えない家の中の一言で、場面に入れる。
- 2文目：贈る人の、とぼけた返し。まだ何も明かさない。
- 3文目：「これは、あなたにだ」。物を渡して、手紙へ送る。

（イ）手紙から入る形
- 1文目：あて名・祝いの言葉。だれに向けた言葉かを、名指す。
- 2文目：出会いからの歩みを、短い3拍で言う。または、誇りに思う、と言う。
- 3文目：ふだん言えていない、と認める。または、小さい時からを振り返る。

- 何で「え、どういうこと？」を作っているか：声ではなく、画面の札。「相手が◯◯な人なら、これで泣く」と先に言い切ってあるので、見る人は、泣く所・何が入っているかを見たくて待つ。寸劇の形は、そこに「けんかのように始まる」落差を足している。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：見せていない。こわい事は1つも出ない。代わりに、手紙の頭で「言えていなかった」を認める所が、見る人の後ろめたさに当たる。決まりの5章（フックのすぐ後にデス）は、この形では満たせない。

# 線の段との対応

| 線の物 | どの区切りに入っているか |
|---|---|
| ①相手の型 | 画面の札（「相手が◯◯な人なら」）。声では言わない |
| ②入口の事実 | 手紙の頭（言えていない・気づいているのに言っていない） |
| ③商品が要る1点：放っておけば戻るのでは、への答え | 無い |
| ③商品が要る1点：今の手で足りるのでは、への答え | 無い（「口で言えば足りるのでは」に、答えていない） |
| ③商品が要る1点：なぜこの商品だとできるのか、への答え | 無い（言葉が商品に付いている事を、絵で見せるだけ） |

このフォーマットは、商品が要る1点を、言葉で1つも言わない。穴の埋め方：台本では、札の1行と、受け取った人の一言で「口では言えなかった事が、これで届いた」を見せる。値段・作り・届くまでの日数・言葉を替えられるか、は全部、記事（飛び先）に回す。困り事を直す商品では、この穴は埋まらない。

# 書く時の手順

1. 贈る人と贈られる人の間がらを、1つに決める（設計メモの相手の型は、贈る側）。
2. 贈る人が「気づいているのに、言っていない事」を、声・レビューから1つ選ぶ（＝入口の事実）。
3. 画面の札の1行を決める（「相手が◯◯な人なら」の◯◯を、2で選んだ事に合わせる）。
4. 入り方を選ぶ：寸劇から（全体が長くなる）か、あて名から（短い）か。
5. 手紙を、区切り5〜6で書く。順は、認める → 見ている物 → 相手を言い表す → 願いを1つ → 約束。読んで33〜38秒に収める。
6. 「願いを1つ」を、全体の3分の2の所に置く。
7. 結びを決める：最後の1行で止めるか、受け取った人の一言を足すか。声のオファーは入れない。
8. 手紙で言えなかった事（値段・作り・言葉を替えられるか）を、記事への疑問として書き出す。

# はまる落とし穴

- 商品の事を、手紙に書いてしまう。確かめ：手紙の文だけを読んで、商品の言葉が1つも無いか。
- 贈る人が言いそうにない、きれいすぎる言葉になる。確かめ：1文ずつ、声・レビューに近い言い方があるかを見る。無い文は消す。
- 札の1行と、手紙の中身が合っていない（札では◯◯な人と言い、手紙では別の事をほめる）。確かめ：札の◯◯が、手紙の「見ている物」の文に出ているか。
- 困り事を直す商品に使ってしまう。確かめ：設計メモの「商品が要る1点」の問いに、手紙で答えられる物が1つでもあるか。無ければ、この形は使わない。
- 手紙が長くなる。確かめ：声に出して読み、38秒を超えたら、区切りを1つ消す。
- 決まりの「フックのすぐ後にデス」を満たせない。確かめ：この形を選ぶ時に、その事を台本の頭に書いて出す（黙って外さない）。
