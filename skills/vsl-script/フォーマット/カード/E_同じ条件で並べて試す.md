# E　同じ条件で並べて試す

- 一言で：相手が今使っている物と商品を、カメラの前で同じ条件で動かし、結果の差を目で見せる。訳の説明は、結果の後に短く付ける。
- 勝っている証拠：同じ運びの広告 5本・4ブランド（2本は同じブランド）。最長の配信 634日（Winning・used 2）。5本とも今も配信中（157〜634日）。弱い所：5本の形はそろっていない。2つを並べて結果まで見せるのは3本。残りの2本は「悪い側だけを作って見せる実験」と「同じ量になる数を並べて比べる実演」で、結果の差までは見せない。映像を通しで見られたのは1本と、もう1本の1枚だけ。3本は最初の1枚しか無かった。1本はヒンディー語で、自動の文字起こしが粗い。
- 始まり（線のどの端から入るか）：線の終わり（結果）か、線の中ほど（今使っている物）から入る。入口の事実も原因も、言葉では言わない。今の物の「足りない結果」を、最初に目で見せる。
- 進み方（何の時計・何の区切りで進むか）：実験の手順が区切り。①今の物の側を見せる ②条件が同じだと言う ③商品の側を動かす ④2つを並べて言い切る ⑤（ある時は）訳を1つずつ・日がたった後の差 ⑥締め。
- 語り手（だれの目・だれの声か）：試している本人の声（「両方を同じ条件で動かした」「今日はわざと◯◯する」）。目は、結果の物に向いている。顔を出す形（自分の体で左右を比べる）と、手元だけの形がある。
- 各区切りで言う事：①今の物の名前と、起きている結果 ②同じ物・同じ手順で試す事 ③商品の側で何をしたか（手順を声に出す） ④「見てのとおり」と結果を指す ⑤片方が届く範囲と、もう片方が届く範囲／良かった期間の差 ⑥値段を今の物と比べる・保証・「結果は見たはず」。
- 1区切りの中の文の並び：指す（「これが◯◯」）→ 何をしたか → 結果を1語で言う。訳の所は「片方の中身 → それが届く範囲 → もう片方の中身 → 残りに届く」。1文が短い。声の無い間（絵だけ）が入る。
- つなぎの作り：実験の手順そのもの（「今度は、もう片方に」「では、見てみよう」）。指す言葉（「これ」「こっち」）で、絵に話を渡す。
- 商品が要る1点の置き場所：④の並べて言い切る所（全体の45〜71%）と、⑤の訳。「今の物で足りるのでは」に、目で見える結果で答える。訳は後から1回だけ。
- 締めの作り：値引き・まとめ買い → 1つあたりの値段を今の物と比べる → 保証 → 「結果は見たはず」。短い形（2本）は、値段を言わず「これを試して」の1文だけ。
- 長さの目安：33〜136秒（5本。平均70秒）。うち、声の無い時間が全体の2〜5割ある広告が3本。
- 要る材料（商品の資料に何が無いと使えないか）：結果の差が、その場で目に見える事（色・量・跡・数など）／同じ条件で比べた記録か、うちで撮れる実験／今の物が届かない範囲を言える根拠／比べる相手を名指してよいか（決まりの確認）。
- 合わない商品・相手：結果が目に見えない物・日がたたないと差が出ない物。実験の記録が無く、撮る事もできない物（絵で作ると、うその実験になる）。原因を知らないと、差の意味が分からない相手（結果を見ても「それで？」になる）。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：問題も原因も言葉で説明しない。結果の差を先に見せ、原因は「片方が届かなかった残り」として後から1回だけ言う。線は逆向き（商品→対策が届かない訳→原因）。声より絵の時間が長い。

# フックの分解

- 1文目：形が3つあった。片方の結果を指す（「これが◯◯の後」）／自分に起きている悪い結果を、笑いながら見せる／多くの人がすぐ手を伸ばす物を名指す。セールの知らせから入る1本は、これに当てはまらない。
- 2文目：もう片方の結果を指す。または「その代わりに何を払っているのか」と問う（隙間を開ける）。または「自分はもう困っていない」と言う。
- 3文目：判定を相手に渡す（「どちらが要るかは、もう分かるはず」）。または「今日はわざと元に戻す」「このままにはしない」と、これから見せる事を約束する。
- 何で「え、どういうこと？」を作っているか：絵。言葉より先に、2つの差（または、ふつうはしない事をしている手元）が映っている。「同じ事をしたのに？」「何をする気？」が、相手の頭に出る。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：言葉では見せていない。今の物の側の結果（残った物・うまくいかなかった跡）を、寄りの絵で見せる事が、その代わりになっている。暮らしの場面としてのデスは、5本とも無い。

# 書く時の手順

1. 見せる結果を決める。資料に、同じ条件で比べた記録があるか、うちで撮れる実験があるかを確かめる。無ければ、このフォーマットを使わない（作らない）。
2. 「同じ条件」を決める。設計メモの相手の場面（いつ・何をしている時）を、そのまま実験の条件にする。
3. 比べる相手を決める。相手が今使っている物の中で、一番多い物。名指してよいかを、決まりで確かめる。
4. 絵の順を先に書く（今の物の側の結果 → 条件 → 商品の側 → 並べる）。語りは、絵を指す短い文だけにする。声の無い間を、秒で決めておく。
5. 訳を入れるかを決める。入れるなら、結果を並べた後に、設計メモの「なぜこの商品だとできるか」を、線の言葉のまま1〜2文。
6. 商品の名前を、先に言うか（比べる相手を名指す形）、実験の後に言うか（今の物をわざと作って見せる形）を決める。
7. 秒を当てる。商品の側に移るのは全体の3〜5割。締めは最後の1割強。
8. 締めを書く。値段を今の物と比べられるなら、1つあたりで比べる。

# はまる落とし穴

- 条件が同じに見えない。確かめ：絵だけを見て、2つの違いが「使った物」だけだと分かるか。量・時間・場所が、同じ画面で確かめられるか。
- 撮っていない実験を、絵で作る。確かめ：結果の絵の1つずつに、元の記録（写真・動画・試験の紙）があるか。無い物は出さない。
- 結果は見えるが、相手の暮らしの結果ではない。確かめ：見せた差が、設計メモの「相手が失っている物」につながるか。つながらないなら、条件を相手の場面に寄せ直す。
- 訳を足しすぎて、実験が止まる。確かめ：訳の段が、全体の3割を超えていないか（測った中で一番長い1本で約28%）。
- 語りを秒いっぱいに書いて、絵を見る間が無くなる。確かめ：結果を映す所に、声の無い1〜2秒があるか。
- 比べる相手を悪く言いすぎる。確かめ：相手の物が「できる事」を1つ認めているか。認めた上で「届かない残り」を言っているか。
