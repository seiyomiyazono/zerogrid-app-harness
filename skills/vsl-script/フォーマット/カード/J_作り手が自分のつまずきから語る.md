# J　作り手が自分のつまずきから語る

- 一言で：作った本人が、自分が困った日・だめだった日から話し、調べて、自分で試して、それが商品になった、と年の順に運ぶ。
- 勝っている証拠：同じ運びの広告 5本・5ブランド（一人称4本＋作り手を「彼」と呼ぶ三人称1本）。最長の配信 1106日。5本とも500日を超えている。ほかに、弱い同じ形が4本（中身は測っていない）。見本の運営者の広告は無い。5本は長さが大きく違い（66〜267秒）、割り振りの幅も広い。
- 始まり（線のどの端から入るか）：線の入口の事実を、作り手自身の体験として言う。入り方は4つ見た：自分の体に起きた事の一言／手に持った古い物（「この中の1枚が、始まり」）／「私は◯◯ではない、ただの◯◯だ」という名乗り／「これは、私の暮らしが変わった話」という予告。三人称の版だけは、「みんなが見落としている事が1つある」から入り、作り手は後から出る。
- 進み方（何の時計・何の区切りで進むか）：作り手の年表が区切り。①困った日 ②たよった先で足りなかった・今までの手では変わらなかった ③自分で調べた・思いついた ④自分で試して良くなった ⑤それが商品になった・人に広がった ⑥ほかの手との違い ⑦確かさ（使った人の数・作り）と結び。②が無い物（見た問題から、すぐ思いつきへ行く物）もある。
- 語り手（だれの目・だれの声か）：作り手本人の一人称（4本）。三人称の版は、別の語り手が、作り手を名前と「彼」で呼び、家族を助けるために作った話として語る。
- 各区切りで言う事：①いつ・何が起きたか（年や時期を言う物が3本）②相手も言われた事のある言葉・相手も試した事のある手 ③分かった仕組みを1つ ④良くなった速さ（週・月）⑤1つの物が、商品の形に広がった事 ⑥今までの手の弱い所と、これの違い ⑦数。
- 1区切りの中の文の並び：その時の自分の様子 → した事 → 起きた事。③だけは、「調べた（本・人・学び）」→「分かった事を1文」→「体や暮らしの、分かるたとえ」の順。⑥は、「今までの手は◯◯」→「だから届かない」→「これは◯◯だから届く」の順。
- つなぎの作り：年・時期の言葉と、作り手の気持ち（「がまんしたくなかった、だから」「短く言うと」「そこから」）。三人称の版は「その時、彼は気づいた」「そこで彼は」で進む。
- 商品が要る1点の置き場所：2か所に分かれる。（1）②〜③の所（全体の2〜3割）で、「今までの手・たよった先では、足りなかった」を、作り手の体験として言う。（2）⑥（全体の6〜7割）で、「今までの手と、どこが違うか」を、もう1度、相手に向けて言う。
- 締めの作り：2通り。（ア）使った人の数・作りの確かさ・お礼で止め、値段もオファーも言わない（2本）。（イ）試せる日数や返せる約束 → 今だけの値引き・ただで受けられる事 → 「◯◯な物に、お金をむだにするのをやめよう」の1行（3本）。第1版の「オファーを言わない物が多い」は、測ると、言う物の方が多かった（5本のうち3本）。
- 長さの目安：66〜267秒。短い組（66・85・105秒）と、長い組（245・267秒）に分かれる。
- 要る材料（商品の資料に何が無いと使えないか）：作り手が実在し、顔と名前を出せる事。作り手自身の困った日と、たよった先で言われた言葉（本当の話）。調べて分かった仕組み。試して良くなるまでの長さ。日本の店で、海外の作り手の話を使ってよいかの確かめ。
- 合わない商品・相手：作り手の話が無い・出せない商品（作ると、うその人物になる）。仕入れて売っている物。作り手と相手の型が離れている時（年代・悩みが違う）。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：段の順は普通と同じだが、全部が1人の過去形で語られる。相手は「言われる」のではなく、同じ道を先に歩いた人の話として聞く。商品は、話の結果として、後ろ（全体の6〜8割）に出る。会社やブランドの名前は、名乗りとして早く言う物がある（商品として言うのとは別）。

# フックの分解

- 1文目：4通り見た。自分の体に起きた事を、そのまま一言／手の中の古い物の年を言い、「中身を話したい」と言う／世の中が思う肩書きを、自分で否定する／「暮らしが変わった話だ」と言い切る。どれも、売る側の人が、売り物ではなく自分の事から話し始める。
- 2文目：名前と立場を名乗る。または、「ただの◯◯で、◯◯にうんざりしていた」と、相手と同じ側に立つ。
- 3文目：困った時期（年・年数）を言い、年表に入る。
- 何で「え、どういうこと？」を作っているか：売る人が、自分の弱い所・失敗・怒りから話し始める落差。または、古い物を見せて「この1枚が始まり」と、中身を伏せる。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：作り手に起きた事として、区切り1で見せる（全体の6〜33%）。命にかかわると思った日／人を手放さなければならない所まで来た日／家族がひどく痛がった朝。相手のこわい事を、相手に向けては言わない。こわい事の無い物もある（道具への不満から入る物）。フックのすぐ後ではなく、名乗りの後に来る。

# 書く時の手順

1. 作り手の話が、資料に本当にあるかを確かめる（困った日・たよった先・調べた事・試した長さ）。無ければ、この形は使わない。
2. 作り手の困り方が、設計メモの相手の型と同じかを見る。違う所は、言わない。
3. 入り方を1つ選ぶ：体に起きた事の一言／古い物／否定の名乗り／暮らしが変わった話。
4. 区切り2に、設計メモの入口の事実を、作り手が言われた言葉・試した手として置く（全体の2割ごろ）。
5. 区切り3で言う仕組みを、1つにしぼる（設計メモの「商品が要る1点」）。
6. 商品を出す所を決める（全体の6〜7割）。そこまでは、会社の名乗りは良いが、商品として名前を言わない。
7. 区切り6（ほかの手との違い）を、設計メモの「商品の言い方」の表にある条件だけで書く。
8. 締めを選ぶ：数と確かさで止めるか、試せる約束とオファーまで言うか（着地が記事なら、決まりの6章の順を先に守る）。

# はまる落とし穴

- 作り手の話を、資料に無い所まで作ってしまう。確かめ：年・場所・言われた言葉を1つずつ、資料のどこにあるかを書く。
- 年表が長くなり、商品が出る前に終わる。確かめ：商品が出る所が、全体の8割より後ろになっていないか。
- 商品が出た後が、作り手の話ではなく、ただの商品の説明になる（三人称の版は、後ろ3分の1がそうなっている）。確かめ：区切り6以降の文の主語が、作り手か「私たち」のままか。
- 作り手の困り方と、相手の困り方が、ずれている。確かめ：区切り1・2の文を、相手の声と並べて、同じ事を言っているか。
- 「たよった先」を悪く言いすぎて、相手に言い返される。確かめ：言われた言葉を、そのまま1つ言うだけにして、決めつけの文を足していないか。
- 名乗りで会社の名前を言い、その後で「ある物を見つけた」と伏せると、ちぐはぐになる。確かめ：名前を言う所と、伏せる所が、ぶつかっていないか。
