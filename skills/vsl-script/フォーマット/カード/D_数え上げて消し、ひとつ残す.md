# D　数え上げて消し、ひとつ残す

- 一言で：相手が選びそうな物（または相手の型）を数で言い、1つずつ「ここが足りない」と消していき、消した訳を裏返した条件を言ってから、最後に残る1つを出す。
- 勝っている証拠：同じ運びの広告 6本・4ブランド（うち3本は同じ売り先が別の名前のページで出しているので、1ブランドと数えた）。最長の配信 257日。6本とも今も配信中（155〜257日）。used は 1〜10。弱い所：3本が同じ売り先なので、別々の売り手で確かめられたのは実質4つ。そのうち2本は変わり形（人の型を数える版・必要な物を数えて束ねる版）。段（Winning／Optimized）は6本とも確かめていない。映像は6本とも最初の1枚しか見られなかった。
- 始まり（線のどの端から入るか）：線の中ほど（今している対策・比べている物）から入る。1文目で数を言う。入口の事実（相手が気づいている事）は、フックでは言わず、番号の中で「あなたも◯◯しているはず」として出る。
- 進み方（何の時計・何の区切りで進むか）：番号が区切り。2〜5つを順に消す。全部消したら、条件を1文にまとめた問いを置き、残りの1つへ。数える所は、全体の半分まで。
- 語り手（だれの目・だれの声か）：詳しい第三者が、相手に語る（実物の後ろに立つ人・売り場を歩く手・白衣ふうの服の人・自分の部屋で話す使い手）。作り手の顔はしない。「私なら買わない」「私はこれしか使わない」と、自分の選びとして言う。
- 各区切りで言う事：番号ごと＝その物の名前／みんながそれを選ぶ訳（認める点）／足りない点とその訳／毎日には向かない、の一言。まとめの問い＝消した訳を裏返した条件を3〜4つ並べ、「そんな物はあるのか」。残る1つ＝条件を1つずつ満たす作り → 使う場面 → 長持ち → 選んでいる人の数。
- 1区切りの中の文の並び：番号と名前 → 良いと言われている点（認める） → 「でも」 → 足りない点 → それで起きる事（体・手間・お金） → 短い言い切り。どの番号も同じ並びで、言い切りの1文で閉じる。
- つなぎの作り：番号そのもの（「◯番」）。番号の間に、つなぎの文は置かない。数える所から残る1つへは、問いの1文（「では、◯◯で◯◯な物はあるのか」→「ある」）。変わり形では「それができても、まだ足りない物がある」と、前の番号では届かない所を言って次の番号へ進む。
- 商品が要る1点の置き場所：まとめの問いの1文（全体の31〜64%）。番号の段は、その条件を1つずつ作る場所。「今の手で足りるのでは」には、番号ごとに、その物に当てはまる訳で答える。
- 締めの作り：条件をもう1回まとめる（「◯◯か◯◯かを選ばなくていい」）→ 値引きとおまけ → お試し・保証 → 「数が無くなったら終わり」。短い形では、値段を言わず、保証の1文か、自分の選んだ物を見せるだけで終わる。
- 長さの目安：62〜230秒（6本。平均135秒）。消す物が2つで60〜110秒、4〜5つで160〜230秒。
- 要る材料（商品の資料に何が無いと使えないか）：相手が実際に選んでいる対策・比べている物の名前を2〜5つ／1つずつ、その物に当てはまる「足りない訳」（まとめて1つの訳にしない）／足りない訳を裏返すと、商品の作りと1対1になる事／値引き・保証（締めに使うなら）。
- 合わない商品・相手：比べる相手がいない新しい種類の物。足りない訳が物ごとに言えない時（1つでも当てはまらないと言い返される）。原因をまだ知らない相手（消す訳が飲み込めない。原因の説明を番号の中に割って入れる事になり、長くなる）。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：普通は対策を1つにまとめて「届かない」と言う。これは対策の段を番号で広げて主役にし、原因の説明を「足りない訳」の中に割る。問題の段が無い（1文目から数える）。商品が要る1点は、相手が消した後に自分で言える形になる。

# フックの分解

- 1文目：数を言う（「◯つある」）。形は3つあった。数と「でも残るのは1つだけ」を1文で言う／数と「私なら買わない」だけを言う／相手の困り事を名指して「あなたは◯つの型のどれか」と言う。数を言わない1本は、「みんな一番悪い物を選んでいる」と、こわい事から入る。
- 2文目：「残るのは1つ」「◯番目まで待って」と、最後まで見る訳を作る（隙間を開ける）。変わり形は「合っていれば◯◯、違っていれば◯◯」と、良い先と悪い先を並べる。
- 3文目：もう1つ目の番号に入っている（6本中5本）。フックは長くても3文。
- 何で「え、どういうこと？」を作っているか：数と「残るのは1つ」。相手は、自分が使っている物が何番で出るか・残る1つは何かを知りたくて見る。だれもが良いと思っている物を「買わない」側に入れる形では、信じていた物の否定がそれに重なる。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：フックでは、ほぼ見せていない（悪い先を1文で言うのは6本中1本）。番号ごとの「足りない点で起きる事」として、小分けにして見せる。1つにまとめた大きな絵は無い。

# 書く時の手順

1. 設計メモの「今の手で足りるのでは」から、相手が実際に選んでいる物を全部書き出す（声・調査にある物だけ）。数は2〜5つ。
2. 1つずつ、その物に当てはまる「足りない訳」を書く。同じ訳を2つに使い回さない。1つでも相手に言い返される物は、数から外す（2-6）。
3. 足りない訳を裏返して、条件の1文にする。その条件の1つずつが、商品の作りと1対1になるかを表にする（2-7）。ならない条件は、消す訳として使わない。
4. 並べる順を決める。相手が一番多く選んでいる物を1番に置き、その頭に入口の事実を1文入れる。商品に一番近い物を、最後に消す。
5. 番号ごとの文の並びを1つに決める（名前 → 認める点 → 足りない点 → 起きる事 → 言い切り）。全部の番号を同じ並びで書く。
6. 秒を当てる。数える所は全体の半分まで。消す物が4つ以上なら、1つ10〜15秒。
7. 残る1つを書く。条件の順のまま、作りで1つずつ答える。条件に無い良さは言わない。
8. フックを書く。数と「残るのは1つ」。3文目には、もう1番に入る。

# はまる落とし穴

- 足りない訳が、その物に当てはまらない。確かめ：番号ごとに、相手が言いそうな「でも、◯◯は平気だけど？」を書き、言い返しが成り立たないか。
- 消す訳が、商品にも当てはまる。確かめ：消した訳を全部、商品に向けて言ってみる。1つでも商品に当たれば、その訳は使えない。
- 数える所が長くなり、商品に着く前に相手が離れる。確かめ：まとめの問いの始まりが、全体の64%より後ろになっていないか。
- 認める点を飛ばして、全部を悪者にする。確かめ：番号ごとに、相手がそれを選んだ訳を1文で言っているか。無いと、相手は「私の選びをばかにされた」と離れる。
- まとめの問いの条件が、消した訳と合っていない。確かめ：条件を1つずつ、どの番号から出たかに線で結べるか。どの番号からも出ていない条件が入っていないか。
- 体にこわい事を、番号ごとに積みすぎる。確かめ：「起きる事」の1つずつに資料の出どころがあるか。無い物は、手間・お金の話に替える。
