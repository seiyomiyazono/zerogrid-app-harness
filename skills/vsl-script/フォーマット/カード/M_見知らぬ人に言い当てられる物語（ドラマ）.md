# M　見知らぬ人に言い当てられる物語（ドラマ）

- 一言で：1人の主人公の物語。かくしていた困り事を、売り手でも専門家でもない通りすがりの他人に言い当てられ、そこから原因と商品にたどり着く。
- 勝っている証拠：同じ運びの広告 2本・2ブランド。最長の配信 378日。もう1本は 224日で、ほかの売り手にも5回使い回されている台本。見本の運営者の広告は無い。弱い所：2本だけ。2本で、見知らぬ人が出る位置が大きく違う（頭／全体の35%）。映像は2本とも最初の静止画1枚しか見られていない。
- 始まり（線のどの端から入るか）：入口の事実から。ただし、相手に向けて言うのではなく、「主人公が、自分でも見ないふりをしていた事を、他人に見抜かれた」という場面で見せる。入り方は2つ。（ア）言い当てられる場面そのものから始める。（イ）1文目で結末を先に言い（失いかけた物＋見知らぬ人が教えてくれた）、言い当てられる場面は全体の3分の1あたりに置く。
- 進み方（何の時計・何の区切りで進むか）：物語の出来事が区切り。言い当てられる → 試してだめだった手の話 → 他人が手がかりを渡す → 半信半疑で調べる・買う → 日数の段 → 結果の確かめ → 最初の場所・最初の心配に戻る。時計は、後ろの3分の1だけ「日・週」になる。
- 語り手（だれの目・だれの声か）：主人公の一人称（声だけ、または本人が映って話す）。見知らぬ人のせりふは、主人公が引用する。（ア）の版は入れ子で、主人公 ← 見知らぬ人 ← その人の身内、の3重。
- 各区切りで言う事：
  1. 言い当て：他人が、主人公の様子を見て、困り事を口にする。主人公の気持ち（はずかしい・固まる）を1文。
  2. 試した手：困り事の様子を3〜4つ → すすめられた手を1つずつ、「それで何が起きたか」付きで切る → 「教えてくれるはずの人が、訳を説明しなかった」。（ア）では、これを見知らぬ人の身内の話として言う。（イ）では主人公自身の話として、言い当ての前に言う。
  3. 手がかり：他人が、名前だけを渡す（物に書いた1語／「これを使った」の一言）。売りこまない。
  4. 原因：なぜ今までの手が届かなかったか。（ア）は他人が2〜3文で言う。（イ）は主人公が自分で調べて分かった事として、全体の2割ぶんを使って言う。
  5. 買う・疑う：「またがっかりするのでは」を主人公が自分で言う。信じた訳は、他人の言い方の確かさ。
  6. 日数の段：刻みごとに、体や暮らしで分かる変化を1つ。
  7. 結果の確かめ：詳しい人が数を読み、「何を変えたのか」と聞く（ア）。または、頭で失いかけた物が戻った事を言う（イ）。
  8. 戻る：最初の場所・最初のせりふに戻り、逆の答えで閉じる。
- 1区切りの中の文の並び：場面（どこで・だれが）→ 他人または主人公のせりふ → 主人公の気持ちを短く1文。説明の区切りだけは、「みんなが知っている事」→「でも、知らなかった事」→「だから今までの手はこうなった」。日数の段は、刻み → 起きた事 → 「◯◯ぶりに」。
- つなぎの作り：出来事の順。区切りの頭は、時を言う言葉（その夜／◯日後／ある日／◯か月後）か、「でも、その人は◯◯を言った」。中身を伏せて先に見せる（「何かを書いた」→ 後で何と書いたかを見せる）事で、次の区切りへ引っぱる。
- 商品が要る1点の置き場所：手がかりのすぐ後。「今までの手は、出ている様子を押さえるだけ。もとの所に届いていない」を、他人の口か、主人公の調べで言う。位置は全体の35〜70%（2本で大きく違う）。（ア）は3文と薄い。（イ）は2割ぶんを使い、たとえを1つ置く。
- 締めの作り：頭に戻る。同じ場所・同じ人・同じ問いに、逆の答え。その後に、効き目の言い直し1文と、急がせる1文（ア）。または、主人公の人がらの1文（「◯◯な人間だから、だめな物はすすめない」）→「自分のように待つな」（イ）。値段は2本とも言わない。
- 長さの目安：139〜166秒（平均152秒）。
- 要る材料（商品の資料に何が無いと使えないか）：外から見て分かる困り事（他人が見て気づける様子）。試した手と、その後どうなったか。今までの手が届かない訳（1〜3文で言える物）。日数ごとの変化（声か調査にある物）。結果を数や人の反応で確かめられる場面。主人公が失いかけている物。
- 合わない商品・相手：外から見て分からない困り事（他人が言い当てる場面が、作り話になる）。日数ごとの変化の材料が無い商品。詳しい人が結果を読む場面を、決まりの上で言えない商品（その時は（イ）の閉じ方にする）。商品をもう知っていて迷っている相手（物語が長すぎる）。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：段は同じだが、どの段も「だれかが主人公に言った事」として運ぶ。原因を教えるのが売り手でも専門家でもないので、売りこみに聞こえにくい。その代わり、原因の段がうすくなりやすい。「放っておけば」への答えは、説明ではなく、他人の身内がたどった先として見せる。

# フックの分解

- 1文目：（ア）場面に入れる（どこで・だれが・何をしたか。あいさつも前置きも無い）。（イ）結末を先に言う（失いかけた物 ＋「見知らぬ人が、教えてくれるはずの人が言わなかった事を教えた」）。
- 2文目：（ア）他人のせりふで、主人公の様子を言い当てる。（イ）困り事がどれだけ長く続いているかを言う。
- 3文目：（ア）他人が「自分の身内も同じだった」と言い、その先にあった重い事を1語で言う。（イ）何を使っても消えなかった事を言う。
- 何で「え、どういうこと？」を作っているか：売る人でも詳しい人でもない他人が、なぜそれを知っているのか、という隙間。（ア）は、「何かを書いた」と見せて中身を伏せる事で、隙間をもう1つ開ける。（イ）は、「教えてくれるはずの人が言わなかった事」と言い、中身を全体の半分まで伏せる。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：（ア）全体の4〜7%。他人のせりふの中で、「同じ様子だった身内が、もっと重い所の手前まで行った」と言う。最後の1文でもう1回、「手おくれになる前に」と言う。（イ）1文目で、大事な人との仲を失いかけた事を言い、10〜14%と33%でもう1回、その仲がどうなっているかを見せる。

# 線の段との対応

| 線の物 | どの区切りに入っているか |
|---|---|
| ①相手の型 | 「困り事の様子と、試してだめだった手」の区切り。（ア）では他人の身内の姿として、（イ）では主人公の姿として |
| ②入口の事実 | 言い当ての区切り（主人公が、気づいているのに見ないふりをしていた事）と、「何を使っても戻る」の文 |
| ③商品が要る1点：放っておけば戻るのでは、への答え | （ア）他人の身内が年単位で悪くなった話。（イ）は「昔からずっと」の1文だけで、うすい |
| ③商品が要る1点：今の手で足りるのでは、への答え | 試した手を1つずつ切る区切り ＋ 原因の区切りの「だから、今までの手は◯◯だけ」 |
| ③商品が要る1点：なぜこの商品だとできるのか、への答え | 原因のすぐ後。（ア）は1文。（イ）は「何が入っていて、原因のどこをどうするか」を2文 |
| ④商品 | 手がかりの区切り（名前だけ）→ 買う区切り → 日数の段 |

このフォーマットは、（ア）の形だと「なぜこの商品だとできるのか」を1文しか言わない。台本では、他人のせりふをもう1〜2文のばして、線で使った言葉のまま言う。のばすと売りこみに聞こえる時は、記事に回す。

# 書く時の手順

1. 設計メモの相手の型から、「他人が外から見て気づける様子」を1つ選ぶ。無ければ、このフォーマットを使わない。
2. 見知らぬ人を決める：どこで・何をしている人で、なぜその様子に気づけるのか（同じ困り事の人を身近で見た・自分もそうだった）。売り手・専門家にしない。
3. 入り方を決める：言い当てる場面から始めるか、結末の1文から始めて場面を3分の1に置くか。前の台本と同じにしない。
4. 線の段を、「だれが主人公に言うか」に割り振る：試した手（他人の身内の話か、主人公の話か）／原因（他人が言うか、主人公が調べるか）。商品が要る1点は、ここで一番はっきり言う。
5. 手がかりの渡し方を決める（何に・どう書いて渡すか。または一言か）。商品の名前を初めて出す所は、ここ。全体の45〜70%。
6. 日数の段を、声と調査にある変化だけで作る。刻みは1〜6つ。資料に無い刻みは作らない。
7. 結果の確かめ方を決める（詳しい人が数を読む／失いかけた物が戻る）。決まりの上で言えない物は使わない。
8. 最初の場所・最初のせりふに戻る締めを書き、頭の文と並べて、逆になっているかを見る。最後に、設計メモの段が全部、順に通っているかを確かめる。

# はまる落とし穴

- 他人が言い当てる訳が無い：外から分からない困り事を言い当てさせると、作り話に見える。確かめ方：「この人は、何を見て気づいたのか」を1文で言えるか。
- 原因がうすい：物語を進める事に気を取られ、商品が要る1点が1文で終わる。確かめ方：設計メモの問い（放っておけば／今の手で足りるのでは／なぜこの商品だと）の答えが、どの区切りのどの文かを指させるか。
- 見知らぬ人が売り手に見える：他人が商品の良さを長く話すと、芯がこわれる。確かめ方：他人のせりふに、商品の特長が2つ以上入っていないか。
- 入れ子で迷う：「彼」「その人」が、他人なのか、他人の身内なのか、分からなくなる。確かめ方：1回聞いて、だれの話かが分かるか。区切りの頭で、だれの話かを言い直しているか。
- 日数の段・検査の数を作ってしまう：資料に無い日数・数を書くと、言い返される。確かめ方：刻みと数を1つずつ、声・調査の出どころに当てる。
- 頭の約束と中身が合わない：頭で「他人が教えてくれた」と言ったのに、中では主人公が自分で調べて分かった事になる（見本の1本がそうなっている）。確かめ方：頭の1文と、原因を言う区切りの語り手を並べて見る。
