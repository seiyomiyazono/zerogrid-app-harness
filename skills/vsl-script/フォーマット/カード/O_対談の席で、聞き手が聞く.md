- 一言で：マイクを置いた対談の席で、聞き手が短く問い、もう1人が1文で言い切ってから、たとえで絵にする。または、よく知られた人の問いと答えの切り抜きを先に見せ、「その通り。訳はこうだ」と自分の声で続ける。

- 進み方（何の時計・何の区切りで進むか）：問いが区切り。数は少ない（1〜5。聞き返しをふくむ）。時計は無い。問いの間は、2〜4文の時と、20〜35秒の長い答えの時がある。
- 語り手（だれの目・だれの声か）：2人。目は聞き手（＝相手）。答える人は、売る本人（詳しい人）か、同じ立場で先に使った人（同じ親どうし・同じ仲間）。聞き手は、問うだけでなく、「この人は当たっていた」「広告で見た」と、裏づけと商品への橋も担う。切り抜きの版は、有名な人の声 → 売る側の声（1人の語り）に替わる。
- 各区切りで言う事：
  1. 大きな問い → 1文の答え（言い切り）。
  2. たとえで絵にする（相手と、ほしい物の間に、じゃまが並んでいる絵／身近な小さな事と同じ仕組みだという絵）。たとえの中で、じゃまを3つ名指す。
  3. 「では、どうやって取るのか」「本当の原因は何か」→ 仕組みを3〜5文。または、答える人が聞き手に返し、聞き手が自分の体験を言う。
  4. 聞き手の裏づけ：見ている人に向いて、「この人が言った事が、自分に当たった」と言う。または「最近、広告でよく見る。名前は？」と、商品の名前を答える人に言わせる。
  5. 小さい問いを続ける（どれを買ったか／どう使うか）→ 1〜3文の答え。
  6. 「どうすれば受けられるか」→ 答える人が、見ている人に向き直る。

- 締めの作り：3つ見つかった。聞き手が「どうすればいい？」と聞き、答える人が見ている人に「これを見ているのは、たまたまではない。リンクから」と言う（押した先で何が見られるかまで言う）。返金の約束の1文で、ぷつりと終わる。「この人たちが、自分の人生を変えた」を2回言って終わる（押す先を言わない）。値段は4本とも言わない。
- 長さの目安：66〜111秒（4本。平均90秒）。第1版の「見当80〜160秒」は、実測で短く直した。
- 要る材料（商品の資料に何が無いと使えないか）：答える人（詳しい人・作り手・先に使った同じ立場の人）と、聞き手。1文で言い切れる答えと、それを絵にするたとえ1〜2つ。聞き手が言える裏づけ（自分に当たった事・使った結果）。切り抜きの版は、使ってよい他人の発言（使う権利の確かめが要る）。
- 合わない商品・相手：詳しい人を立てられない商品・立ててはいけない決まりの商品。目で見せないと分からない物（話だけになる）。問いが多い物（疑いを5つ以上つぶす掛け合いのカードの方が合う）。日数ごとの変化を見せたい時（この運びには時計が無い）。

# フックの分解

- 1文目：（ア）聞き手の問い（相手が知りたい事に、こつはあるのか）。（イ）言い切り（みんなが最後の手だと思っている物は、要らない）。（ウ）切り抜きの中の人が、有名な人の名前を呼んで問う（初めての人は、どこから始めればいいか）。相づちの版は、話し手が「前に、◯◯の取り方を人に教えた」と言う。
- 2文目：（ア）1文の答え（◯◯を通れるようにする）。（イ）聞き手の「本当に？」。（ウ）有名な人が、相手の型を名指して、物の種類の名前を1つ言う。相づちの版は、「その手は取れる。でも年単位の時間がかかる」。
- 3文目：（ア）「たとえば」と、たとえに入る。（イ）聞き手が、「詳しい人に、それを最後の手だと言われた」と、相手が信じている事を言う。（ウ）その物の種類が何かを説明する。相づちの版は、「取れた後に、こうなる」と前ぶれする。
- 何で「え、どういうこと？」を作っているか：対談の途中から始まったように見える事（広告に見えない）。問いが、相手が人に聞けずにいる事。（イ）は、信じていた物を否定する。（ア）の答えは、わざと絵になる言葉で言い切り、訳をたとえまで伏せる。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：ほとんど見せていない。（ア）は、たとえの中で「ほしい物が、いつまでも自分に届かない」を絵にする（5〜25%）。（イ）は、原因の説明の終わりで、目に見える様子を1文（51〜58%）。相づちの版は、「少し良くなって、その後、前より悪くなる」（26〜32%）。フックのすぐ後に置いた物は、1本も無い。

# 書く時の手順

1. 答える人と聞き手を決める：詳しい人と相手の代わりの人／同じ立場の2人（先に使った人と、まだの人）／他人の発言の切り抜きと自分。資料と決まりの上で、立てられる人だけ。
2. 1文目を決める：設計メモの入口の事実を、聞き手の問いにするか、答える側の言い切り（信じている物の否定）にするか。
3. 1つ目の答えを、1文で書く：商品が要る1点を、絵になる言葉で言い切る。問いのすぐ次の文に置く（前置きをはさまない）。
4. たとえを1つ選ぶ：じゃま・仕組みを、相手が見た事のある物に置きかえる。たとえの最後に、本題へ戻す1文を必ず置く。
5. 2つ目・3つ目の問いを決める：相手が次に思う事だけ（どうやって／本当の原因は／どう使う）。全部で2〜5つ。問いは1文、10語まで。
6. 聞き手の裏づけを決める：資料にある事実だけ（使った結果・当たった事・見かけた事）。全体の55〜90%に置き、そこから商品の名前へ渡す。名前は、答える人に言わせる。
7. 締めを決める：聞き手の「どうすれば」→ 答える人が見ている人に向き直る。押した先で何が見られるかを言う。
8. 線の段のうち、入らなかった物（放っておいた先・相手の型・商品が届く訳）を書き出し、問いを1つ足して入れるか、記事に回すかを決める。

# はまる落とし穴

- 問いと答えが合っていない：問いの次の文が、前置きや別の話になる。確かめ方：問いだけ読み、すぐ次の1文だけ読んで、答えになっているか。
- たとえが本題に戻らない：たとえが面白くて長くなり、要る1点に戻る文が無い。確かめ方：たとえの最後の文が、線の言葉で言い直しているか。
- 聞き手が持ち上げすぎる：聞き手が答える人をほめる文が続くと、広告だと気づかれる。確かめ方：ほめる文が、事実（何が当たった・何が変わった）を言っているか。
- 信用で代えて、訳が無い：「この人が言うから」「みんな良い人だから」で、なぜ商品だとできるのかが抜ける。確かめ方：設計メモの「この商品だと、なぜそれができるのか」の答えが、どの文かを指させるか。
- 借りてはいけない物を借りる：他人の発言の切り抜き・放送で取り上げられたという言い分・詳しい人の肩書き。確かめ方：使う権利と、事実の出どころを1つずつ当てる。無ければ使わない。
- 言い切りが、言い返される：頭の「◯◯は要らない」が強すぎると、相手は「自分は言われたけど？」と離れる。確かめ方：言い切りを聞いた相手の言い返しを書き、次の文がそれに答えているかを見る。
