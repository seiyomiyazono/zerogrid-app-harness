# G　当事者の物が自分で語る

- 一言で：原因・体の中の物・成分・生き物など、ふだんしゃべらない当事者が、一人称で自分の事を話す。聞き込みに答える形（聞き込み型）と、順に名乗っていく形（名乗り型）がある。
- 勝っている証拠：同じ運びの広告 4本・4ブランド。最長の配信 275日（4本とも217〜275日）。4本とも文字起こしの秒を測った。弱い所：聞き込み型は1本だけ。名乗り型は2本。残る1本は、成分の一人称に「日数の段」を重ねた合いの子。段（Winning／Optimized）は4本とも不明。used は2が2本、1が2本。300日を超える物は無い。映像は4本とも最初の静止画1枚だけ。
- 始まり（線のどの端から入るか）：線の入口の事実を、当事者の口から言わせる。聞き込み型は、相手が困っている行いを「なぜしたの」と聞かれて、当事者が答える所から。名乗り型は、当事者が「私はあなたの◯◯」と名乗り、自分の受け持ちを言う所から。合いの子の1本は「私を毎日◯日とると、こうなる」という先の予告から入り、すぐ名乗る。
- 進み方（何の時計・何の区切りで進むか）：聞き込み型＝問いが区切り（7問。なぜ → 何を聞いてもらえない → うそでは → どう分かる → どう止める → だましてないか → 効かなかったら → どこで）。名乗り型＝名乗る順が区切り（8人前後。敵が順に → 味方が順に → 最後に商品が「全部を1つにしたのが私」。敵を出さず、味方だけが8人続く物もある）。合いの子＝名乗りの後、日数が区切り（4段）。
- 語り手（だれの目・だれの声か）：当事者（原因・体の部分・成分・飼っている生き物）の一人称。聞き込み型は、聞く人（相手の代わり）がマイクを向ける。名乗り型は、聞く人がいない。当事者が、相手（「あなた」）にじかに言う。
- 各区切りで言う事：聞き込み型＝相手が困っている行いの「本当の訳」→ 今の対策（しかる・がまんさせる）が効かない事 → ほしい物 → 疑いへの答え。名乗り型＝1人が、自分の役目と、相手のどの困り事が自分のせいか（自分の仕事か）を1つだけ言う。
- 1区切りの中の文の並び：聞き込み型＝聞く人の短い問い（1文）→ 当事者の答え（1〜2文。打ち消し → 訳）。証拠を体で見せる往復が1回ある（問い → 「◯◯してみて」→ 聞く人の声 → 「それが△△」）。名乗り型＝「私は◯◯」（名乗り）→ 相手の体・暮らしの今の様子を1文 → 「それが私の仕事／私のせい」→ 自分がする事を、短い動きの言葉で2つ → その結果、相手が感じる事を1文。合いの子の日数の段＝日数 → 当事者がしている事 → 相手が感じる事 → 「まだ感じない。待って」か「それは本当」。
- つなぎの作り：聞き込み型＝聞く人の次の問い（前の答えを疑う問いが多い）。名乗り型＝次の者の「私は◯◯」だけで切りかえる。前の者に触れてつなぐ文（「あの者がこわし、私が運ぶ」）は、8人の中で1回だけだった。敵の列の終わりに、まとめの1文（「だから、今の手が効かなくなる」）を置いて、味方の列へ渡す。
- 商品が要る1点の置き場所：聞き込み型＝「どう止めるの」への答え（39〜48%）と、仕組みの答え（64〜73%。「訳が消えれば、行いも止まる」）。名乗り型＝敵の列の終わりのまとめ（45%）と、商品の名乗り（74〜82%。「全部を1つにした」）。合いの子＝今の手を2つ外した後の3文（29〜35%。「問題は◯◯ではない。△△だ。要るのは私」）。
- 締めの作り：聞き込み型＝聞く人が「効かなかったら？」（76%）→ 返金（82%）→「どこで」（90%）→ 当事者が、数が少ないと急がせる。名乗り型＝商品が名乗る（74〜81%）→ 日数の約束か、使った人の数（87〜88%）→ 返金（1本だけ）→ 最後の1文（「私がいるのに、あいつらに勝たせないで」／リンク）。合いの子＝値段を、高い別の手と比べて言う（81%）→ 商品の名前（86%）→ 中身の条件 → 返金 →「私を毎日とって」。
- 長さの目安：測った4本は 77〜114秒（平均90秒）。聞き込み型77秒／名乗り型84秒・114秒／合いの子85秒。
- 要る材料（商品の資料に何が無いと使えないか）：原因・仕組みを、1つずつ「だれ（何）」と名指しできる事。聞き込み型＝相手が困っている行いと、その本当の訳。相手が今している対策。買う前の疑いが3つ。名乗り型＝原因が3つ以上の部分に分かれるか、成分ごとに受け持ちが1つずつ言える事（受け持ちが、相手の困り事の1つずつに当たる事）。合いの子＝日数ごとの変わり方の資料。
- 合わない商品・相手：原因が1つで、分けて名乗らせる物が無い商品（名乗り型）。当事者に口を持たせると軽く見える重い悩み。体の言葉で言い切れない決まりのある商品。原因をまったく知らない相手に、味方だけが名乗る形（何の話か分からないまま、8人が続く）。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：線の段を言うのが、語り手ではなく、段の中身そのもの（原因が原因を、成分が成分を語る）。説明が「言い分」になるので、相手は講義ではなく告白として聞く。聞き込み型は、カードFの答える役を当事者に替えた物。名乗り型は、線の「原因」と「商品の働き」の段を、人数ぶんに切り分ける。そのかわり「放っておいた先」「今の手で足りない訳」は、1文か、まったく無い。

# フックの分解

聞き込み型
- 1文目：聞く人が、当事者に、相手が困っている行いを「なぜしたの」と問いつめる（場面に入れる。相手の困り事を、行いのまま見せる）。
- 2文目：当事者が「助けを求めているのに、聞いてもらえない」と答える（悪者だと思っていた側を、訴える側にひっくり返す）。
- 3文目：聞く人が「何を聞いてもらえないの」（隙間を、もう1段開ける）。

名乗り型
- 1文目：「私はあなたの◯◯」と名乗り、自分が何に守られているか・どれだけ長くその仕事をしてきたかを言う（名乗り＋数か、名乗り＋守りの名前）。
- 2文目：「あなたは、今の手では私に触れない」か「あなたの中の◯◯が見えるか」（相手の今の手を否定する／相手の体の中の場面に入れる）。
- 3文目：「それが私の仕事」か、次の者の名乗り。

合いの子
- 1文目：「私を毎日◯日とると、こうなる」（先を予告して、隙間を開ける。だれが言っているかは、まだ言わない）。
- 2文目：相手の体の、本来の姿を1文。
- 3文目：「私は、その中の主な物」→ 名乗り。

- 何で「え、どういうこと？」を作っているか：しゃべるはずの無い物が、相手の困り事について言い分を持っている事。聞き込み型は、悪者だと思っていた側が「訳がある」と言う事。名乗り型は、原因が自分から「あなたには止められない」と言う事。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：聞き込み型＝25〜32%。体で証拠を見せる往復（聞く人がいやがる声を出し、当事者が「それが◯◯している印」と言う）。フックのすぐ後ではない。名乗り型＝見せていない。敵が「年とともに、私は強くなる」と言う所（15%・25〜31%）が近いだけ。味方だけの物は、1人ずつが困り事を1つ言うが、先のこわさは言わない。合いの子＝20%に1文（今、体の中で起きている事を、強い絵の言葉で）。

# 書く時の手順

1. 設計メモの線の段を見て、「だれ（何）」と名指しできる当事者を書き出す（原因の部分・体の物・成分・生き物）。1つしか無ければ聞き込み型、3つ以上に分かれ、受け持ちが1つずつ言えるなら名乗り型。
2. 聞き込み型：線の段を、聞く人の問いに言いかえる（7問まで）。問いは、相手が実際に思う疑い。1問目は、相手が困っている行いを「なぜしたの」と聞く問いにする。
3. 名乗り型：名乗る順を決める。敵（原因の部分）を先に、入口の事実 → 放っておいた先 → 今の手が効かない訳、の順で受け持たせる。味方は、敵1人か困り事1つに、1人ずつ当てる。合わせて8人まで。
4. 1人（1問）の中身を、決めた文の並びで埋める。1人が言う受け持ちは1つだけ。1人10秒前後。
5. 商品が要る1点を置く。聞き込み型は「どう止めるの」の答えと仕組みの答え。名乗り型は、敵の列の終わりのまとめの1文と、商品の名乗り。
6. フックの3文を書く。デスが見える文を、聞き込み型は4問目より前（2問目の答え）に、名乗り型は1人目の敵の2〜3文目に入れる。
7. 締めを決める。聞き込み型は「効かなかったら」→ 返金 →「どこで」。名乗り型は、商品の名乗り → 約束か数 → 最後の1文。値段を言うかどうかも、ここで決める。
8. 線の段が全部、だれかの台詞に入ったかを表で確かめる。入らなかった段は、記事に回す。

# はまる落とし穴

- 味方の名乗りが、成分の良さの数え上げになる。線に無い強みが、人数ぶん入る。確かめ方：味方1人ずつに、設計メモの「商品が要る1点から出た条件」のどれを受け持つかを書く。受け持ちの無い者は出さない。
- 敵どうし・味方どうしの言い分が、ぶつかる。「原因は私だ」と言う者が何人も出て、どれが本当の原因か分からなくなる。確かめ方：全員の言い分を「いつ・どこで・何が・どうなる」の表に並べ、1本の線の順につながるかを見る（台本の決まり2-6）。
- 敵が強すぎて、商品が勝てる訳が言えない。「あなたには止められない」と言わせた敵を、味方がどう止めるかの文が無い。確かめ方：敵1人ごとに、それを止める味方の文が1つあるかを、1対1で並べる。
- 当事者が、自分が知るはずの無い事（値段・返金・在庫）を言う。聞き込み型では笑いになるが、名乗り型ではうそっぽくなる。確かめ方：締めの文を、だれが言うと自然かを1文ずつ決める（名乗り型は、商品の名乗りに言わせる）。
- 体の言葉で言い切ってしまう。原因が一人称で「私がこうしている」と言うと、言い切りになりやすい。確かめ方：当事者の台詞を1文ずつ、資料の仕組みの記述と照らす。資料に無い働きを言わせない。
- デスが無いまま、名乗りが続く。フックの決まり（1章の5）を満たさない。確かめ方：最初の15秒の中に、相手の暮らしのこわい場面が目に浮かぶ文があるかを見る。
