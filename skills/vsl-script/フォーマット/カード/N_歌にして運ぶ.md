# 書く時の手順

1. 形を選ぶ：対比が1行で言えて、今の手に怒りがある相手なら①（サビあり）。線の段を全部言いたいなら②（通し歌）。相手がもう商品の種類を知っているなら③（短い）。
2. 歌う立場を決める：本人の一人称／仲間が外から／使った人。設計メモの相手の型と、同じ人か、すぐそばの人にする。
3. （①）サビを先に書く：商品が要る1点を、「今の手は◯◯／別の手は△△」の対比に直す。同じ言い出しで2行ずつ。くり返すたびに、対比の後ろ半分の言葉を1つ替える。
4. 線の段を、番に割り振る：番1＝相手の型と入口の事実、番2＝今の手で足りない訳、番3＝商品と結果。1番に段は1つ。入らない段は、記事に回すと決める。
5. 商品の名前を出すか、出すならどこで何回かを決める（見つけた広告は0〜1回、出す時は85%）。出さない時は、画面と飛び先のどこで名前を見せるかを、映像の側に書く。
6. 行を書く：1行に事を1つ。2行で1組。数は1行に1つまで。1回聞いて分かるかを、声に出して確かめる。
7. 締めを決める：歌のまま終わるか、最後だけ間を空けた短い行にするか。頭の言葉に戻すか。
8. 秒を数える：1行3〜5秒で、行の数から長さを出す（語数から出さない）。設計メモの段が、どの番・どの行に入ったかを、表にして確かめる。

# はまる落とし穴

- 細部が運べない：仕組みを歌に入れると、聞き取れない。入れないと、「なぜこの商品だと」に答えが無い。確かめ方：仕組みの行が1〜2行までか。答えの残りを、記事のどこに回したかが書いてあるか。
- 対比が言い返される：「よそでは安く済む」「売る側はもうけている」は、相手が確かめられない言い分になりやすい。確かめ方：サビの対比の両側を、資料の数・事実に1つずつ当てる。
- 音をそろえるために、うその数・場面を作る：行の終わりを合わせたくて、資料に無い言葉を足す。確かめ方：歌詞の数と場面を全部、声・調査に当てる。
- 商品の名前が出ない：歌だけ聞いた人は、何を買えばいいか分からない。確かめ方：音だけで聞いて、何の種類の物かが分かるか。画面を見ずに、押す先が分かるか。
- 軽く見える：重い悩みを明るい曲に乗せると、相手は「ばかにされた」と感じる。確かめ方：番1の場面を、相手の声の言葉と並べて、ふざけて聞こえないかを読む。
- 長さを読みちがえる：語数からの見当と実測が、2倍以上ずれた広告がある。確かめ方：行の数×1行の秒で出し、仮の歌で通して測る。
