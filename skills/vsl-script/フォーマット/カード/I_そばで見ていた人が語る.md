# I　そばで見ていた人が語る

- 一言で：使う本人ではなく、家族などそばにいる人が、本人に起きた事を語る。本人は映るだけで、何も売りこまれていない。
- 勝っている証拠：同じ運びの広告 3本・3ブランド。最長の配信 372日。ただし3本は、作りが1本ずつ違う（内緒で替えて待つ形／先に前と後を見せて訳を語る形／本人の代わりに試す形）。同じ形が2本そろった物は無いので、秒の割り振りは「見当」。見本の運営者の広告は無い。
- 始まり（線のどの端から入るか）：線の終わり（変わった後）を、1文で予告して入る（2本）。「本人は気づかなかった、◯◯が変わるまで」「本人は、もう少しで◯◯をする所だった、これが起きるまで」の形。代わりに試す形だけは、「本人がやるはずだったが、自分が代わりにやる」という事情から入る。
- 進み方（何の時計・何の区切りで進むか）：見ていた人の時間が区切り。形は2つ。
  - 内緒で替える形：①本人の長い悩みと、試した物の山 ②見ていた人が動く（黙って取りかえる）③しばらく何も起きない ④本人が自分から変化に気づく ⑤種明かし ⑥なぜ効いたかを1つ ⑦「同じ人がいたら教えてあげて」。
  - 先に見せる形：①本人の前の姿と、後の姿を見せる ②なぜこれを話すのか（同じ悩みの人のため）③自分で調べて分かった原因 ④本人がしようとしていた手では足りない訳 ⑤商品と、その働き ⑥「同じ人の役に立てば」。
- 語り手（だれの目・だれの声か）：そばの人の一人称。目は、本人を外から見ている。本人は話さない（本人の言葉は、語り手が伝える）。
- 各区切りで言う事：本人が長く困っていた事・試した物／語り手が動いた訳／待った長さ／本人が言った事／訳は1つだけ（続けられた訳・届いた訳）／身近な人に教えて、という頼み。値段は言わない。
- 1区切りの中の文の並び：見た事（本人が何をしていたか・何と言ったか）→ 自分がした事 → その後に起きた事。訳の区切りだけは、「今までの物が効かなかった中で、これが効いたのは◯◯だから」→ 当たり前の理屈で言い直す1文 → だから結果が出た、の順。
- つなぎの作り：語り手の動き（「そこで私は」「それを聞いて」）と、時間の言葉（「何週間も何も言わなかった」「◯週間ほどして」）で進む。先に見せる形は、「調べてみると」「そこで、これが出てくる」で進む。
- 商品が要る1点の置き場所：訳の区切り（全体の半分〜8割の所）。「今までの物が続かなかった（届かなかった）のに、これは◯◯だったから効いた」。訳を1つにしぼり、見ていた人の気づきとして言う。
- 締めの作り：「同じ事で悩んでいる人が身近にいたら、教えてあげて」「役に立てばうれしい」。売りこみの言葉を使わず、人に教える形で終わる。値段・割引は言わない。行き先の一言（下のボタン）は、付ける物と付けない物がある。
- 長さの目安：68〜70秒（2本）。代わりに試す形は152秒。
- 要る材料（商品の資料に何が無いと使えないか）：そばの人が買う・勧める事が、実際に起きている事（声・レビューで確かめる）。本人が言っていた言葉。変化に気づくまでの長さ。効いた訳を1つに言える事。そばの人の目に、変化が見える事。
- 合わない商品・相手：そばの人には変化が見えない物。人に知られたくない悩みで、家族が勝手に動くとおかしい物。訳をたくさん言わないと信じてもらえない仕組み。
- 普通の運び（問題→原因→対策が届かない訳→商品）と、どこが違うか：線の段は同じだが、語るのが相手本人ではない。相手は「身近な人の事」または「自分を見ている人の目」として聞く。原因の説明は1つにしぼる。内緒で替える形は、結果（本人が気づく）を先に言い、訳を後から言う。J（作り手が語る）とは、語る人が違うだけで、「自分で調べた」と言う所は同じ。

# フックの分解

- 1文目：本人がまだ知らない事・しようとしていた事を言い、「◯◯まで」で止める。終わりを先に見せて、間を空ける。
- 2文目：本人が長く困っていた事（または、これが前の姿、と見せる）。相手を、本人に重ねさせる。
- 3文目：何を試しても変わらなかった（または、これが後の姿）。今までの手を、一言で片づける。
- 何で「え、どういうこと？」を作っているか：「本人が知らない間に、何かをした」という秘密。または「する所だった事を、やめさせた何か」。相手は「何をしたのか」「いつ気づくのか」を待つ。
- デス（相手の暮らしで一番こわい事）は、どこで・どう見せているか：はっきりは見せていない。先に見せる形の1文目に、本人が取ろうとしていた大きな手（お金も体の負担も大きい手）が出て、それがこわい事の代わりになっている。内緒の形には無い。

# 書く時の手順

1. 語り手を決める（本人とどういう間がらか。声・レビューに、その間がらの人が買った・勧めた例があるか）。
2. 形を選ぶ：内緒で替えて待つ／先に前と後を見せる／代わりに試す。そばの人が黙って替えられる商品でなければ、内緒の形は使わない。
3. 1文目を、変わった後の予告で作る（「◯◯まで」で止める）。
4. 区切り1に、設計メモの入口の事実を、本人がしていた事・言っていた事として置く。
5. 訳を1つにしぼる（設計メモの「商品が要る1点」から、そばの人が見て分かる物を選ぶ）。全体の半分より後ろに置き、全体の3〜5割を使う。
6. 待った長さと、本人が変化に気づいた時の一言を、資料にある物で決める。
7. 締めを「身近にいたら教えて」の形にする。値段は言わない。
8. 語り手が知っているはずのない事（体の中の細かい仕組みなど）を言っていないか、通して確かめる。

# はまる落とし穴

- 語り手が、知っているはずのない事を言う（専門の人のような説明）。確かめ：どの文も「見た」「聞いた」「調べた」のどれかで言えるか。
- 訳を2つ3つと言って、そばの人の話ではなく、商品の説明になる。確かめ：訳の区切りの答えを、1文で書けるか。
- 内緒で替えるのが、おかしい・こわい商品に使う（体に入れる物を、黙って替える など）。確かめ：本人が後で知った時に、怒らないか。
- 予告した終わり（1文目）と、後で出る変化が、別の物になっている。確かめ：1文目の「◯◯まで」と、本人が気づく所の言葉が、同じ事を指しているか。
- 本人の変化が、そばの人に見えない物なのに、見たように言う。確かめ：変化を知る手が「本人が言った」なのか「自分が見た」なのかを、文ごとに書く。
- 締めを売りこみにしてしまう。確かめ：最後の2文に、値段・割引・急がせる言葉が無いか。
