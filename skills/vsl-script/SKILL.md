# vsl-script — 台本を書く（2026-10-21 作り直し。2026-11-19 `台本の決まり` を書き直して入れた）


## 大もとの決まり（絶対）
このスキルのどのファイルにも、**商品の中身を書かない**（商品の名前・その商品の困り事の言葉・体の部分の名前・その商品でしか通らない例）。運営者 の指摘や、台本の良かった点・悪かった点を決まりにする時は、**どの商品・どのアングルでも通用する形**に直してから入れる。1行足す前に「別の商品（体でない物・生き物の商品）に当てても意味が通るか」を確かめる。商品ごとの事は、商品のフォルダ（`05_原稿の決まり`・`使った物の記録`）に書く

## 読む物（これだけ。この順）
0. [references/台本の芯.md](references/台本の芯.md) — **最初に読む1枚。順番・1枚の絵・売りの決め方・運び。`台本の決まり` と食い違う時は、芯が先**（2026-11-23）
1. [references/商品を読む.md](references/商品を読む.md) — 商品の資料を読む順。読んだら短い理解メモ
2. [references/相手を1人に決める.md](references/相手を1人に決める.md) 0章 — 相手は商品の資料（アングルのページ J・人物の表 K）から写す。資料に無い時だけ原文を集める
3. [references/台本の決まり.md](references/台本の決まり.md) — **伝える事と質。中身の決まりは、この1枚が正**
3b. フォーマット（運び方）を変える時だけ：[フォーマット/一覧.md](フォーマット/一覧.md) と、選んだカード1枚
3c. まとめて4本以上作る時は、1本を新しいフォーマット（試作）で書く：[フォーマット/新しい型を編み出す.md](フォーマット/新しい型を編み出す.md) の3つのルートのどれかで編み出し、`フォーマット/カード_ひな形.md` でカードを書き、`一覧.md` の新作の表に足してから台本を書く
3d. 書いた後、1文ずつ当てる時は [references/文章の決まり.md](references/文章の決まり.md)（フックの決まり・1文ずつの確かめ・問いを最後までつなぐ）。芯と食い違う時は、芯が先
4. 寄せ方の1枚（[寄せ方/対応の表.md](寄せ方/対応の表.md) で選ぶ。ZackDFilms は [寄せ方/ZackDFilms寄り.md](寄せ方/ZackDFilms寄り.md)）
5. 着地が記事なら [references/15の心の声.md](references/15の心の声.md) と [references/記事と分ける.md](references/記事と分ける.md)
6. 商品の `06_原稿/台本の台帳.md`・`使った物の記録.md`（前の台本と同じ運び・言い回しにしないため）

**人に見せる試写（相手役・日本語の検品・意味の検品・聞き返しの検品）は、全部やめた。** 質は `台本の決まり` 9章の確かめで作る（別の読み手に本文だけを渡す「突っこみ役」の1回は、する）。寄せ方の1枚と `台本の決まり` がぶつかる時は、`台本の決まり` が先。

書いた後は [references/台本の確かめ表.md](references/台本の確かめ表.md) を当てる。運び方を選ぶ時、段階ごとにどの箱が使えるかは [フォーマット/箱の台帳_案.md](フォーマット/箱の台帳_案.md)（案。運営者の決めを待っている所がある）。

## 受け取る物
商品・認知段階・映像の型・寄せ方・着地・長さ（依頼票があれば、その項目のまま）。無い物は聞く。長さの指定が無ければ3分前後。寄せ方は、指定が無ければ映像の型と同じ。

## 出す物
`台本の決まり` 10章。台本は依頼票の「納める場所」に置き、票の状態に「台本ずみ」と日付。台帳に1行。
